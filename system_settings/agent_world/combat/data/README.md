# 战斗生产内容包

当前目录版本为 combat-1.0.19 / engine_schema=5，25 张 CSV。物理或魔法通道结算完成后，再按水、火、土、风、光、暗做一次修正：属性修正 = clamp(1 + 攻击方该属性强化 − 防守方该属性抗性, 0.60, 1.50)，然后只向下取整一次。无属性攻击和毒伤不进入这层修正。技能写明的属性优先于武器或魔物普攻属性；空属性跟随武器，显式 `none` 保持无属性。角色六项强化和抗性默认是 0，不随等级或六维成长，只由职业精通和装备词条现算，不写入成长存档。没有新增数据库列、迁移或 WebDAV 实体；新词条保存在原有装备快照里，只出现在此后按新目录生成的掉落上。

combat-1.0.18 的地点与装备内容继续保留：新增 1～15 级新手地点“新芽草甸”，只生成普通怪；软泥怪从苔石洞窟迁入，新增绒耳兔、叶壳甲虫、晨光萤。苔石洞窟新增普通怪洞穴晶蜥，推荐等级 10～20；废弃矿坑推荐等级 15～25。普通洞穴蝙蝠使用专属属性档（等级 10～20，HP 倍率 0.8、攻击倍率 0.9、闪避率 6%）。苔石兽、苔冠巨兽及矿坑精英/Boss 属性与等级保持原值。新手区 Boss 字段为空且 Boss 概率参数为 0，目录校验和探索生成均按无首领区域处理。

本包含 7 个地牢、28 只魔物、97 个装备模板、74 个玩家技能和 10 个魔物技能，并新增 `monster_resists.csv`。冥想每 15 秒恢复最大法力的 2% / 3% / 5%；圣愈每 15 秒恢复最大生命与最大法力各 1% / 2% / 3%。训练木剑显式标记为通用类型。三转门槛为 50 级，大盾精通与大盾等级段为 50～70 级。法师路线法杖为单手武器，等级 10～30，一转法师自动获得绑定白装；秘法杖（双手杖类型）与晨祷权杖（圣杖类型）为 30～50 级。盾牌物品名为符文法盾、橡木圆盾、壁垒塔盾，类型标签仍分别为魔法盾、小盾、大盾。头饰及各等级段布甲、重甲、皮甲、轻甲、板甲均使用不同物品基础名称，等级和掉落规则不变。新增双手剑，适用 50～70 级；剑士 30 级学会精通后，达到装备等级即可穿戴，剑圣继承；狂战士在 50 级学会精通后也可穿戴。精通装备只按已学精通与装备等级判定，不叠加职业白名单。装备采用九槽，吊坠 10～30 级，每人可装两枚 1～30 级戒指。头饰与精通防具按精通等级起步，以 20 级分段、末段封顶 99。

词条池按槽位限制：武器排除物理/魔法防御；防具排除物理/魔法攻击；暴击率和暴击伤害仅适用于吊坠与戒指；命中仅适用于手套，闪避仅适用于靴子。属性强化只进入戒指和吊坠，属性抗性只进入头、身、手、脚和副手。当前武器模板都是无属性，属性类型写在武器模板上，不作为武器词条。吊坠和戒指保留攻击、防御、生命、法力、六项基础属性、治疗、暴击和暴击伤害的完整饰品池。白/蓝/金装备仍分别生成 1/2/3 条不重复词条。Boss 专属吊坠沿用原有专属来源与 50% 出现规则，并加入属性强化词条池。

普通掉落按池与等级规则生成非绑定实例：怪物本次遭遇等级必须落在装备模板的 `level_min`～`level_max` 内，且区域装备等级范围与模板等级范围存在可生成实例的交集；掉落实例等级同时受遭遇等级、区域和模板范围约束。装备基础间隔为 5 分钟，可由职业配置继续缩短；普通/精英未中即消耗，Boss 保留原有优先装备规则。Boss 专属吊坠还需满足 Boss 遭遇等级落入该模板等级范围。设计历史位于 docs/data/combat，状态为 design_only，不可安装。

目录安装在完整包校验通过后事务创建 CombatCatalog。已存在的版本和指纹不可覆盖；损坏文件、未列入清单的 CSV、错误业务引用或同版本不同内容均保留上一有效版本。新的配置必须生成新版本、新清单哈希；历史探索继续绑定原版本，装备实例、成长和交易不按新配置重估。旧目录仍包含在同步快照并按原规则校验。

生产包相对设计草案新增 monsters.attack_multiplier（独立怪物攻击校准）、dungeons.equipment_level_min/equipment_level_max（区域装备等级）。普通/精英的 rank 攻击倍率已经按完整引擎模拟校准。战斗职业、怪物、技能、物品 ID 是稳定业务身份，不得用名称替代或复用 ID 指向另一实体。

属性公式、节奏和额度属于 engine_schema=5 的规则契约。修改这些规则需要同时更新对应纯规则实现和验证，不能只改变 CSV 后声称引擎已采用新公式。技能效果码 `summon`、`shield_break`、`reflect`、`passive_recovery` 和装备条件被动由后端按规则结算；`passive_recovery` 在交战回合开始按最大生命/法力百分比恢复，封顶于对应上限，探索等待时不触发。盾墙按一次敌方攻击行动汇总命中的原始伤害后反击，按伤害类型结算且不暴击、不递归。演示画面不参与伤害事实。职业、技能、装备模板、精通条件、怪物属性档案、动作权重、物品属性、词条/品质、地牢等级及来源使用本包的配置。戒指和吊坠继续共用 `EquipmentInstance.snapshot.slot=accessory` 与既有类型快照字段，两个戒指位使用 `CombatProfile.loadout` 中的 `ring_1`、`ring_2` 键，吊坠仍使用 `accessory` 键。没有新增数据库列、迁移或 WebDAV 实体；战斗同步快照版本升至 5，使用新装备行囊的设备必须先升级后再同步，旧客户端会拒绝版本 5 快照。旧目录继续随历史事实保留。
