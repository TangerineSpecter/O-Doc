# 战斗生产内容包

这是可执行的 combat-1.0.3 / engine_schema=3 包，24 张 CSV；装备机会调整为每 5 分钟一次，普通/精英未中即消耗，Boss 保留原有优先装备规则。设计历史位于 docs/data/combat，状态为 design_only，不可安装。

目录安装在完整包校验通过后事务创建 CombatCatalog。已存在的版本和指纹不可覆盖；损坏文件、未列入清单的 CSV、错误业务引用或同版本不同内容均保留上一有效版本。新的配置必须生成新版本、新清单哈希；历史探索继续绑定原版本，装备实例、成长和交易不按新配置重估。

生产包相对设计草案新增 monsters.attack_multiplier（独立怪物攻击校准）、dungeons.equipment_level_min/equipment_level_max（区域装备等级）。普通/精英的 rank 攻击倍率已经按完整引擎模拟校准。战斗职业、怪物、技能、物品 ID 是稳定业务身份，不得用名称替代或复用 ID 指向另一实体。

属性公式、节奏和额度属于 engine_schema=3 的规则契约。修改这些规则需要同时更新对应纯规则实现和验证，不能只改变 CSV 后声称引擎已采用新公式。技能效果码 `summon`、`shield_break` 由后端按规则结算；新召唤规则中弱/中/强权重为 60%/30%/10%，分支倍率与减益不同，强档附加两轮灼烧。combat-1.0.1 的历史探索继续按旧等概率规则执行。演示画面不参与伤害事实。职业/技能、怪物属性档案、动作权重、物品属性、词条/品质、地牢等级及来源使用本包的配置。日额度的用户配置保存在同步 CombatConfig。自动探索由已启用的迷宫探索活动及本机统一生活运行开关共同控制；历史本机自动探索许可字段不再参与排程，也不需要 WebDAV 同步。此次没有新增持久模型字段或 WebDAV 同步字段。

发布前验证和命令见 docs/agents/Agent战斗探索一期实施与验收记录.md。released 标记表示引擎可安装该内容，不表示已经迁移生产库或通过真实模型、WebDAV、双设备验收。
