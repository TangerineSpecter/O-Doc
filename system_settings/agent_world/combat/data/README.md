# 战斗生产内容包

这是可执行的 combat-1.0.13 / engine_schema=5 包，24 张 CSV，含 97 个装备模板、74 个玩家技能和 10 个魔物技能。冥想每 15 秒恢复最大法力的 2% / 3% / 5%；圣愈每 15 秒恢复最大生命与最大法力各 1% / 2% / 3%。训练木剑显式标记为通用类型。三转门槛为 50 级，大盾精通与大盾等级段为 50～70 级。法师路线单手法杖为 10～30 级，一转法师自动获得绑定白装；双手杖与圣杖为 30～50 级。新增双手剑，适用 50～70 级；剑士 30 级学会精通后，达到装备等级即可穿戴，剑圣继承；狂战士在 50 级学会精通后也可穿戴。精通装备只按已学精通与装备等级判定，不叠加职业白名单。装备采用九槽，吊坠 10～30 级，每人可装两枚 1～30 级戒指。头饰与精通防具按精通等级起步，以 20 级分段、末段封顶 99。

词条池按槽位限制：武器排除物理/魔法防御；防具排除物理/魔法攻击；暴击率和暴击伤害仅适用于吊坠与戒指；命中仅适用于手套，闪避仅适用于靴子。吊坠和戒指保留攻击、防御、生命、法力、六项基础属性、治疗、暴击和暴击伤害的完整饰品池。白/蓝/金装备仍分别生成 1/2/3 条不重复词条。Boss 专属吊坠沿用原有专属来源与 50% 出现规则。

普通掉落按池与等级规则生成非绑定实例。装备基础间隔为 5 分钟，可由职业配置继续缩短；普通/精英未中即消耗，Boss 保留原有优先装备规则。设计历史位于 docs/data/combat，状态为 design_only，不可安装。

目录安装在完整包校验通过后事务创建 CombatCatalog。已存在的版本和指纹不可覆盖；损坏文件、未列入清单的 CSV、错误业务引用或同版本不同内容均保留上一有效版本。新的配置必须生成新版本、新清单哈希；历史探索继续绑定原版本，装备实例、成长和交易不按新配置重估。旧目录仍包含在同步快照并按原规则校验。

生产包相对设计草案新增 monsters.attack_multiplier（独立怪物攻击校准）、dungeons.equipment_level_min/equipment_level_max（区域装备等级）。普通/精英的 rank 攻击倍率已经按完整引擎模拟校准。战斗职业、怪物、技能、物品 ID 是稳定业务身份，不得用名称替代或复用 ID 指向另一实体。

属性公式、节奏和额度属于 engine_schema=5 的规则契约。修改这些规则需要同时更新对应纯规则实现和验证，不能只改变 CSV 后声称引擎已采用新公式。技能效果码 `summon`、`shield_break`、`reflect`、`passive_recovery` 和装备条件被动由后端按规则结算；`passive_recovery` 在交战回合开始按最大生命/法力百分比恢复，封顶于对应上限，探索等待时不触发。盾墙按一次敌方攻击行动汇总命中的原始伤害后反击，按伤害类型结算且不暴击、不递归。演示画面不参与伤害事实。职业、技能、装备模板、精通条件、怪物属性档案、动作权重、物品属性、词条/品质、地牢等级及来源使用本包的配置。戒指和吊坠继续共用 `EquipmentInstance.snapshot.slot=accessory` 与既有类型快照字段，两个戒指位使用 `CombatProfile.loadout` 中的 `ring_1`、`ring_2` 键，吊坠仍使用 `accessory` 键。没有新增数据库列、迁移或 WebDAV 实体；战斗同步快照版本升至 5，使用新装备行囊的设备必须先升级后再同步，旧客户端会拒绝版本 5 快照。旧目录继续随历史事实保留。

发布前验证和命令见 docs/agents/Agent战斗探索一期实施与验收记录.md。released 标记表示引擎可安装该内容，不表示已经迁移生产库或通过真实模型、WebDAV、双设备验收。
