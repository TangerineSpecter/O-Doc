动量方向对冲得分

momentum_direction_hedge_score

结合截面动量与时间序列动量，对冲趋势反转风险，在极端行情下提供稳健防守。适用于日频调仓、高波动、非单边上涨等复杂市场环境。

9 params = parameters or {}

12 short_window = params.get('short_window', 5)
13 long_window = params.get('long_window', 20)
14 decay = params.get('decay', 0.95)
15 clip_threshold = params.get('clip_threshold', 3.0)
16
17 # 计算截面动量收益率
18 ret_short = (close - past_price.get(f'close_{short_window}')) / past_price.get(f'close_{short_window}')
19 ret_long = (close - past_price.get(f'close_{long_window}')) / past_price.get(f'close_{long_window}')
20
21 # 截面排序排名百分比 Rank
22 rank_short = np.argsort(np.argsort(ret_short)) / len(ret_short)
23 rank_long = np.argsort(np.argsort(ret_long)) / len(ret_long)
24 raw_momentum = rank_short * w1 + rank_long * w2
25
26 # 波动率惩罚计算
27 realized_vol = data.get('realized_vol_20d', benchmark_vol)
28 vol_ratio = realized_vol / benchmark_vol
29 vol_penalty = np.minimum(1.0, vol_ratio)
30
31 # 组合得分与极端值惩罚截断
32 composite_score = raw_momentum * (1.0 - vol_penalty)
33 mean_val = np.mean(composite_score)
34 std_val = np.std(composite_score)
35 if std_val > 0:
36 z_score = (composite_score - mean_val) / std_val
37 final_score = np.clip(z_score, -clip_threshold, clip_threshold)
38 else:
39 final_score = composite_score
40
41 return final_score

核心因子公式与数学模型

将多维度动量信号与波动率惩罚结合，生成综合排名分。

RawScore = (Rank(Return5d) × W1 + Rank(Return20d) × W2) × (1 - VolatilityPenalty)
其中 VolatilityPenalty = Min(1.0, RealizedVol20d / BenchmarkVol)
计算频次: 日频 (Daily) 输出类型: 连续浮点值 (Float64)
适用资产池: A股全部 (剔ST/停牌) 港股通流动性前500 美股标普500成分股

多维度特征定义与指标体系

用于计算核心因子的输入特征定义与衍生指标计算逻辑

特征 1: 收益率 (Return) 基础时序行情特征

历史收益率（支持多周期动态窗口），使用近 N 日收盘价变化率。计算方式为 (Close_t / Close_{t-N}) - 1。

特征形态: 序列特征 (Series)
数据类型: Float64
缺失值策略: 均值填充 (Mean Fill)
指标: 波动率惩罚 (Volatility Penalty) 针对过去 20 日高波标的实施扣分
input_vol = StdDev(Return_daily, 20) * Sqrt(252) penalty = Min(1.0, Max(0.0, (input_vol - 0.25) / 0.15)) output = 1.0 - (penalty * VolatilityWeight)
计算频次: 日频 (Daily) 表达式: RealizedVol_20d / BenchmarkVol
