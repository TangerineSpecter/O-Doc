# 可莉精灵战斗演示

核对日期：2026-10-22。范围：独立的横版 2D 精灵战斗原型，不接正式战斗结算。世界工坊 `/world-studio-preview.html` 保持独立，后续继续讨论。

## 打开

- 开发入口：`frontend_react/sprite-battle-preview.html`；当前会话 URL 为 `http://127.0.0.1:43131/sprite-battle-preview.html`。
- 可单独打开的 HTML：项目根目录 `outputs/sprite-battle/klee-sprite-battle.html`。角色、背景、武器、字体、样式、脚本全部内嵌，战斗演示无需服务器。导航中的世界工坊仍是项目预览入口。
- 重新导出：在 Node 22 的 `frontend_react` 目录运行 `node scripts/build-sprite-battle-demo.mjs`。

## 当前效果

默认可莉、花火骑士套、炎法师、奥术星芒月轮杖。支持另外两套防具（星芒学者套、绯金剑圣甲）及两件武器（红莲灭世双头炎魔杖、天丛云·绯金剑圣名刀）。选择职业只切换职业；服装和武器独立保留。“默认搭配”和“剑圣推荐搭配”是显式的整套预设操作。

角色使用新生成的 4 列 × 3 行透明精灵图：每套服装有待机、蓄力、施法、斩击四个姿态。载入时剔除切片周围孤立 alpha 噪点，按脚底归一到 144×144 画布；动作时序与位移由程序驱动。武器沿用 v17 已有设计，由像素数据一次性导出为三张透明 PNG，通过各自握点、角度与角色帧的手部挂点组合。法术从武器发射点出发；剑类普通攻击采用突进与斩击。

| 职业 | 职业特性 | 技能 |
| --- | --- | --- |
| 炎法师 | 三叶余烬：三枚浮焰、每三次普攻命中追加花火 | 四叶焰·星陨花火：聚焰、曲线飞行、四瓣爆开、余烬 |
| 剑圣 | 藏锋·五曜剑阵：剑匣与五柄浮游灵剑 | 天元剑匣·神裁天剑：24 柄独立飞剑分批沿曲线追击，最后落下神裁天剑 |

木桩在视觉命中时扣除演示 HP，并产生闪白、晃动、伤害数字；击破后短暂碎裂并自动修复。支持自动试演、普通攻击、主动技能、暂停、0.5/1/1.5 倍速及木桩重置。键盘 `1` 普攻、`2` 技能、空格暂停；点击画布释放技能。

## 数据边界与限制

- 不读写正式 Agent、职业、装备和战斗事实，不新增数据库字段或 WebDAV/WebDev 同步内容。所有状态只在浏览器内存中；数值仅用于比较视觉效果。
- 服装是三套预制配套动作，不能证明任意盔甲可自动套到任意角色上。角色只有四个动作姿态，加位移和姿态切换；不是完整高帧数逐帧动画。
- 技能特效是独立程序绘制的像素形状、轨迹与光效；未接正式技能目录和服务端事件。切职业或装备不取消当前技能，已开始技能按开始时的职业和普通攻击武器类别执行，后续动作使用新配置。
- 完整场景、人物与武器均采用前端 Canvas2D。原 v17 HTML 和世界工坊源码没有改动。
- 移动布局可查看与操作；画布按屏幕缩放，主要视觉验收以桌面为准。

## 代码与验证

`BattleApp.tsx` / `LoadoutPanel.tsx` 负责 UI；`useBattle.ts` 负责生命周期；`BattleSimulation.ts` 负责演示动作和命中事件；`BattleScene.ts` 编排渲染；角色、场景、两种技能及像素绘制分别在独立模块。`art.ts` 载入和切片，`catalog.ts` 保存演示规格，`pose.ts` 保存姿态与坐标变换。

已通过类型检查、局部 ESLint、6 项纯逻辑测试，以及桌面和 390px 浏览器交互验证。单文件 HTML 已通过 `file://` 离线打开验证：无外部 HTTP 请求，两种技能播放正常，剑圣产生 24 次飞剑命中及 1 次神裁命中。证据在项目根目录 `outputs/sprite-battle/verification.json` 与同目录截图；飞剑连续播放录像为 `blade-skill.mp4`。
