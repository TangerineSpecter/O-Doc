# 林间慢日：横版 2D 场景演示

2026-10-22。独立、可操作的视觉与交互预览，尚未接入正式 Agent 世界。

## 打开

Node.js 22，在 `frontend_react` 中运行 `npm run dev -- --host 127.0.0.1 --port 43131`，访问
`http://127.0.0.1:43131/camp-world-preview.html`。默认应用入口和构建不引用此预览。

新增的[世界工坊模板预览](../worldStudio/README.md)位于 `/world-studio-preview.html`，用于验证摆件占格、布局编辑、独立室内坐标和角色精灵切片。

## 当前实现

- **正侧视、单条地面**：1920×400 逻辑世界，地面 Y=334。角色只在 X 方向行走；Y 只用于跳跃和落地。移动不包含前后纵深或俯视寻路。
- **可横向扩展的独立建筑**：房屋使用单独的正立面透明素材，不烘焙进背景。房屋、路旁树、座位、设施各自登记外观、位置、点击形状和互动点。之后增加建筑可沿 X 轴登记；本版没有建筑编辑器或建筑存档。
- **两个居民**：可莉和阿尼亚，保留用户参考中的身份与服装特征。有待机、三帧行走、挥手、坐下、烘烤和开心姿态；钓竿、鱼线、小鱼、火焰和环境点缀单独绘制。
- **自主活动与气泡**：本地规则分配活动和空闲互动点，走到后才执行动作。聊天是预设角色台词，不调用模型。桌面同时显示对话，窄屏优先显示选中居民的气泡。
- **横版碰撞**：篝火石圈、石头为地面障碍；沿预计算抛物线跳过，途中对运动线段采样检测。建筑和路旁树属于道路后方的展示层，不把整张图片当实心障碍。
- **物体识别**：物体具有稳定 ID。先做形状命中，再使用渲染素材的 alpha 检查，透明像素可穿透点选；不对截图执行在线视觉识别。调试开关显示物体范围、阻挡范围、互动位置、地面线和跳跃路线。
- **镜头**：左右按钮或横向拖动查看街道；跟随开关和居民选择可恢复观察。窄屏缩小可见世界宽度，保持同一正侧视投影，不拉伸角色。
- **生命周期**：30 帧/秒，页面隐藏、画面离开视口或暂停时停止循环；系统要求减少动态效果时默认暂停。卸载清理监听、观察器和画布。

操作：点击角色打招呼，点击地面左右走，点击物体安排互动；左右方向键移动，空格暂停，D 切换碰撞显示。

## 数据与同步边界

纯前端 Canvas 2D＋React 演示，没有新增依赖、业务 API、数据库、持久字段或本地存储，不新增 WebDAV 同步数据。
角色、位置、活动、镜头和台词均为内存样例；不改变真实居民资料、日程、库存或账目。

## 模块

- `CampWorldApp.tsx` / `campWorld.css`：页面、可读气泡和控制栏。
- `useCampWorld.ts`：加载、失败重试和实例生命周期。
- `CampScene.ts`：画布渲染、横向镜头、指针命中、输入和暂停。
- `simulation.ts` / `dialogue.ts`：自主活动、位置、席位、台词和记录。
- `worldMap.ts` / `navigation.ts`：独立物体登记、同一地面、障碍检测和跳跃路线。
- `art.ts` / `effects.ts`：原生透明素材的运行时切帧、像素绘制和道具动画。
- `simulation.test.ts`：单条地面、双向跳跃碰撞、互动点可达、双人席位、持续活动和暂停。

素材均由内置 imagegen 生成，保留原始文件。项目使用：
`public/previews/camp-world/side-forest.png`、`side-objects.png`、`characters.png`。
完整提示词见 [generation-prompts.md](./generation-prompts.md)。首次斜视背景已淘汰，仅留在 `outputs/camp-world/superseded-campsite.png` 作过程记录。

## 验证

在 `frontend_react` 中：

```sh
npm run type-check
npx eslint src/previews/campWorld
node --experimental-strip-types --import ./scripts/register-ts-loader.mjs --test src/previews/campWorld/simulation.test.ts
```

类型检查、局部 ESLint、独立入口生产构建与六项逻辑测试通过，其中连续模拟四分钟验证落地、跳跃和碰撞。实际 Chrome 验证了双人烘烤、暂停、房屋像素点击、碰撞显示、拖动、跳跃到达钓鱼点、镜头跟随、长椅坐下及 390px 气泡不越界与无页面横向溢出；无页面异常或失败请求。
截图、录像与浏览器结果保存在项目 `outputs/camp-world/`。这些结果仅证明独立演示，不代表真实 Agent 执行或正式接入已完成。
