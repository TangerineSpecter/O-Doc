# Grsai 生图接入

## 配置

1. 在「设置 → AI 服务商」新增 **Grsai**，填写 API Key。Base URL 可用 `https://grsaiapi.com/v1` 或 `https://grsai.dakka.com.cn/v1`。
2. 在该服务商下新增类型为「图像生成」的模型，模型实际名称填写 Grsai 文档中的模型 ID，例如 `nano-banana-2`。
3. 在「默认模型」中选择该生图模型并保存。
4. 打开提示词库中的「生图」模板，填写字段后点击「用默认模型生图」。完成后的图片会存为素材，并显示在该模板的历史效果中。

默认模型配置、服务商与模型记录、提示词历史效果和素材沿用现有 WebDev 同步机制。生成中的第三方任务凭证只临时保存在当前浏览器会话，关闭模板后重新打开可继续查询；会话结束或凭证超过一小时后需重新提交。

## 当前接口范围

- Agent 创建/编辑弹窗可上传一张「全身形象参考图」（`fullBodyImage`），支持全身立绘或包含完整角色的设定拆解图；与头像独立保存，随 WebDAV 同步。建议使用与头像一致的角色和画风。「旅行场景照」技能通过通用生图 MCP 明确选择参考图后传给 Grsai，旧文章插画流程不会自动使用角色参考。

- 使用 Grsai 的 `POST /v1/api/generate` 和 `GET /v1/api/result`，支持同步返回和异步查询。
- 提示词库生图仍使用纯文字生图默认参数；编辑器的「生成文章配图」会先读取当前默认模型的能力，再提供可用的画幅和分辨率选项。文章配图默认使用 `16:9`、`1K`；提示词要求按文章主题生成暖色手绘绘本风格的正文插图，使用简化造型、深色手绘轮廓和留白，不生成写实照片、封面、海报或信息图。
- Nano Banana 使用固定比例选项和 `imageSize` 档位；具体可选分辨率随模型名限制，例如 `nano-banana-2-cl` 仅提供 `1K`，普通 `nano-banana-2` 提供 `1K/2K/4K`。比例和分辨率不是任意文本输入。
- GPT Image 2 普通型号提供比例选项并固定为 `1K`；VIP、Flare、Sunburst 型号以像素尺寸传递分辨率，可选择比例和 `1K/2K/4K` 档位，也可手动填写尺寸。手动尺寸仍须满足 Grsai 约束：边长不超过 3840、两边为 16 的倍数、像素总数为 655,360–8,294,400，长短边比不超过 3:1。
- New API 的模型契约由用户配置且当前适配器不发送尺寸参数，因此界面显示由模型自动决定，不提供未核实的比例/分辨率输入。
- 编辑器图片尺寸设置只随本次生成请求传递；通用 MCP 会将执行参数保存在任务快照中以支持去重和恢复。新增其他生图场景时，应复用模型能力描述，并为场景配置独立默认比例和分辨率。
- 提示词库的负向提示词约束会拼入 `prompt`；文章配图则在 prompt 中明确正文插图用途。纯文字生图使用 `images: []`，返回类型为 `json`。
- 仅保存 PNG、JPEG、WebP 格式的图片；远程图片下载遵循现有公共地址校验和大小限制。
- 文章配图生成成功后会先保存为未关联的普通资源，再插入正文。Grsai 返回异步任务后，当前设备资源库先记录「生成中」任务；编辑器轮询可停止或超时，之后从资源库继续查询，不会重新发起付费生图。Grsai 或 New API 已返回图片 URL 但下载失败时，记录转为「待下载」，保留原图 URL 和任务 ID；可重试入库或手动保存原图后上传。只有通过公网地址校验的 URL 才会自动预览和提供查看原图链接；其他地址只提供手动复制。待处理记录不参与 WebDev 同步，入库后的资源按原有规则同步。
- 不在「测试连接」中触发付费生图。配置完成后应在提示词库执行一次真实生成来确认账号权限、额度和出图效果。

接口依据：[nano-banana 接口](https://qmy27nhsd9.apifox.cn/452392911e0)、[GPT Image 接口](https://qmy27nhsd9.apifox.cn/452409160e0)、[异步结果查询接口](https://qmy27nhsd9.apifox.cn/452409577e0)、[Google Gemini 图片生成参数](https://ai.google.dev/api/generate-content)。

## 通用生图 MCP 与旅行场景照

「生图 MCP」保留旧 `get_illustration_options`，新增：

| 工具 | 用途 |
| --- | --- |
| `get_image_generation_options` | 默认模型能力、可用比例与分辨率，以及当前 Agent 的头像和全身图资源 ID |
| `generate_image` | 原样提示词与可选 `reference_image_ids` 生图；返回本系统 `task_id` |
| `get_image_generation_result` | 查询任务状态，或仅恢复已有图片下载；不重新提交生图 |

参考图为最多 4 个已有资源 ID（本工具限制），按输入顺序读取。仅允许自己上传或公开可读的有效图片；本机文件需已下载。服务端校验实际图片格式和文件路径后转为 base64，不让供应商访问应用私有资源 URL。单张最多 15 MB，合计最多 20 MB。当前以图生图能力仅对 Grsai 的 Nano Banana/GPT Image 2 型号开放，New API 保留文字生图。

`request_id` 由调用方为每次生成意图固定，同一参数重试返回原任务，相同标识搭配不同参数会拒绝。任务隔离到当前 Agent；外部 MCP 无 Agent 上下文时使用独立命名空间。任务状态包括 `submitting`、`generating`、`download_pending`、`succeeded`、`failed`、`submission_unknown`。不确定是否已经提交时禁止自动再次收费生成。查询始终使用执行时模型 ID；删除该模型后如实报错。最终仅返回已入库资源地址和 Markdown，不返回服务商临时图片地址。

新增 `prompts.0005_imagegenerationtask` 迁移。用户已确认通用生图业务任务随 WebDAV 同步，保留请求、服务商任务 ID 和恢复参数；执行锁 `lease_until` 不导出，导入时保留本机锁或清空，不同步服务商密钥。最终图片仍沿用普通资源的同步规则。

启用并绑定「旅行场景照」「旅行游记」和「生图 MCP」后，明确要求带图游记：先起草、选取已发生的片段、生成图片、查询成功、插入正文。要求发布时还需「Agent 帖子 MCP」，使用 `skip_illustration: true` 避免旧插画再次生图。Skill 不会因绑定而自动生图或发布。内置旅行工作流先发布正文，再单独补图；失败不阻止日记，详见 [一期说明](../agents/Agent旅行工作流一期说明.md)。普通主动调用 Skill 的场景可先完成图片再发帖。
