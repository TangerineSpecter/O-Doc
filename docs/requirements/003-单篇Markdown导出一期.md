# 需求：单篇 Markdown 导出一期

- 状态：可领取规格；建议排在版本历史一期（`002`）之后，也可与 `002` 并行（无新模型）
- 规划来源：`docs/功能规划文档.md` P2「导入导出增强」建议顺序第 1 项；组合 A 安全感里尚未落地的切片
- 对照现状：HEAD `7d54799`，前端 `0.9.13`。阅读页已有「导出 PDF」（浏览器打印）；HTML 原样笔记已有「下载原文件」。**没有**把 Markdown 正文存成 `.md` 的入口
- 无新模型、无同步字段、不必升应用版本

## 1. 要解决的问题

用户可以把知识库整站打成 zip，也可以把一篇文章打成 PDF，但不能把一篇 Markdown 文章拿到编辑器外。迁移、备份单篇、丢进 Git / 语雀 / 其它笔记软件时，只能复制粘贴。

导入已经能吃 HTML / Markdown；导出明显弱于导入。

## 2. 目标

登录用户（以及能打开该文的公开读者）可以把**当前这篇** Markdown 文章下载为单个 `.md` 文件：YAML 头 + 正文。不打包图片，不改库。

## 3. 范围

### 做

- 仅 `content_format=markdown` 且当前可见的文章（与阅读页同一套可见性）
- 阅读页：在现有「导出 PDF」按钮旁增加「导出 Markdown」
- 编辑器：顶栏增加同样入口；导出**当前缓冲区**（含未保存改动），不要先强迫保存
- 文件名：由标题生成，非法路径字符替换为 `-`，去掉首尾空白与点，最长 80 字；空标题则用 `articleId.md`
- 文件内容：UTF-8，LF 换行。先 YAML frontmatter，再空行，再正文

frontmatter 字段（缺省就省略该行，不要写空数组凑数）：

```yaml
---
title: 文章标题
anthology: 文集名
category: 分类名
tags:
  - 标签A
  - 标签B
source_url: https://...
updated_at: 2026-09-20T10:00:00+08:00
---
```

`title` 含冒号或特殊字符时按 YAML 加引号。正文保持库里 / 编辑器里的 Markdown，**不要**再包一层 `# 标题`（标题只在 frontmatter）。

### 不做

- 原样 HTML 笔记（已有下载原文件 / 转 Markdown 副本）
- 闪念、白板、图片文集、图书、资源库批量下载
- 把 `/api/resource/view/<id>` 图片打进 zip，或改写成外网可离线路径（二期）
- 文集 ZIP、整站 zip（已有）、PDF（已有）
- 新模型、WebDAV、应用版本号
- 版本历史、回收站、双向链接、自定义模板

## 4. 产品规则

1. 谁能打开这篇阅读页，谁就能导出。私密文对游客仍然不可见，导出不另开权限模型。
2. 图片、视频、附件在正文里保持现有写法（通常是 `![](/api/resource/view/<assetId>)`）。导出说明里写一句：图片仍指向本实例，换机器打不开是预期，不是 bug。
3. 回收站里的文章没有阅读页，一期不必从 `/recycle` 导出。
4. 编辑器未保存时导出缓冲区；阅读页导出已保存正文。不要在导出时偷偷 `PUT` 保存。
5. 一次只导一篇。不要弹复杂选项（是否含图片、是否含批注）。
6. 不引入独立 TODO。

## 5. 界面要点

- 阅读页：与 PDF 按钮同一组。桌面可出「Markdown」文字，窄屏与 PDF 一样用图标 + `title`/`aria-label`「导出 Markdown」
- 编辑器：放在「存为模板」附近，不要再挤进保存主按钮
- 点击后立即下载，成功不必 toast；失败（无正文、浏览器拦截）用现有错误 toast
- 主色仍是橘子；这是普通导出，不要做成红色危险按钮
- 不要营销风插画

## 6. 实现约束（给阿尼亚）

- 优先前端生成 Blob + `download` 属性。阅读页已有文章详情，编辑器已有 `title`/`content`，不必为了一期再开下载接口
- 文集名、分类名、标签若详情里已有就用；缺失则省略对应 frontmatter 行
- 文件名净化放纯函数，单测覆盖：斜杠、空标题、超长、Windows 保留字符
- 不要把导出逻辑写进 `ArticleReader.tsx` 整页；抽 util / hook，页面只接线
- `useArticlePrintExport` 继续只负责 PDF/打印，不要把 Markdown 塞进去

## 7. 验收

- Markdown 文章阅读页能下到 `.md`，开头是 `---` frontmatter，后面是正文
- 标题含 `/` 或 `:` 时文件名合法，内容里的标题仍是原样
- 编辑器改了正文但没保存，导出的是改后的字，库里的文章未变
- HTML 笔记阅读页**没有**「导出 Markdown」，仍只有「下载原文件」
- 游客打不开私密文章，也就下不到
- 无迁移、无 `TARGET_APPS` 变更、无应用版本提升
- 不 commit（由人类决定）
