- 盘点日期：2026-09-20（`odoc-pm-2` 更新）
- 对照版本：前端 `0.9.8`，README 徽章 `0.9.7`，HEAD `1b44b3c`（内置模板）。工作区另有未 commit 的自定义模板（卡 `odoc-custom-templates`）与本目录需求文档
- 角色：产品（银月）；开发仍归阿尼亚
- 依据：`docs/功能规划文档.md`、`docs/项目结构文档.md`、`docs/数据同步逻辑说明.md`、路由与模型实勘、自定义模板 diff

## 1. 产品定位（已落地）

小橘文档是面向个人知识库与小团队的自部署知识管理工具：文集 + Markdown 文章为主线，辅以闪念、白板、图片/图书文集、AI / MCP / RAG 和云端同步。视觉与交互按橘子主题的清爽文档系统，不做重型任务管理。

## 2. 现有功能盘点

### 2.1 知识主线

| 能力 | 入口 | 现状 |
| --- | --- | --- |
| 文章文集 | `/`、`/article/:collId/*` | 树形目录、公开/私密、分类、标签、字数/阅读时长、父级文章 |
| Markdown 编辑器 | `/editor`、`/editor/:docId` | 斜杠菜单、气泡菜单、元信息栏、AI 润色、保存直接覆盖正文 |
| 文章模板 | 新建文章选择器；编辑器「存为模板」 | **一期**内置六套（空白 / 技术方案 / 会议纪要 / 读书笔记 / 周报 / 复盘），已 commit `1b44b3c`。**二期**自定义模板已落地未 commit：localStorage 键 `o-doc-user-article-templates`，最多 40 个，可从当前正文保存、可删，内置不可改；换浏览器/换设备会丢，**不进 WebDAV**（与字体、悬浮菜单同类）。三期变量未做 |
| 原样 HTML 笔记 | 文集「导入网页 / 文件」 | 只读 HTML/ZIP 预览、转 Markdown 副本、专属资源清理；删除文案为「不可恢复」 |
| 网页 / Markdown 导入 | 同上 | 可解析为可编辑 Markdown，可后台 AI 润色 |
| 划线批注 | 文章阅读 | 原文锚点 + 评论；Agent 也可写。原样 HTML 笔记不支持划线 |
| 思维导图 | 文章 | 按正文 AI 生成并缓存在 `Article.mind_map` |
| 闪念 | `/memos` | 卡片墙、置顶、标签、随机漫步、关系图谱；用户或 Agent 可创建。**不进 WebDAV 快照** |
| 灵感白板 | `/whiteboard`、`/:boardId` | 无限画布、便签、连线、AI 启发。**白板数据不进业务快照** |
| 图片文集 | `/image/:collId` | EXIF、地图足迹、焦段/标签/主色筛选、瀑布流 |
| 图书文集与 AI 导读 | `/books/:collId`、`/guide/:bookId` | 书架、云端正文按需下载、导读/图谱/传记；分析设置随 v2 同步，向量与任务为本地派生 |
| 分类 / 标签 | `/categories`、`/tags` | 独立管理页 |
| 资源库 | `/resources` | 附件与媒体；删除文案为永久删除 |
| 知识维护 | `/maintenance` | 每日回顾（旧文/旧闪念/近作/批注）+ 健康检查（空文、未分类、未标签、RAG 待同步、文件缺失）。**不进同步快照** |

### 2.2 检索、AI、系统

| 能力 | 入口 | 现状 |
| --- | --- | --- |
| 全局搜索 | 导航栏搜索弹窗 | 文章 / 闪念 / 图片 / 资源，摘录 + 关键词高亮，每类最多 12 条。无独立结果页，不含白板、图书正文 |
| AI 对话 | `AIChatWindow` | 多提供商、记忆、技能、MCP 工具 |
| AI 润色 | 编辑器「AI 润色」 | 直接改写全文；无版本可回滚 |
| Agent / 定时任务 / 飞书 | 设置 | Agent 配置、周期任务、飞书 IM、Agent 世界 `/agent-world` |
| RAG | 设置-计划任务 | 文章与闪念向量；可定时同步。Chroma 为本地派生，不进快照 |
| 统计 | `/stats` | 创作与阅读图表、热力图 |
| 云端同步 | 设置-同步 | WebDAV / FTP / FTPS / SFTP，v2 不可变快照 + 三方合并 + 本机安全归档 |
| 本地备份 | 设置-同步 | zip 导出/导入；导入为**全量覆盖**，不含图书正文 |
| 权限 | 文集与文章字段 | `public` / `private`。游客可读公开文集。无 token 分享链接、无密码、无有效期 |
| 系统更新 | 导航 / 关于 | 检测与执行更新 |

### 2.3 同步边界（做新功能必须看）

进 v2 快照：`article`、`anthology`、`categories`、`tags`、`assets`、`stats`、`ai_assistant`、`system_settings`（不含连接配置）、`user`、`book_analysis`（已发布导读）。软删记录随快照走，删除用墓碑。

不进快照：闪念、知识维护、消息、RAG/Chroma、白板、同步连接配置、本机设备 ID、浏览器外观（字体、悬浮菜单风格、**自定义文章模板**）。

结论：任何新模型或新字段，只要希望跨设备，必须进 `SyncManager.TARGET_APPS` 并更新同步说明。闪念上的能力默认是本机能力。

| 规划项 | 规划优先级 | 现状 | 判断 |

| 双向链接与反向链接 | P1 | 无 `[[标题]]` 解析，无反链面板 | 未做 |
| 公开分享链接 | P1 | 仅有公开/私密，无不可猜测 token 分享页 | 未做（不要把现有 `permission=public` 当成分享链接） |
| AI 文档操作面板 | P2 | 已有润色、思维导图、聊天；无「总结/大纲/提取行动项/确认后写回」面板 | 部分具备 |
| 导入导出增强 | P2 | 有网页/HTML/MD 导入、整站 zip；**无单篇 Markdown 导出** | 导入强于导出 |
| 全文搜索增强 | P2 | 搜索弹窗已覆盖四类并带高亮 | 一期弹窗基本完成；缺结果页与语义搜索 |
| 评论与批注 | P3 | 划线批注 + Agent 帖子评论已有 | 团队段落评论不必重做一套；规划项可降为「补齐用户侧体验」 |
| PWA 与移动端快记 | P3 | 无 PWA | 未做 |
| 独立 TODO | 明确不做 | Markdown `- [ ]` + 闪念即可 | 维持不做 |

《功能规划文档》尚未把模板一/二期写回去，后续应补，避免规划与仓库脱节。

## 4. 建议优先级（在规划三组合上的取舍）

规划里的近期组合：

- A 安全感：版本历史、回收站、单篇 Markdown 导出
- B 知识网络：双向链接
- C 创作效率：模板库、AI 操作面板

组合 C 的模板一、二期已经打过（二期尚未 commit）。把自定义模板再做成云端模型不是下一刀：本机方案已明示「保存在本机」，与字体/悬浮菜单同类。

版本历史价值高（尤其后台导入润色会直接写库），但必须新模型、新接口、写入 v2 快照，并限制每篇最多 20 版，切片大于回收站。

回收站杠杆仍最大：Markdown 文章和闪念已经软删，缺的是「看见、恢复、彻底删除」。HTML 笔记除外。

**建议顺序：**

1. 人类先 commit 自定义模板（工作区已脏，不要在上面叠 P0）
2. **回收站一期** — [001-回收站一期.md](./001-回收站一期.md)（尽量复用 `is_valid`）
3. **文章版本历史一期** — [002-文章版本历史一期.md](./002-文章版本历史一期.md)（必须新模型 + WebDAV）
4. **单篇 Markdown 导出** — 尚未写成独立规格，仍是导出增强的最小切片
5. 双向链接、token 分享链接 — 仍是 P1，排在安全感之后
6. 自定义模板上云 / 变量占位符 — 后置

不建议下一刀做：独立 TODO、完整团队评论、PWA、Notion/语雀导入、搜索结果页、再做一套同步模板。
