# 小橘文档：现状盘点与优先级

- 盘点日期：2026-09-20（`odoc-pm-3` 更新）
- 对照版本：前端 `0.9.14`，README 徽章 `0.9.14`，HEAD `7d54799`。回收站一期已 commit `6571549` 并验收。本目录需求文档（含本次 `003`/`004`）尚未全部进 git
- 角色：产品（银月）；开发仍归阿尼亚
- 依据：`docs/功能规划文档.md`、`docs/项目结构文档.md`、`docs/数据同步逻辑说明.md`、路由与模型实勘

## 1. 产品定位（已落地）

小橘文档是面向个人知识库与小团队的自部署知识管理工具：文集 + Markdown 文章为主线，辅以闪念、白板、图片/图书文集、AI / MCP / RAG 和云端同步。视觉与交互按橘子主题的清爽文档系统，不做重型任务管理。

## 2. 现有功能盘点

### 2.1 知识主线

| 能力 | 入口 | 现状 |
| --- | --- | --- |
| 文章文集 | `/`、`/article/:collId/*` | 树形目录、公开/私密、分类、标签、字数/阅读时长、父级文章 |
| Markdown 编辑器 | `/editor`、`/editor/:docId` | 斜杠菜单、气泡菜单、元信息栏、AI 润色、保存与恢复历史版本 |
| 文章模板 | 新建文章选择器；编辑器「存为模板」 | **一期**内置六套（空白 / 技术方案 / 会议纪要 / 读书笔记 / 周报 / 复盘），commit `1b44b3c`。**二期**自定义模板已在仓库：localStorage 键 `o-doc-user-article-templates`，最多 40 个，可从当前正文保存、可删，内置不可改；换浏览器/换设备会丢，**不进 WebDAV**（与字体、悬浮菜单同类）。三期变量未做 |
| 原样 HTML 笔记 | 文集「导入网页 / 文件」 | 只读 HTML/ZIP 预览、转 Markdown 副本、专属资源清理；删除文案为「不可恢复」 |
| 网页 / Markdown 导入 | 同上 | 可解析为可编辑 Markdown，可后台 AI 润色 |
| 划线批注 | 文章阅读 | 原文锚点 + 评论；Agent 也可写。原样 HTML 笔记不支持划线 |
| 思维导图 | 文章 | 按正文 AI 生成并缓存在 `Article.mind_map` |
| 闪念 | `/memos` | 卡片墙、置顶、标签、随机漫步、关系图谱；用户或 Agent 可创建。**业务记录已进 v2 快照**；RAG 向量仍本机重建 |
| 灵感白板 | `/whiteboard`、`/:boardId` | 无限画布、便签、连线、AI 启发。**白板记录已进 v2 快照**（整板作为一条原子记录） |
| 回收站 | `/recycle` | Markdown 文章与闪念：列表、类型筛选、恢复、彻底删除（墓碑）。HTML 笔记与资源库仍不可恢复 |
| 提示词库 | `/prompts` | 模板 / 主题 / 标签 / 效果图；软删进提示词自己的回收逻辑，随 `prompts` 快照 |
| 图片文集 | `/image/:collId` | EXIF、地图足迹、焦段/标签/主色筛选、瀑布流 |
| 图书文集与 AI 导读 | `/books/:collId`、`/guide/:bookId` | 书架、云端正文按需下载、导读/图谱/传记；分析设置随 v2 同步，向量与任务为本地派生 |
| 分类 / 标签 | `/categories`、`/tags` | 独立管理页 |
| 资源库 | `/resources` | 附件与媒体；删除文案为永久删除 |
| 知识维护 | `/maintenance` | 每日回顾（旧文/旧闪念/近作/批注）+ 健康检查（空文、未分类、未标签、RAG 待同步、文件缺失）。**不进同步快照** |

### 2.2 检索、AI、系统

| 能力 | 入口 | 现状 |
| --- | --- | --- |
| 全局搜索 | 导航栏搜索弹窗 | 文章 / 闪念 / 图片 / 资源，摘录 + 关键词高亮，每类最多 12 条。图片侧另有自然语言 / 以图搜图。无独立结果页，不含白板、图书正文 |
| AI 对话 | `AIChatWindow` | 多提供商、记忆、技能、MCP 工具 |
| AI 润色 | 编辑器「AI 润色」 | 编辑器内润色仍是未保存草稿；保存时归档旧正文。导入后的后台润色写库前自动归档 |
| Agent / 定时任务 / 飞书 | 设置 | Agent 配置、周期任务、飞书 IM、Agent 世界 `/agent-world` |
| RAG | 设置-计划任务 | 文章与闪念向量；可定时同步。Chroma 为本地派生，不进快照 |
| 统计 | `/stats` | 创作与阅读图表、热力图 |
| 云端同步 | 设置-同步 | WebDAV / FTP / FTPS / SFTP，v2 不可变快照 + 三方合并 + 本机安全归档 |
| 本地备份 | 设置-同步 | zip 导出/导入；导入为**全量覆盖**，不含图书正文 |
| 单篇导出 | 文章阅读页 | 已有「导出 PDF」（浏览器打印）。**无** Markdown `.md` 下载 |
| 权限 | 文集与文章字段 | `public` / `private`。游客可读公开文集。无 token 分享链接、无密码、无有效期 |
| 系统更新 | 导航 / 关于 | 检测与执行更新 |

### 2.3 同步边界（做新功能必须看）

进 v2 快照：`article`、`anthology`、`categories`、`tags`、`assets`、`prompts`、`stats`、`ai_assistant`、`system_settings`（不含连接配置）、`user`、`book_analysis`（已发布导读）、`whiteboard`、`memos`、`message`。软删记录随快照走，删除用墓碑。

不进快照：知识维护、RAG/Chroma（含图片视觉索引任务）、同步连接配置、本机设备 ID、浏览器外观（字体、悬浮菜单风格、**自定义文章模板**）。

结论：任何新模型或新字段，只要希望跨设备，必须进 `SyncManager.TARGET_APPS` 并更新同步说明。`003`/`004` 一期都刻意不新增模型。

## 4. 建议优先级（在规划三组合上的取舍）

规划里的近期组合：

- A 安全感：版本历史、回收站、单篇 Markdown 导出
- B 知识网络：双向链接
- C 创作效率：模板库、AI 操作面板

组合 C 的模板一、二期已经打过。把自定义模板再做成云端模型不是下一刀：本机方案已明示「保存在本机」，与字体/悬浮菜单同类。

版本历史已使用独立业务记录进入 v2 快照，并限制每篇最多 5 版；回收站一期也已验收。接下来优先完成单篇 Markdown 导出。

**建议顺序：**

1. **单篇 Markdown 导出** — [003-单篇Markdown导出一期.md](./003-单篇Markdown导出一期.md)（无新模型）
2. **文章双向链接一期** — [004-文章双向链接一期.md](./004-文章双向链接一期.md)（P1，一期不要新模型）
3. token 分享链接、回收站二期（文集/图片/白板）— 尚未独立规格，排在后面
4. 自定义模板上云 / 变量占位符 — 后置

不建议下一刀做：独立 TODO、完整团队评论、PWA、Notion/语雀导入、搜索结果页、再做一套同步模板、把 `004` 做成关系表。
