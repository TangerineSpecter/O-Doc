# 需求：单篇文章公开分享一期

- 状态：可领取规格（P1）；建议排在 `003` 导出、`004` 双链之后（本刀要新模型 + 升应用版本）
- 规划来源：`docs/功能规划文档.md` P1「公开分享链接」第一期（只分享单篇文章）
- 对照现状：HEAD `b2852e9`，前端 `0.9.14`。文集/文章有 `public`/`private`，游客可读**公开文集**里的文章。这不是分享链接：链接可猜性差、不能关、不能设密码/有效期，私密文集里的文章游客进不去
- 新模型必须进 WebDAV v2，并更新 `docs/数据同步逻辑说明.md`

## 1. 要解决的问题

用户想把**某一篇**发给别人只读，又不想把整本文集改成公开，也不想让对方登录。现在只能：

- 把文集/文章改成 `public`，出现在站点公开列表里
- 或让对方注册账号

缺少「带不可猜测 token 的只读页」，也缺少关闭、过期和可选密码。

**不要把现有 `permission=public` 当成本刀。** 公开列表和分享链接是两件事。

## 2. 目标

文章所有者可以为单篇 Markdown 文章打开一条只读分享链接。对方不用登录；所有者可随时关闭、更换链接、设有效期和可选密码。关闭后旧链接立即失效。私密文章被分享后，**不会**出现在首页公开文集列表里。

## 3. 范围

### 做

- 仅 `content_format=markdown` 且 `is_valid=True` 的文章（所有者自己的）
- 新模型（建议名 `ArticleShare`）落在 `article` app，**稳定字符串主键**（如 `ash_` 前缀），禁止自增整数主键
- 字段：`article_id`、不可猜测 `token`、是否启用、可选过期时间、可选密码哈希、是否允许搜索引擎收录（默认否）、创建时间、创建者
- 一篇文章一期最多一条有效分享；再次打开是更新同一条，不是堆很多条
- 路由：`/s/:token`（或等价短路径）。未登录可打开。使用精简壳，**不要**带会列出其它文集/搜索/AI 的主导航
- 阅读：标题 + Markdown 正文（复用现有阅读样式）。文内 `/api/resource/view/<id>` 图片必须能在分享页显示（走带 token 的授权资源接口，只放行该文引用到的资源）
- 所有者入口：阅读页「分享」。可复制链接、开关、设/改/清除密码、设/清除有效期、更换 token（旧链接作废）
- 分享页 `<meta name="robots" content="noindex">` 默认；仅当所有者显式允许收录时去掉

### 不做

- 文集分享、整站公开门户
- 原样 HTML 笔记、闪念、白板、图片、图书
- 访问统计、分享页换肤、自定义域名
- 划线批注、版本历史、编辑、AI、导出、反链（分享页只读正文）
- 用改 `permission=public` 来冒充分享
- 把 token 做成可枚举的自增 id

## 4. 产品规则

1. 默认关闭。必须所有者显式打开才生成/启用 token。
2. token 不可猜测（长度明显长于 `art_` 那档；不要用文章 id 当 token）。
3. 密码和过期只在服务端校验。过期或关闭 → 与「从未分享」一样，不要 200 出正文。
4. 有密码时先出密码表单，通过后再出正文；失败不泄露文章标题以外的信息（标题可显示以便确认链对了，或统一「链接无效」——一期选**统一「链接无效或密码错误」**，避免探测）。
5. 分享不改变文章/文集的 `permission`，不改变首页列表。
6. 文章进回收站或彻底删除：分享立即失效。恢复文章后分享仍保持关闭，需所有者再打开（避免误发已删内容）。
7. 被分享人不能看到作者其它私密文，不能走站内搜索跳到私密目标。
8. 不引入独立 TODO。

## 5. 同步（硬约束）

`article` 已在 `TARGET_APPS`，新模型会进 v2 快照：

- 主键与 token 跨设备稳定；按 `模型:主键` 合并
- **提升应用版本**，旧客户端拒绝写回（与 HTML 笔记 0.9.8、版本历史 0.9.14 同类）
- 更新 `docs/数据同步逻辑说明.md`：分享记录是业务数据；关闭/换 token 是更新不是删除；粉碎文章时分享行走墓碑
- 密码只存哈希，快照里也不要明文
- 旧快照没有该模型：视为「未分享」，不要把缺失当删除

## 6. 界面要点

- 阅读页：所有者可见「分享」按钮（游客、公开读者没有）
- 弹层：开关、只读链接 + 复制、密码、有效期、允许收录、更换链接。主色橘子；更换/关闭用次级操作，不要大红主按钮
- 分享页：白底文档，标题 + 正文；窄屏可读。密码表单只要一个输入和确认
- 失效页：简短「链接无效或已过期」，不要露出站点其它内容
- 不要营销风插画

## 7. 验收

- 私密文集里的私密文章打开分享后，未登录用 token 能读正文和文内图；不用 token 仍进不去 `/article/...`
- 首页公开列表不会因为分享而多出这篇
- 关闭或换 token 后，旧 URL 看不到正文
- 过期后同样失效
- 设密码后，错密码看不到正文
- HTML 笔记没有分享入口
- 文章删除后分享失效
- 有迁移；同步说明已写；升了应用版本
- 不 commit（由人类决定）

## 8. 实现提示（给阿尼亚）

- 资源接口必须校验「该 asset 出现在这篇分享文章的正文或 ArticleAsset 里」，禁止 token 变成任意文件下载器
- 不要复用登录 Cookie 去放行 `/api/resource/view/`；分享页用独立路径
- 密码用 Django 口令哈希；前端只传一次明文
- 测试至少：未启用/过期/错密码/关闭/换 token、私密文不进公开列表、资源不属于该文则 404
