### 前端拆分约定

- `views/` 放页面壳与页面级数据流，负责路由视图、接口调用、筛选状态、弹窗控制和主布局组合。
- `components/<Feature>/` 放特性组件，承接页面内可独立维护的 UI 与交互。
- `views/ArticleOutline.tsx` 在确认文集类型后挂载对应工作区：`components/AgentPost/workspace/AgentPostWorkspace.tsx` 组合专栏头、列表和详情，`hooks/useAgentPostWorkspaceData.ts` 负责帖子列表、详情、筛选、分页、阅读标记与照片轮询；`components/Outline/MarkdownCollectionWorkspace.tsx` 配合 `hooks/useMarkdownWorkspaceData.ts` 处理 Markdown 树与编辑。文集元信息由 `hooks/useCollectionWorkspace.ts` 统一读取，两种工作区不同时挂载，避免专栏进入时再发 Markdown 树和重复详情请求。文章切换和重试分别校验会话与请求归属，旧详情、评论或评分返回后不得覆盖当前文章及输入；Markdown 详情请求在切换时失效。帖子列表的并发刷新只接受最新请求，卸载时作废在途结果，失败不显示刷新成功；本地浏览器乱序回归入口为 `frontend_react/scripts/tests/agent_post_list_race.py`，对应 `scripts/fixtures/agent-post-list-race.html`。

- AI 对话流式显示使用 `components/AIChatWindow/smoothStreamQueue.ts` 管理有序字符队列，按原积压分档和 32ms 定时节奏输出，错误时保留未显示的正文和思考内容；队列按游标消费并定期释放已消费内容。`npm run test:chat-stream` 校验原分档、Unicode、会话边界及中断剩余内容；`frontend_react/scripts/tests/chat_stream_browser.py` 使用拦截全部 API 的 local 浏览器验证正常结束和中断。
- `components/Settings/AgentSettings.tsx` 处理居民与任务列表；`agent/AgentTaskEditor.tsx` 渲染任务编辑弹窗，`useAgentTaskEditor.ts` 管理编辑会话、校验、保存与最新生活配置，`agentTaskDraft.ts` 负责新建/回填草稿及调度字段转换，`utils/agentTaskPayload.ts` 生成类型化提交内容。编辑会话关闭后返回的旧请求不得关闭下一次打开的弹窗。
