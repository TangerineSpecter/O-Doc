### 前端拆分约定

- `views/` 放页面壳与页面级数据流，负责路由视图、接口调用、筛选状态、弹窗控制和主布局组合。
- `components/<Feature>/` 放特性组件，承接页面内可独立维护的 UI 与交互。
- 图片文集页面 `views/ImageAnthologyPage.tsx` 保留文集/图片加载、筛选状态、派生统计和上传/预览/删除控制，具体展示拆到：
  - `components/ImageAnthology/ImageAnthologySidebar.tsx`：地点入口、焦段/标签摘要和主色调筛选。
  - `components/ImageAnthology/ImageGalleryFilters.tsx`：国家、标签、焦段范围和清除筛选。
  - `components/ImageAnthology/ImageLocationPanel.tsx`：地点统计、国家/城市列表与地图承载。
  - `components/ImageAnthology/ImageTagStatsPanel.tsx`：完整标签统计面板。
  - `components/ImageAnthology/ImageMasonryGrid.tsx`：瀑布流列布局、图片卡片渲染和空状态。
- 闪念备忘页面 `views/MemosPage.tsx` 目前保留列表/筛选/编辑状态、图谱数据状态和随机漫步状态，具体展示拆到：
  - `components/Memos/MemoCard.tsx`：信息流卡片、卡片菜单、作者/标签徽标。
  - `components/Memos/KnowledgeGraphPanel.tsx`：知识图谱、ECharts 初始化、缩放隐藏标签、图谱详情侧栏。
  - `components/Memos/MemoEditModal.tsx`：编辑闪念弹层、置顶切换和未保存确认。
  - `components/Memos/MemosSidebar.tsx`：视图切换、快速收集、随机漫步入口、信息密度和标签筛选。
  - `components/Memos/RandomWalkModal.tsx`：随机漫步聚焦弹层、卡片切换动画、继续漫步按钮。

后续如果单个页面接近 1000 行，优先按“页面壳 + 特性组件”的方式拆分，避免把图表、弹层、列表卡片和业务请求都堆在同一个页面文件里；仅略高于目标行数且职责仍清晰的页面可以暂缓拆分，避免为了行数过度抽象。
