# 固定验证历史与后续 AI 研究

核对日期：2026-10-25。适用应用 1.5.37、quant schema 45；没有新增数据库字段或迁移。本文描述当前本地实现，不代表真实模型质量、原生平台或生产验收完成。总体目标见[重构规格](../requirements/007-AI量化研究系统重构.md)，固定计算规则见[固定方案新数据验证](./固定方案新数据验证说明.md)。

## 进入下一次分析的内容

固定验证完成、失败或取消后，后续源码研究、实验解读和外部反馈分析可选入它的历史事实。它不只停留在原实验页面的一份报告中。

系统保留原计划／请求／成果的身份和哈希、来源实验／实际尝试／真正父代、冻结公式／绑定／实际参数、成本与策略规则、明确的评价区间、普通复核或新数据预约模式、固定方案和同成本基线，以及预约时／发布时的重用审计摘要。成功记录不抹掉亏损、低于基线、缺失信号、失败或取消。失败和取消没有完整收益，记录为未知，不填零。

模型不读取 CSV、原始价格、完整净值或审计全清单；只获取有界指标和执行摘要。原生编译／平台等价仍未知。审计覆盖本机当时已记录的限定范围，外部使用和全局独立性均未证明。

## 后续 AI 的责任

AI 必须逐项说明选入的历史记录如何处理，选择“采用为研究线索／不采用／继续核查”，引用 `memory:种类:真实ID` 并保留理由。选入记录必须全部被覆盖，不能只引用成功案例；不存在的记录或被改写的事实不能作为证据。

新的源码分析在“检索比对”冻结历史，在原有“评价与审查”和“设计实验”模型调用中读取，不增加新的模型调用次数。源码报告会保存冻结依据、历史判断及首轮规划，仍可人工编辑和删减正文。参数面板显示当前源码默认值；历史观察另外显示原冻结公式的实际参数，不能用历史参数冒充当前源码默认值。

首轮提案既可引用当前 `factor:序号`、AI 修订证据，也可引用冻结历史；每个选中的当前父代仍须引用自己的原文证据，历史观察不能替代当前定义。实验／反馈提案继续使用原有完整参数、预算、策略与归属合同。AI 可据失败提出新的反例对照，也可以明确不提出方案。

历史评价已经被查看，进入后续研究后属于开发线索。后续新假设需要另外的新数据；不再把这段历史当作当前新公式的未见样本外证明。相关性排序基于候选身份、机制、标签、市场与时间，不按收益挑选高分因子；组合收益也不授给各个父因子。源码质量评分仍为 `static_unverified`，不会因为历史收益自动晋级。

## 版本与冻结规则

- 源码工作流默认 v12，跨源码增量工作流 v13；旧 v1–11 不改变输入和结果合同。
- 新实验解读统一使用 review v10、上下文 v5，支持普通因子、显式策略及可选的当前固定验证引用；旧 review v1–9 保留原合同。
- 新外部反馈选择为 `feedback-research-4`，冻结研究记忆 v3；旧选择 v1–3 保留。
- 记忆 v3 增加 `fixed_validation`，最多保留6个实验、4份反馈、4份直接对照、4份固定评价，整体不超过32000字符。相关记录中各计算类优先保留一份负面观察，再按固定规则填充。当前正在解释的固定验证不会同时作为自己的历史。

扫描每类最多最近2000条，新增可选历史扫描另受5秒和2000万字符的读取预算限制，先读固定评价，避免它被大量旧实验挤出。上限在记录边界检查，单条读取／解析不能实时抢占。触及时间或读取预算时，冻结 `scan_limits` 标记；模型和页面都提示覆盖不全，不能把未提供的历史当作没有失败或反例。超出模型输入大小时整条省略，不截掉失败部分。

新请求固定自己的历史；刷新和同步恢复不重新检索。继续未完成的源码研究时，来源、要求、上游事实和候选集合均未变，沿用原冻结时间与判断。候选集合变化或明确从“检索比对”重跑，则重新冻结并让后续评价／规划处理新输入。从更晚阶段重跑继续保留原比对范围。旧报告、旧得分及人工修订均不覆盖。

## 同步与恢复

按用户已确认的全业务同步范围，冻结的历史、选择、扫描覆盖、AI 判断、报告和提案保存在既有业务 JSON 中，经 WebDAV／FTP／SFTP 同步。执行队列、租约、凭据和向量索引仍留本机；没有新增执行权限。

恢复重建每个被选历史的真实来源、公式参数、成本、区间、结果、审计摘要与相关依据，拒绝改写或跨文集引用。源业务的完整性仍由各自验证器检查；历史输入按原冻结选择重建，不重新跑全库检索、计算搜索、原平台或模型。过往软删／整理影响新的发现，不改写已冻结的证据。完整旧快照和旧工作流续跑不会借用新历史。

源码首轮方案同时核对当前定义和历史引用；实验提案／连续研究核对各自版本与完整配置。固定验证解读不能冒充连续研究中原开发实验那一轮的评价。导入或恢复业务事实不会启动后台任务。

## 页面与代码入口

报告中的“本次分析参考了 N 条历史研究”可展开，查看实际扫描／省略范围、每条 AI 判断，以及历史固定方案的实际参数、区间、费用、基线和失败情况。历史策略规则可单独展开，完整冻结 JSON 仍保留。首次收集时用户无需先写研究正文。

- `quant/research_memory/`：固定事实投影、ORM／快照适配、相关选择、反例保留、扫描预算和判断验证。
- `quant/workflows/memory.py`：源码分析的冻结合同、继续复用和静态报告扩展。
- `quant/experiments/`、`quant/feedback/`：后续解读／提案及对应版本和恢复校验。
- 前端 `ResearchMemory`、`FixedResearchEvidence`、独立类型与解码，local 使用类型化人工历史样例，不执行行情或模型。

本地验收包含真实隔离后端事实到前端 JSON 的读取：历史实际参数 `N (p0)=3` 与当前源码默认 `N=20` 分别保留。提供商仍为模拟响应，行情为人工隔离样本；不能据此宣称真实 AI 判断质量已通过。真实模型、原平台执行／对照、双设备远端同步和完整 P0–P5 的其余验收仍需继续。

本轮核验：量化、同步管理和图书嵌入529项后端回归通过；96项前端测试、类型检查、定向lint、构建、迁移一致性、文档链接和差异检查通过。真实隔离后端的源码报告HTTP JSON由前端严格解码，历史 `N (p0)=3`、当前默认 `N=20`、完整判断引用和扫描标记分别对应。纯local浏览器用实际粘贴收集新源码，自动归档一个候选并选入8条历史（含一份固定验证），展示AI判断、实际参数、费用和基线；390px／1440px根内容未横向溢出。截图 `/private/tmp/odoc-fixed-history-report.png`、`/private/tmp/odoc-fixed-history-390.png`、`/private/tmp/odoc-fixed-history-1440.png` 均明确为人工本地样例。临时预览页已清理；本轮未部署、未修改正式数据库或调用真实提供商。
