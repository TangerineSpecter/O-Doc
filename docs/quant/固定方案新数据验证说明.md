# 固定方案的新数据验证

核对日期：2026-10-25。当前代码1.5.44、quant schema47；本领域从1.5.36/schema44及迁移 `0024_validation_studies` 引入，登记与一次绑定规则保持。已有[登记后真实行情单案例](./登记后真实新数据验收记录.md)，不代表正式部署、完整模型质量基线或全局独立性验收通过。完整目标见[重构规格](../requirements/007-AI量化研究系统重构.md)，基础规则见[当前量化说明](./量化文集一期说明.md)。

## 使用流程

在“因子候选库 → 参数与组合实验”选中已发布的已评价尝试，点击“登记当前尝试的验证”。登记冻结该尝试的实际受控表达式、完整参数、输入绑定、阈值、费用与可选策略规则，保留原实验／结果／行情／尝试哈希、实际父代及折号。不是回到源码默认值，也不按测试收益另选一折。

登记时指定验证标的、周期、收益区间数（5–2000）和计算预算（1–60秒）；标的和周期留空时继承来源。截止点始终是原实验完整行情的最后时间。登记成功后再导入 CSV，核对区间和使用记录，再选择：

- **用新数据验证**：行情文件在登记后导入，同所有者私密量化库的已记录审计完整且无重叠。
- **普通复核**：明确允许已导入或已使用的数据，仍执行同一冻结公式与完整区间，不称为新的独立验证。

标的和周期大小写精确匹配，不自动处理别名／跨周期等价。评价从文件中首个严格晚于截止点的新开盘开始，固定使用登记的收益区间数。系统递归计算嵌套滚动／滞后的历史需求，要求该开盘前具备预热与信号柱；历史不足时拒绝，不能跳过初段寻找更好的起点。预热不进入评分区间。文件是否遗漏中间市场柱、是否经过外部挑选仍无法证明。

一个登记只绑定一次行情和模式；重复同一请求返回原预约，停止、失败、租约到期、重启或恢复均不清除使用记录，也不自动重新授予权限。改变参数、市场、区间预算或绑定文件需另登记计划。此路径没有搜索、遗传优化或执行上传源码。

## 计算、报告与因子证据

本机使用既有因果表达式计算器。普通因子沿用下一开盘做多／空仓的参考模拟；显式策略使用[策略执行与成交账本](./策略执行与成交账本说明.md)的冻结规则。结果保留固定方案、同成本买入持有基线、净值和完整成交账本。过大结果在发布前失败并保留登记／预约，不截断账本冒充完整成果。时间预算与停止检查属于本机授权，恢复只做有界确定性核对。

完成时尝试自动创建一份 AI 解读（1.5.36为review v9；1.5.37起默认v10，旧合同保留，详见[后续研究说明](./固定验证历史与后续AI研究说明.md)）。该解读同时绑定原实验结果和独立的固定验证结果；1.5.36的冻结上下文v4保留记忆v2；1.5.37的新上下文v5保留记忆v3，两者均绑定固定结果ID／哈希和原有检索。模型只读取有界指标、执行摘要、实际方案、区间以及授权时／发布时审计摘要，不读取完整价格或全库原始材料。结果解释与风险必须引用固定验证；非空表现和成本评分还须引用实际来源尝试。单次固定参数验证不构成参数稳定性或最优参数证明；没有足够对照时相关得分仍未知。

计算和报告分开保存。模型未配置、配额不足或调用失败不会抹掉已完成计算，可显式重试解读。AI 的下一轮提案继承原开发实验的完整搜索／滚动／演化／策略配置与预算；已看过的新区间不能继续作为未看数据。报告保留既有原稿、人工删减和修订历史。

完成结果自动形成 `fixed_validation` 直接证据及 `fixed_observation` 层级，只关联真正被评价的单因子／参数变体或其确切回库公式。组合收益不会继承给各祖先。该层级不自动提升收益评分、平台等价或正式独立验证状态。

## 数据使用审计的范围

每次预约前、发布时及详情读取时，核对同所有者的所有私密量化文集，包括软删研究留下的记录：已导入行情、实验预约、样本对照和固定验证预约。失败与取消均保留。按精确标的／周期的时间交集，或完整规范化行情行哈希相同进行保守核对。其他文件只要已导入且覆盖评价区间，也会阻止“未发现已知重用”资格。

扫描最多1000条业务记录、读取至多2000万字符的行情投影，超限显示覆盖未知并禁止新数据模式，仍可明确执行普通复核。摘要最多展开100条冲突，完整已扫描清单和遗漏计数保留。预热旧数据可重复，审计关注评分区间。

预约与结果分别冻结当时的审计。详情的“当前已知数据使用”重新计算，后来新增、同步合并或恢复的使用事实可以改变当前提示；历史结果不被覆盖。审计记录含出处、市场、区间与哈希，没有原始价格。毫秒精度的登记／导入顺序与同步时间编码一致；同毫秒导入不视为可证明在登记之后。

**所有结果的 `independent_validation` / `global_independent_validation` 均为 false。** 登记后导入并不证明外部未看过、其他设备未用过、文件未经选择、别名／跨周期不存在相关数据，也不是可信时间戳认证或对历史审计完整性的外部签名。审计只描述本机当时已知的限定范围；不能把“未发现重用”写成全局独立证明或盈利承诺。

## 持久化、同步与恢复

按用户已经确认的范围，`ValidationPlan`、`ValidationRequest`、`ValidationResult`、`AIRun.validation_result`、AI 报告及直接因子证据进入 WebDAV／FTP／SFTP 全业务同步。`ValidationJob` 是本机执行权限，不同步；恢复删除队列和租约，不发起计算或模型调用。

恢复重建来源实际尝试、公式与参数、目标／预热／区间、身份／哈希、冻结审计每条可见事实及归属，并用受控计算器有界重放完整结果与账本。恢复不重做搜索、不执行 Pine／MQ4／Python 源码或调用模型。后续新增记录不反写历史审计；原有同 ID 的不可变事实不可被重哈希改写。完整旧备份缺少新指针时按空引用恢复，不借用本机新指针。清理顺序考虑一对一和级联父记录下的受保护引用，避免恢复旧备份被后来的解读阻塞。

入口：`quant/validation_studies/` 分开管理合同／使用审计／计算／授权／AI证据／展示／同步；前端 `Quant/validations/`、`useQuantValidations`、独立 API／类型／解码；local 使用明确标注的人工样例，不计算导入行情或调用模型。

## 本地验收边界

回归覆盖登记与导入顺序、精确区间、嵌套历史需求、复用／取消预约、跨私密文集审计、别名完整行哈希、超限未知、外来行情权限、实际参数与成交账本、时间预算、AI 引用和继承配置、重哈希伪造拒绝，以及旧完整备份恢复不借新指针／不恢复授权。前端验证类型化样例、列表／登记／核对／结果／报告和空数据、加载、错误；真实后端 JSON 另由前端解码核对。
