## 当前执行规则

1. 先完成“贴入资料 → AI报告、评分与参数分析 → 阅读与删改保存”的主流程，再收尾已开发的研究功能。
2. 每次功能修改只验证受影响的正常流程、常见失败提示和必要计算正确性。没有新增故障或修改依据时，不反复跑全量回归。
3. 已通过的验证直接引用现有记录，不为了增加覆盖率重复拆分任务。不新增与当前功能缺陷无关的边界专项、压力工具或验证框架。
4. 保留必要的数据正确性检查：实际参数不能被默认值替代；收益、回撤、成本与样本对齐不能算错；不得使用未来数据形成当前信号；未知数据不能补成零或伪造有效结论。发现这类真实逻辑错误立即修复。
5. 不为测试单独增加应用或数据合同版本；只有实际兼容变化才按项目现有规则处理。
6. 待办不阻止个人使用的主功能交付。出现可复现问题再按影响处理；已有权限、同步和执行保护继续保留。
