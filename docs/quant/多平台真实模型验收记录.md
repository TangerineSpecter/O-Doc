## 实测方法与边界

使用[固定原创语料](./研究报告质量评测说明.md)和本地已配置的 deepseek-flash，原始源码与参数标签分开，参考答案不进入模型提示。每次首次运行使用独立私密文集；开发 PostgreSQL 只读查询模型配置，业务资料、报告、模型用量和队列全部在隔离内存库中。所有真实请求有阶段记录，失败不发布残缺报告，不补零分。

本批次属于发现缺陷并修复的调试采样，期间代码和提示发生变化，不将这些运行混作固定版本下三次重复的评分稳定性基线。按指定阶段续作的报告保留复用依据，`fresh_model_calls=false`，不冒充一份全新重复样本。参数匹配率只相对于待专家核对的草稿标签，不表示语义全部正确。

## 本批次修正

- 参数用途：input/extern 不能因默认值固定或不直接改变信号而归为 constant；订单标识/滑点为执行用途，手数为风险用途。计算曲线和条件输出若保留在参数表中，应归为 state；缺少实际运行配置不以默认值代替。state 默认值可空，但建议字段仍须说明它不是可调输入。
- 特征与显示：可独立复用的数值变换不因画在图上就归为 display；显示开关、样式或显示门控另作处理，不因此把全部指标曲线排除在研究候选之外。
- 提取合同：明确输入1–20项、引文1–10段及文字/数组上限。黑箱依赖的输入未知时只能记录源码实际引用的运行上下文；无法确认则说明未提取原因，不能为通过检查虚构 close 或算法。
- 修订合同：此前未向模型说明每项引文最多5段，真实 EA 返回6段被正确拒绝；已补充该上限、未知项最多8项等限制，校验没有放宽。平台执行副作用不能改写成虚假的纯计算定义。
- 有界网络请求：显式持有受 SDK 支持的 httpx 客户端，限定依赖为 `httpx>=0.27,<1`，客户端与 SDK 在同一异步作用域关闭。保留超时、取消、零自动 SDK 重试和正常 stop 终止要求。当前本机 SDK 为3.0.0、httpx为0.28.1；原默认 httpx2 路径有流关闭告警，改后27次真实请求均未再出现。

网络与 SDK 序列化测试28项通过；共享图书/量化请求回归126项通过。扩展检查发现4个既有认证上下文测试的模型替身缺少当前 AIModel 的 pk/type/thinking 字段，已补全替身并核对所选模型ID，没有修改认证策略或放宽错误脱敏。参数/修订定向17项通过；量化与共享模块完整回归601项通过，最后的提示补充后受影响合同/工作流31项再次通过。不存在把这些有重叠的计数相加当作不同测试的做法。

网址负对照使用保留的 `.invalid` 来源，3次均在来源获取阶段失败、模型调用为0、报告为0；配置为明确的假模型以证明此路径无需真实提供商，不冒充模型质量样本。[负对照记录](./验收记录/2026-10-25-source-controls-responses.json)已归档。隔离脚本曾因还原时未暂停同步跟踪、负对照文集标题重复而在验收准备阶段失败，修正后再执行；这些不是提供商失败，没有追加模型调用。
