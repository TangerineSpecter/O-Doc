# MT4 回测文集

核对日期：2026-10-27。回测文集用于整理已有 MT4 EA 与外部回测结果；不执行 EA，不保存行情 K 线或 tick，也不连接交易账户。文集仅所有者可见，与量化研究文集互不转换。

## 档案和回测

每个 EA 记录名称、类型、版本、来源及论坛链接、官方要求、注意事项、交易逻辑、参数定义和参数组合；EA 附件可以上传及下载。回测记录按 EA 分组，保存标题、测试说明、条件、参数、指标、交易事件、结论和附件。参数及 EA 版本是创建时的快照，修改 EA 不回写历史。列表可按文字筛选并比较测试条件、参数与指标。手工录入和截图导入允许资料不完整，缺失显示为“—”。

EA 资源文件支持点击选择或拖拽单个文件上传；已有附件时仍可拖拽到附件区域。一次拖入多个文件会提示重新选择。每个 EA 附件可单独添加、编辑或清空不超过 500 字的备注；备注显示在附件卡片上，不修改文件本身。

EA 类型可选马丁EA、趋势EA、震荡EA。官方最低要求分为最低资金（美元，非负数字）、时间框架（1M、5M、15M、30M、1H、4H、1D）、账户要求（无要求、低点差）和额外补充；各项均可留空。原官方要求文本字段直接作为额外补充保留，不自动解析。详情按独立字段展示。

## 报告与图片

- 选择 `.htm`/`.html` 或包含且仅包含一份报告的 `.zip`，先预览并修改，再保存；相同 HTML 内容会提示重复，可确认后继续建立新记录。上传的原报告保留为附件；不渲染或执行报告 HTML。
- 指标行独立前缀如“最大:”“平均：”解析和接口返回时去掉末尾冒号，金额、负号、括号及其他标签原样保留；已保存的旧指标读取时同样规范化，不改写数据库和原始附件。详情页也识别带冒号的前缀。
- HTML 导入和回测接口仅返回实际参数：按明确名称过滤 `comm2`、`Comments`、`note`、魔法号（如 `magic`、`MagicNumber`）等注释与订单标识；以 settings、heading 等结尾且值为引号包裹的冒号标题视为分组标题。名称或用途不明确的参数保留，无法保证识别所有自定义注释。旧记录读取时同样过滤；编辑时保留旧记录中未返回的隐藏项和原始参数字符串，更新可见参数；HTML 附件不改写。原始参数字符串不再在 `fields.parameters` 中重复返回。
- ZIP 中引用的同目录图片可展示为 MT4 原图；单独图片可与 HTML 同时上传，或之后补充。图片非必填。ZIP 内不跟随外部链接，不解压到文件系统；报告 HTML 上限 20 MiB、ZIP 上限 30 MiB、ZIP 总解压大小上限 40 MiB、ZIP 内曲线及识图截图上限 10 MiB、事件不超过 20 万行；普通附件上传上限 50 MiB。
- 截图识别由用户主动触发，使用系统默认识图模型；只把模型输出作为可修改的草稿，保存截图与模型名称，不填充未识别的指标。没有识图模型或识别失败时仍可手工填写。
- 交易事件保留序号、服务器原始时间、类型、订单号、手数、价格、止损、止盈、获利和余额。空值保持空值；序号不等同订单号。交易表头的列顺序或事件行结构不受支持时拒绝导入，避免静默错列或跳过异常行。平仓余额重建图不包含持仓期间的浮动净值；大数据量抽样时保留分段高低点，交易明细按 100 行分页。
- EA 页面和回测列表使用数据库生成的无交易事件摘要，只有打开单条回测详情才读取完整事件；不复制或变更原记录和同步数据。
- 切换回测时重新加载详情并重置筛选及页码；缺失盈亏不会当作零，只有可识别平仓事件的余额和盈亏完整时才用事件补算净盈利、初始资金和胜率。点差取报告指标，缺失显示“—”。大报告余额曲线按区间保留极值抽样，开仓手数图最多显示 1000 根抽样柱并标注抽样。

## 同步和边界

用户确认 EA、回测、交易事件、附件及其备注全部纳入现有 WebDAV/FTP/SFTP 同步。`MT4Expert` 的四项官方要求和 `MT4Attachment.note` 均随记录同步；`MT4Expert`、`MT4Backtest`、`MT4Attachment` 属于量化同步域，使用稳定 ID、所有者与引用校验、快照锁和 `quant_schema_version=78`；资源文件按 `Asset` 媒体规则同步。77 版旧快照的附件没有备注，恢复时新附件默认为空，普通合并时同 ID 本机备注保留；新快照缺少备注或低版本携带备注会被拒绝。缺失的已引用附件不会被静默标为无效。参与同步的设备需先升级并执行 `anthology.0011` 和 `quant.0033` 等迁移。上传的 EA 文件作为附件存储，不由系统运行。

## 代码入口和验证边界

后端 `quant/mt4_reports/` 分离 HTML 解析、ZIP、识图、接口、序列化与同步校验；`quant/models.py` 注册业务模型。前端 `views/MT4ArchivePage.tsx`、`components/MT4Archive/`、`hooks/useMT4Archive.ts`、`api/mt4Archive.ts` 与 `mocks/mt4/` 分离页面、状态、API 和 local 样例。local 导入/识图返回明确标记的演示数据，不实际解析报告或调用模型。

解析已针对用户提供的一份中文 MT4 报告核对，不代表所有 MT4 语言和第三方报告均已适配；截图识别依赖模型效果及人工核对。数据库迁移、真实模型服务、部署和两台设备间远端同步需要分别验证，本地隔离测试不等于生产验收。
