# 研究报告对照

核对日期：2026-10-25，应用 1.5.39。当前功能是同一研究条目内的静态报告对照，不调用模型，不修改报告、评分、参数、候选或证据状态。主流程见[量化研究库](./量化文集一期说明.md)。

## 页面与对照方向

一条研究记录有至少两份静态报告时，“AI 研究报告”页面显示“报告对照”入口。展开后默认选择较早的可用报告，可更换基准；没有较早报告时选择其他可用报告，页面始终明确基准 → 当前所选报告的方向、时间和来源快照。历史代码解释可以参与正文对照，实验解读和外部反馈报告不混入静态研究比较。

报告仍可单独切换、编辑和删减。更换对照基准只影响该卡片，不更换当前正在编辑的报告，也不提交或丢弃编辑。卡片关闭时不计算正文差异，展开后在浏览器中按已有记录生成，使用当前条目已获授权的数据，不增加接口、模型调用或执行队列。

## 原稿结构化记录

- 五维评分展示基准、所选原值和分差，可展开理由与依据。只有同一已知评分规则版本才计算分差；未知分数保留未知，不按零分处理。跨规则版本只展示原值。研究评价变化不表示收益改善。
- 参数按大小写敏感的变量名配对，比较默认值、类别、含义/单位、约束、变化影响、候选建议、依据和结构化 domain。比较的是源码默认值及 AI 建议，不能用它代替用户实际运行配置。字面或引用变化也会列出，不自动判断参数数值或语义等价。
- 候选按用途和名称、独立问题按类别和标题配对。条目增减、定义/引用变化和严重度变化可见，但不据此合并因子、不认定公式等价，也不宣称问题刚刚出现或已经修复。
- 同名多项标为无法配对，保留两侧数量，不任意选一个作为对应项。至少一侧缺少参数、候选或同版本问题清单时，该项比较保留未知，不能把旧版未检查当作“以前没有问题”。空数组与没有提供记录分别处理。

以上结构化记录始终来自不可变 AI 原稿。手工修改正文不会改变原稿的评分、默认值、候选或问题清单。严重度本身的含义见[源码问题清单](./源码问题清单与严重度说明.md)。

## 正文与人工修订

正文有两个口径：AI 原稿正文、已保存的修订正文。默认比较两份不可变原稿；切换后比较两侧当前已保存的正文，没有修订的一侧仍用原稿，未保存编辑不会混入对照。页面标明两侧是否已有人工修订。

正文逐行匹配，统一 CRLF/CR 为 LF；增删用符号、颜色及两侧行号区分，并保留附近上下文。文本通过 React 文本节点展示，不执行 Markdown、HTML 或源代码。该对照只能定位文字变化，不能替代 AI 语义复核或实验。

本机计算限制：每侧最多 240,000 字符、1,200 行、两侧行数乘积最多 360,000；逐行最长公共子序列使用有界矩阵。超过上限显示“未计算完整差异”，差异数量为未知而非零；完全相同的原文可直接判断一致。最多展开 40 处变更，额外变更明确列出省略数量，完整原稿仍可在报告中阅读。长内容在卡片内滚动，手机正常换行，不横向撑大页面。

## 数据、同步和代码入口

没有新增业务持久字段或后端接口，无迁移；量化同步保持 schema 46。已有原始报告、结构化数据和人工修订继续按已确认范围同步。基准选择、正文口径和计算出的差异是可随时重建的本机阅读状态，不进入 WebDAV/FTP/SFTP，不恢复执行权限。

入口：`utils/quantReportDiff.ts` 负责基准选择、字面配对、评分边界与有界逐行计算；`types/quantReportDiff.ts` 定义结果；`components/Quant/reports/` 拆分卡片、原稿记录和正文展示；`ReportPanel.tsx` 只编排入口。`QuantReport.data.parameters` 描述后端原本已经返回的字段，不是新数据结构。纯 local 路由样例保留多份原稿及修订，前端测试覆盖实际本地重新分析→发布→对照→修订链路。

本地验证：106 项量化前端测试、类型检查、定向 lint、生产构建、文档链接与差异空白检查通过；构建仍有既有的大 chunk 提示。浏览器在实际纯 local 应用中走通第二份原稿生成、原稿相同提示、保存人工修订及增删行对照；791px 实际页面及 390/1440px 真实组件预览验证了未知评分、参数前后值、窄屏换行和内部滚动。尺寸预览使用人工数据且已移除。没有新增模型请求、部署或正式数据库操作；真实模型质量及完整目标仍待验收。
