审查曾将“含完整指标列与亏损/回撤记录”摘成“含亏损/回撤记录”，不再属于逐字子串。新流程向模型提供完整文字区间及text_ref，由程序复制冻结原文并保存路径/起止位置；禁止拼接引文。注册表按字段排序，新旧注册表恢复只按唯一ref规范化顺序，内容及边界仍须逐字一致，其他数组不重排。

指标历史无损列式编码，保留每次尝试、失败原因与空值，附程序计算的训练/验证收益符号计数。本例模型上下文39569→39044字符，包含新增位置事实后净减少525；这不能证明显著节约tokens或费用。
