# 因子研究分层与准入

核对日期：2026-10-26。应用1.5.50、量化schema53、迁移0028。本文说明已支持的受控表达式研究层，不代表全部平台执行或全系统目标已完成。入口是算法详情“实验与历史研究记录”中的“研究分层与准入”；当前主流程见[源码算法提取](./源码因子算法提取说明.md)。AI自动提取、程序结构检查和证据归集继续是主流程，用户无需手写准入报告或手动挑选分数。

## 分层规则

程序在候选发布、人工/AI公式修订、实验衍生及直接证据归集时，保存不可变FactorAdmission。只读取已有固定事实，不启动AI、源码、行情或平台执行，也不修改AI研究评分、经济有效性字段或当前研究版选择。

| 最高已记录层 | 准入依据 | 保留的限制 |
| --- | --- | --- |
| 候选 | 结构或声明依赖仍有阻断 | 观察不能绕过结构阻断 |
| 可复用受控定义 | 现有结构与声明依赖检查通过 | 未验证原平台语义；默认值缺失与实际输入另行检查 |
| 有直接计算记录 | 同版本表达式有有效计算输出 | 输出可能不一致；计算不等于收益或平台等价 |
| 有历史实验记录 | 本版本直接尝试在已完成实验中被计算 | 保存全部直接参数变体、拒绝/失败及实际分段，不继承其他父代或组合的收益 |
| 有固定区间评价 | 固定公式/参数在指定区间完成评价 | 普通复核、复用数据、无标准或标准未满足都不进入更高层 |
| 有预登记达标范围 | 完整计算满足事先登记标准，并满足现有fresh、登记后导入及启动/发布时已知数据使用核对 | 仅该公式、参数、输入、市场、成本、标准和区间；外部使用未知，全局独立性仍为false |

层级是“曾存在相应范围的研究记录”，不表示当前所有配置都有效。登记标准由登记时的规则决定，例如仅限制回撤可以在亏损时满足；系统不补造“收益为正”的隐含门槛，也不把满足宽松标准宣传成盈利认证。不同规则、参数、市场或后续区间分别保留，不能用一个好结果覆盖反例。

结构阻断优先：即使存在计算记录，准入仍停留候选；原始观察层与阻断原因同时保存。原函数输出不一致会保留为需复核记录，可以说明“确实有计算”，不能据此认定输出一致或原平台已验证。用户上传的回测、模拟、实盘声明及AI评分本身均不提升验证层级。

## 版本与范围

每条记录绑定同一个FactorCandidate、FactorQualification与可选FactorEvidenceLink的身份和哈希，规则版本固定为1。数据包括实际参数、输入绑定、市场/价格口径、成本与策略配置、样本或计划范围、登记标准/核对条件及原始证据指纹。程序不把源码默认值补成本次实际值；固定方案中的规范化recipe参数名和名称映射保持原件。

新公式只有自己的结构准入记录。父代、祖先、同名候选、逻辑分组和当前研究版切换都不会授予新公式旧版层级。因子库新增“研究分层”筛选，按当前展示版本的最高已记录层精确筛选；稳定谱系或逻辑分组的旧成员即使达标，也不能让不达标的展示版本命中该层筛选。其他文字/分类筛选仍按原分组规则。

详情按记录分页，再展开该记录的全部配置；记录数量、需复核数、登记标准满足/未满足数明确分开；两项都为零时显示“尚无登记标准判定”，不推定已完成评价。归集记录可以包含负收益、输出差异、取消和未知，不删除这些信息。可查看原始冻结配置与指纹，下方原有验证区仍保存完整实验与评价依据。

## 未完成的评价与旧记录

固定评价失败或取消时，新直接证据保留result_status/error、空指标和空层级；publication_audit为null，不能显示成零重叠。其分层记录保留实际冻结参数、计划区间、停止原因及未知标准，范围标为planned_not_completed，不进入固定评价或预登记达标层。

新候选与新直接证据标记admission_version=1，必须带对应准入记录。旧数据默认0，恢复不借用当前设备的新标记，不自动补建准入。可显式按页归集已有分层记录；若旧实验/固定评价/原函数对照尚无证据链接，先使用原有“归集已有证据与结构检查”，现在该入口覆盖实验、对照、反馈、固定评价（含失败/取消）与原始Python五类。两种归集均不重新计算，不消耗模型调用。

## 同步与权限

按用户已确认的量化业务数据同步范围，FactorAdmission与candidate/evidence的admission_version全部进入WebDAV/FTP/SFTP，schema53保护新合同。迁移0028只增加业务字段与表，旧记录保持0；没有在本批执行真实业务数据库迁移或部署。

恢复先校验原始候选、结构与直接证据，再逐条重建准入决定、范围、哈希、唯一性、归属与先后时间；重算哈希也不能伪造晋级。新标记的记录缺少规定准入时拒绝恢复，旧完整备份可裁去后来归集的准入记录。执行队列/租约不恢复，没有新增执行授权。列表只读摘要，详情和归集沿用所属用户/文集权限，软删研究不可访问。

本批同时修正同步变更追踪对级联删除对象的外键读取：使用原始attname值，不在相关对象已删除后重新取对象；稳定实体身份规则不变。
