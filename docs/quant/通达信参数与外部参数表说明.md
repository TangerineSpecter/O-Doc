# 通达信参数与外部参数表

核对日期：2026-10-27；应用1.5.66、量化schema67。本地实现，未部署。本文说明当前参数来源和实验边界；完整产品目标仍见[重构规格](../requirements/007-AI量化研究系统重构.md)，通用身份规则见[源码参数身份](./源码参数身份说明.md)。

## 当前流程

收集时选择“通达信公式”，粘贴源码即可归档和交由AI研究；不要求用户写报告。若原公式编辑器另有参数表，可把整张表放入现有说明栏，保留四列表头，例如：

```csv
参数,最小,最大,缺省
N,2,60,20
```

支持CSV、TSV或空白分隔，可调整列顺序；也接受参数名/名称/name、最小值/min、最大值/max、默认值/default等明确表头。说明栏此时只放整张表，不从自由文字猜默认值。若要同时保留其他说明，归档后在“补充依赖源码”上传原CSV/TSV；沿用不可变来源补交机制，产生新来源并可自动重新分析。只有通达信来源接受CSV/TSV补交；其他语言继续使用源码附件。旧版本及旧报告保持原样。

没有参数表仍能收集和分析，缺失默认值保留未知。当前自动语言识别未覆盖所有只有冒号输出的公式；不能识别时需显式选通达信。未支持加密公式文件或从终端读取参数。

## 声明、状态与建议分别记录

服务端只解析完整分号语句和有明确表头的数值表，不执行原平台表达式。

| 材料 | 当前记录 | 是否当作原始可调输入 |
| --- | --- | --- |
| `N:=20;` | 字面初值，constant | 否；改变它仅是受控表达式的新假设 |
| `M:=MA(C,N);` | 计算赋值，state，默认值空 | 否 |
| `OUT:M;` | 公式输出，state，默认值空 | 否 |
| 外部参数表的N | external_parameter，默认20、范围2–60 | 依用途分类；表中定义不证明实际运行配置 |
| 缺表的N或冲突声明 | unresolved，默认值空 | 不进入原始可执行候选 |

同名或仅大小写不同的公式/参数表记录保守地标记冲突，不按名字选一个，包括说明表和附件重复声明。需要保留一份明确的定义后新建分析；该规则不是原平台名称解析或编译认证。计算赋值、输出和未知表达式不能被模型写成猜测的默认值。引号可能表示外部指标/证券引用，不能按字符串旋钮处理。

目录v2保留原名、文件、作用域、原文、行号、默认字面量、冲突及外部范围。说明/parameters栏行号相对于该栏；附件行号相对于完整来源正文，文件名另列。稳定内部符号用于表达式，不取代原名或来源证据。

## 参数范围与实验

参数表的默认值和最小/最大值由系统写入domain v5，模型不可改写。v5只表示数值边界，不推断步长、枚举、算术依赖或条件规则；现有v1–4合同不变。类型暂按默认字面量记录，未核实终端类型。表中上下限不是经验最优区间，AI建议仍需附前提和验证计划。

原始因子候选复制参数阶段的完整记录；首轮方案、人工实验准备和执行重新校验该范围。请求基线越界会拒绝；搜索中的越界变体留为rejected尝试，不静默裁剪或填成有效结果。参数方案、实际计算值及源码默认值独立保留。行情实验使用受控表达式，不把翻译或内部计算当通达信原平台验证。

新普通/增量工作流为25/26，使用目录v2；旧1–24的提示、报告及同源续作仍使用原合同，21–24目录v1不追写。比对仍使用23起的方法v2，实验解读仍为15，没有提高评分或实证等级。

## 预算、同步与实现入口

公式包沿用150000字符、300条声明和160000字符目录预算；单张参数表最多16000字符、300条参数，表头/单行最多3000字符。识别出的表格只要列数错误、数值不有限、默认越界或超限，整个目录保留limited，不用局部结果冒充完整；公式括号、注释、引用或末尾分号不完整时保留unparsed。不能识别成表格的自由文字不产生默认或范围。新工作流模型调用与时间预算沿用23/24。

参数目录、来源身份、范围、报告及候选保存于既有业务JSON，CSV/TSV原文保存于既有SourceRevision.files；均按用户已确认范围纳入WebDAV/FTP/SFTP。schema67拒绝旧客户端恢复新格式，无新表、字段或数据库迁移。新设备从原始材料重建目录和参数事实，校验父代与原报告；恢复不调用模型、不重建本机执行队列或授权，凭据不进入同步。

- `quant/parameters/tongdaxin_inventory.py`：完整语句和参数表解析。
- `inventory.py`、`bindings.py`、`domains.py`：目录v2、绑定、v5范围、发表及恢复校验。
- workflows、research、supplements：分阶段输入、报告、新来源及历史合同。
- `TongdaxinParameterHelp`、`SourceSupplement`、`ParameterSource`、`ParameterDomain`：可选输入、原文及边界展示；文件读取仅在通达信补交入口允许CSV/TSV。
- local的`LOCAL_TDX_PARAMETER_TABLE`为明确标注的人工预制流程，不解析上传表、不调用模型、不计算行情，不证明真实提取质量。
