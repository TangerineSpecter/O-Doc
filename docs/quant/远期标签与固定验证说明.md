# 远期收益标签与固定验证

核对日期：2026-10-27；应用1.5.67、量化schema68。本地实现，未部署。当前固定验证支持预登记多期标签；搜索/多内层已在1.5.68接入可选标签目标，详见[搜索中的远期标签](./搜索中的远期标签说明.md)。完整目标继续按[重构规格](../requirements/007-AI量化研究系统重构.md)实施。

## 登记和计算

在已评价尝试上登记固定验证方案时，可选“同时登记远期收益标签”，明确未来1–2000根柱。系统冻结原公式、实际参数、成本、目标和截止点，再绑定后续行情；不能在看到新结果后改期限或挑起止点。原收益/回撤等登记标准仍可同时启用，标签IC不替代这些标准。

目标合同为`close[t+horizon_bars]/close[t]-1`，预测值为同一柱收盘时的受控因子输出；布尔输出按0/1处理。柱数按导入行计，非日历天数，不推断导入数据连续或已覆盖全部市场柱。行情timestamp仍是bar label，不证明原平台真实可得时点。固定验证原有的下一开盘成交、费用、滑点和完整账本不变，标签收益与交易收益独立计算。

标签只在冻结评价段[start,end]中配对：保留start至end−h的起点，要求每个标签终点t+h≤end。先剔除最后h个跨界起点，再统计其余起点的缺失预测值。总可配对起点为end−start−h+1；至少5个，否则登记/绑定失败，不能延长行情或缩短期限后冒充原计划。起止边界按已登记的第一段新数据确定，不按IC选择。

## 指标及未知

程序保存有效配对、缺失预测、跨界剔除、覆盖率、原文范围、配对哈希、Pearson IC与Spearman IC。Spearman按精确并列值取平均秩；Pearson使用缩放后的中心化向量，防止大数平方溢出。有效配对少于5对、常量或接近常量输入保留null及原因，不填0。所有数值来自本机受控表达式与冻结行情，不接受模型填写指标。

h>1时标签可能共享未来价格；配对数不等于独立样本量。当前只提供描述性相关，p_value和independent_observations始终null，不做显著性、多重检验或置信区间，也不把相关变成金融有效性或最优参数结论。selection_used始终false，这条路径不搜索参数或重选公式。

计算和既有固定验证共享时间、取消与授权检查。超时/失败不发布部分标签为完整成果，原计划和行情预约保留。既有[数据使用审计](./固定方案新数据验证说明.md)仍核对已知重用；标签全部包含在原评价段内，不扩大审计到未声明未来。看到结果并进入后续研究后，该段不能继续称独立未见验证。

## AI和界面

固定验证AI输入复制label_evaluation、冻结目标与原交易事实；提示要求分别解释期限、有效/缺失/剔除、Pearson/Spearman及未知，不将IC当成本或收益。候选的直接固定验证证据也保留目标和标签结果；不增加新的实证晋级等级。原收益标准的判定和资格规则保持。

登记弹窗提供可选目标与期限，详情以独立“标签评价”区显示，保留数值为0与未定义的区别，可展开标签区间和解释边界。先登记但未绑定行情、运行中、失败、取消及无有效相关均有明确状态；不要求用户自己撰写研究报告。

## 版本、同步和入口

启用标签时，ValidationPlan/Result使用v3、计算引擎quant-fixed-validation-2；v3可有或无原登记收益标准。未启用的旧v1/v2、引擎1、报告及同源恢复不变，不能给旧事实事后加目标。新数据全部保存在已确认同步的既有业务JSON内，纳入WebDAV/FTP/SFTP，schema68要求参与端升级。无新模型字段或迁移。

同步从原来源尝试重建目标、区间、公式、参数、完整交易结果和标签指标；重算外层哈希不能伪造跨界剔除或IC。恢复不读取外部数据、不调用模型、不运行上传源码、不恢复本机队列或执行授权。

- `quant/label_studies/targets.py`：严格目标和边界合同。
- `statistics.py`、`calculation.py`：平均秩、相关和完整标签配对。
- `validation_studies/{contracts,calculation,worker,evidence,sync}.py`：预登记、执行、AI与恢复。
- `verification/evidence.py`：直接候选证据；不添加标签晋级。
- 前端`quantLabels`类型/纯逻辑、登记Hook、LabelEvaluation组件；local样例独立模块，只构造人工展示数值，不计算上传行情或调用模型。
