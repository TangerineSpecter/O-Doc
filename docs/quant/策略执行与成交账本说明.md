# 策略执行与成交账本

核对日期：2026-10-25。应用 1.5.34、量化同步 schema 42；无新增数据库迁移。当前实现为受控表达式上的参考策略模型，原平台代码、EA、经纪商成交及独立验证仍未完成。入口见[量化文集当前说明](./量化文集一期说明.md)。

## 适用范围与入口

在因子库手动准备实验，或采用 AI 首轮方案时，可启用“明确的策略执行规则”。原始代码、提取定义、信号参数、AI 建议和实际提交配置分别保留。不开启时仍使用原来的做多／空仓模型，旧实验不自动升级。实际计算只执行声明式受控表达式；不会执行上传的 Python、Pine 或 MQ4。

来源分析 workflow v10/v11 在原 v8/v9 的步骤上增加可选策略规划能力，模型调用预算仍为普通7次／跨源码8次；无修订目标时少一次。旧 v1–v9 的输入和提示不变。AI 必须解释执行设置是来源声明还是待检验假设；不得称为已验证的最佳参数。首轮方案可省略 strategy，但选用时所有字段必须显式完整。止损／止盈停用为 null，未知实际账户设置不补成0。

## 固定执行合同

`strategy.version=1` 在整个实验批次固定。常规搜索引擎为 `quant-local-search-5`，滚动验证为 `quant-local-search-6`；每折独立空仓、重做训练／验证选择并保存自己的测试账本。原引擎1–4继续按原合同读取和运行。

- 数值多头入场为信号大于 config.threshold，多头退出为小于等于 long_exit_threshold；空头入场为小于 short_entry_threshold，退出为大于等于 short_exit_threshold。多退不高于多入，空退不低于空入，双向入场区间不能重叠。持仓区间内保留原方向，形成明确滞回。
- 允许方向为只做多、只做空或多空。布尔 true 仅触发明确选择且被允许的方向，false 表示无信号，不自动变成做空。缺失信号平仓并单独计数。
- 上一根已收盘信号决定下一根开盘操作。开仓按当时净值的指定比例，数量固定到退出，不逐根再平衡；开仓预算含入场手续费：净值E、比例f、单侧费率c时，成交名义金额为E×f／(1+c)，数量取名义金额除以含不利滑点的成交价；因此手续费不会额外挤占预算。允许参考分数数量，不等于真实手数。比例为(0,1]。
- 单侧费用／滑点沿用实验 config。买卖分别计费，滑点总按不利方向调整成交价。做空每根持有柱按柱首开盘价格、持仓数量和指定 bps 计借券成本。该费率是按柱假设，不是年化融资或平台实际费率。
- 固定价格止损幅度为(0,100%)，止盈为(0,1000%)；允许做空时止盈必须小于100%，保持正目标价。价格基于含滑点的入场成交价。同柱同时触及止损和止盈，保守按止损先行；跳空止损按开盘价，跳空止盈按目标价，再扣不利滑点／退出费。OHLC无法恢复真实盘中路径。
- 开盘先处理跳空风险，再处理持有期和信号。止损、止盈及持有期退出后，同柱不重入；退出后冷却柱数0–2000，0表示下一柱可再入场。同开盘先平后反向仅在明确启用且冷却为0时生效，两次单侧费用都保留。
- 最多持有柱数0–2000，0表示停用此限制；每段开仓上限1–2000，达到后继续管理已有仓位但禁止新增。段末开盘强制平仓，不使用段末柱的高低价或后续信号。
- 资金耗尽在开盘及模拟成交／费用时观测；按不利滑点和费用关闭持仓，停止本段新交易，保留负净值与资金缺口。不假设负余额保护，也不模拟盘中保证金强平。训练／验证资金耗尽的尝试保留损失并拒绝参加选择；留出资金耗尽照实记录。

买入持有对照沿用本段起点、仓位比例和费用，进行一次多头持有，停用信号退出、止损止盈、持有期及做空费用。它是同仓位／成本的价格基线，不能称为同风险策略。

公式演化、交叉和信号参数搜索不会修改上述执行规则。当前不能在单批中自动优化仓位、止损和费用；需另行准备不同配置、保留对照，并声明新数据要求。

## 结果、AI 与同步

训练／验证逐尝试保存 execution 汇总：手续费、借券费用、已实现净损益、资金缺口、入场预算阻止柱数和退出原因。选中方案及买入持有的留出结果保存完整成交列表，包括信号／开平仓柱、时间、原始参考价、成交价、数量、入场净值、各项费用和损益。滚动验证每折分别保存。成交结果在发布前检查有界同步大小；超限整段结果不发布，不截断账本冒充完整，保留尝试与失败原因，需减少区间、折数或开仓上限后新建。金额以每段初始资金=1归一，数量为参考分数数量；回撤按开盘采样，不等于盘中最大回撤。

策略实验只使用 AI 实验解读 v8，保留冻结配置、全部失败／中止尝试、资金耗尽和未完成折。模型获得汇总和最多6笔按时间取首尾的留出成交样本，明确记录省略数量；完整账本仍在结果页。没有原生编译、平台对照或真实账户证明时，不得升级证据级别。下一轮和连续研究方案继承完整执行配置，文本中的不同执行假设不会暗中改变运行规则。

按用户已确认的范围，策略配置、执行结果、账本、提案与解读继续全部纳入 WebDAV／FTP／SFTP。没有新增表或本机授权字段；执行队列、租约、模型凭据和向量索引仍留本机。恢复校验新引擎与配置绑定，重放选中方案／基线的受控表达式和冻结行情，逐项核对费用、成交及净值。每段有界校验，不做搜索、模型调用、原生代码执行或新队列授权。旧实验、工作流和解读按其原版本保留。
