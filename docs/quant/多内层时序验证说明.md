# 多内层时序验证

核对日期：2026-10-26。应用1.5.54、量化schema57。此能力已接入本机受控表达式与显式策略实验，以及AI首轮与反馈规划；原平台执行、完整跨请求多重检验和整体重构验收仍未完成。

## 用户操作与实际选择

粘贴源码后，新来源工作流16/跨源码17可自动提出多内层首轮方案；反馈选择5也可提出完整配置。三个AI入口共用冻结的planning_capabilities v1，明确窗口、预算、最低数据长度、实际选择规则和未知条件。多个参数或公式探索优先考虑v2，简单或数据不足的研究仍可采用v1或不提出方案。建议不表示参数已经最优，也不自动执行。

点击“按此方案准备实验”会沿用内外折、预热与参数；也可在“参数与组合实验→准备实验”手工开启滚动验证和“多次内层时序验证”，选择每外折2–4个内层窗口。调整保留原方案并标记实际差异，数据不足时显示最低根数并阻止启动。

新实验解读12/冻结上下文6同样收到能力说明及全部内层事实，其下一轮proposal继续沿用execution.config和预算，不能在该入口增加config或擅自切换验证策略；需要改变时解释后续步骤，通过新的来源/反馈方案或显式调整准备。连续研究核对实际行情和剩余预算，不扩大授权。旧来源14/15、解读10/上下文5及反馈选择4保持原提示和历史输入，不追加新能力字段。

每个外折从冻结原始父代重新搜索，全部候选分别计算各内层训练和验证窗口。训练收益、回撤、换手各取算术均值，与公式复杂度一起做Pareto筛选；验证收益减回撤的均值越高越优，再依次按验证换手均值、复杂度、公式指纹排序。均值等权，不拼接净值。公式演化的Pareto父代也使用内层训练汇总，保留既有随机探索。

任一内层训练或验证段全部信号缺失、或策略资金耗尽，该尝试保留记录但不参与选择。所有内层完整评价后才产生汇总；取消、超时或计算失败保留已完成/部分完成的内层指标，不填补后续窗口。

选定后才计算对应外层测试及同成本买入持有。改变这个外折的测试或未来行情不会改变其内层记录和选择。后折允许使用已过去的前折测试历史；跨实验使用情况仍未证明。顶层选择和单条曲线对应最后已启动外折，不能挑测试成绩最好的一折。

## 窗口、预热与预算

冻结配置沿用walk_forward字段，v2增加inner_folds。v1记录不升级。内外层共用mode：expanding保持训练起点，rolling保持训练长度；每个内层向前推进validation_bars个收益区间。相邻验证段只共享边界价格，不重复收益区间；训练历史可以重叠。训练与验证、最后验证与外层测试之间各保留gap+1的索引间隔，沿用原先下一开盘成交约定。

第一个外折、最早内层训练长度为train_bars。内层j（从0起）和外折k推进量为k×test_bars+j×validation_bars。每个内层计算从自己的训练起点减1再减warmup_bars开始，到该验证段末尾截止；rolling不会偷用更早内层的额外计算历史。外层测试重新从最后内层的计算起点计算信号，包含隔离段的已过去行情，但不参与开发评分。

至少需要 `2 + warmup_bars + train_bars + inner_folds×validation_bars + folds×test_bars + 2×(gap+1)` 根，且整体行情仍为60–20000根。默认40/10/10、3个外折及3个内折、gap1、无额外预热时至少106根。

全批最多32个候选尝试、4代、60秒，总候选预算仍分配给外折，种子逐折递增。每个候选增加2–4次内层评价，不增加候选额度；更高计算量可能使既有时限更早耗尽。每个区段独立空仓起止，费用、滑点和显式策略假设保持冻结，不自动推荐盈利参数。

## 记录、展示与AI

嵌套实验使用quant-local-search-7，显式策略使用8；每外折的search_engine_version记录所复用的2/3/5搜索核心，外层7/8、选择规则与内层记录共同确定新增行为。walk_forward结果版本2保存inner_windows；每个尝试的inner_evaluation保存逐内层指标及完整后的三项均值。原顶层metrics只投影最后已启动内层窗口，不冒充汇总。

新增[跨窗口参数复核](./跨窗口参数稳定性说明.md)按全部计划外折/内层分别检查同参数，取共同离散区域；新AI解读使用独立v2评分门槛，原单窗口摘要仍保留。

列表的选择列显示内层均值；选中尝试展示各段验证时间、训练/验证收益、验证回撤、入场和缺失数。没有汇总显示未知。策略账本摘要及单/多参数敏感度仍只描述最后已启动外折的最后已启动内层窗口，并明确标注范围；全部内层的共同区域由新复核单独判定，不能把旧摘要当成此结论。原固定家族CSCV诊断也只重放各外折最后内层的开发区间，不能代表全部嵌套搜索或跨请求校正。

实验AI输入保留每一失败、取消和已完成尝试，新增全部内层指标、汇总与范围说明，剔除曲线和完整成交明细。既有160000字节证据上限仍适用，超限明确失败，不静默丢弃内层或负面结果。

deepseek-flash已在已有真实分析事实上单独完成一次新规划调用，自动选择3外折×3内层、保留声明默认period=14、提出7/10/20/28并算出最低136根。该原始方案在已归档官方行情上的16次尝试通过102段独立Decimal核算，三个外层测试均亏损。行情此前已用过，属于开发复核，不是新的独立验证；这也不是新一份完整源码报告或原生Python执行。捕获、零调用重放与精确范围见[AI规划验收](./AI多内层实验规划验收记录.md)。

模型选择和评价隔离的原理参考[Cawley与Talbot原始论文](https://www.jmlr.org/papers/v11/cawley10a.html)。这里采用保序历史窗口，没有随机打乱时序；内层重叠不构成独立重复样本，也未据此提供统计显著性或盈利保证。
