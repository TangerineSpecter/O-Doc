## 使用流程

因子详情提供“原始Python验证与AI解读”。选择本候选报告固定的Python来源、一份已导入行情、当前候选的实际参数和输入列，明确原函数名称及所有函数参数映射，再运行固定片段。普通收集、静态分析、上传、阅读和恢复均不会执行上传代码。

签名扫描仅解析语法，不求值、不导入原模块。同名行情列和候选参数可作为映射提示；未识别的参数须明确指定。运行时原模块按Python规则初始化，因此导入、全局语句和默认表达式仍会在隔离进程中执行；调用函数时全部参数均显式传入，不使用函数默认值代替本次实际配置。候选表达式实际参数与原函数显式映射分别记录；源码中的全局常量或硬编码值仍按原文执行，不会被候选参数改写。

映射支持单列OHLCV序列、明确列集的DataFrame、当前候选实际参数、数值/布尔/文本/None常量。可指定从零行号或UTC时间索引；DataFrame/字典输出须指定列名。固定30–20000行，源码运行1–30秒，预热0–2000行，共同预热后至少保留30行；容差0–0.001，默认绝对1e-9/相对1e-8。不会自动移位、补齐、重索引或分别删除两侧缺失值。Series索引须完全一致，列表/一维数组按原位置返回，长度须与输入一致；NaN映射为缺失，Infinity及类型错误拒绝。

HTTP展示将候选实际参数投影为name/value列表，完整核算事实以computed_native_json保存字面键，避免全局驼峰转换改写源码参数名。

原始存储文本及补交的依赖文件保持不变，并按UTF-8编码执行、记录逐文件哈希；不是原文件二进制编码认证。新源码须先重新分析生成对应候选，不能将另一版本源码挂到旧候选上。支持通用顶层Python函数，不承诺执行任意Notebook、平台回调框架或需要外部SDK/数据服务的程序。

## 程序事实与AI报告

受控表达式在宿主的声明式引擎计算；原始函数在独立容器的低权限进程运行。保存完整原始输出、逐行比较、实际参数、映射、行情哈希/范围、源码哈希、镜像ID、运行器哈希及Python/pandas/numpy版本。

完成或失败后，默认自动归档绑定该结果的结构化反馈并使用默认对话模型解读。先保存计算事实，再调用模型；模型缺失、连接失败、格式或证据校验失败不会删除计算结果。取消不会调用模型。可关闭本次AI解读；已归档材料可在来源研究中重新发起解读。

报告固定呈现程序记录的参数、函数映射、样本、容差、环境和计数。AI须原样确认计算判定及实际参数，再解释语义范围、差异、默认值与实际值、参数敏感性假设和可否证的复核步骤。计算事实不要求模型重复摘录JSON；通用外部参数/指标/引文数组保持空，避免将输出一致性冒充收益。后续方案若提出，其基线是本次明确的实际参数；先解决函数与提取候选范围差异，再讨论收益实验。无合理可比较定义时不强行生成实验方案。

仅`pass`增加当前公式版本的“本次原始Python输出一致”有限层级；完成但失败/证据不足保留观察及反例。失败或取消不产生成功层级。单位和用途仍取候选声明，未独立认证；不提升原报告质量分，不继承祖先证据，不认定平台/全局等价、最优参数、经济有效性或全局独立验证。

## 本机运行器

需本机Docker。安装通过显式命令进行，HTTP请求和恢复不会拉取、构建或安装镜像：

```sh
UV_CACHE_DIR=/private/tmp/odoc-uv-cache uv run --python 3.11 python -m quant.native_python.build --build
```

构建器从官方Python镜像取得不可变摘要，安装锁定版本的numpy/pandas及依赖。构建上下文仅包含运行器文件，不包含项目源码、配置或凭据。运行时固定镜像ID并使用`--pull=never`；探测核对可信监督器和子进程脚本哈希，脚本改变需显式重建。

容器无网络、无主机目录/环境变量/套接字挂载，根文件系统只读。可信root监督进程仅保留SETUID/SETGID/KILL，用于降权和终止源码进程；源码UID/GID65532、无附加组和有效capability、no-new-privileges。限制1CPU、256MiB内存及swap总上限、32进程、32MiB临时目录、文件/输出/CPU/墙钟时间；关闭Docker日志存储源码输出。宿主仅按随机名称及匹配的令牌/协议标签清理本次容器，不清理其他容器。可信监督器不导入源码，独立观察输出与超时；执行权限撤销会停止宿主等待并清理本次进程。

这是受限Docker执行范围，并非对宿主内核或Docker守护进程的形式化安全认证。需要其他依赖的源码保留明确失败，不临时联网安装。聚宽SDK/数据访问和Pine/MQ4平台语义仍另行实施。

## 持久化与同步

NativePythonRequest、NativePythonResult、当前候选的直接FactorEvidenceLink、自动归档的反馈SourceRevision及AI报告全部按已确认的WebDAV/FTP/SFTP范围同步。任务、owner授权、lease、取消状态和本机模型选择保存在NativePythonJob，仅本机使用，恢复时删除，不同步或恢复执行权。凭据和Docker安装状态不写入研究事实。

恢复核对归属、固定版本、时间、请求标识、全文哈希、环境结构和不可变冲突；用保存的原始输出重新计算受控表达式及比较。恢复不运行原始源码、不探测Docker、不调用模型，也不将历史镜像记录当作本机执行授权。该数值重放验证内部一致性，未对远端记录签名或认证原平台真实性；远端多设备交换仍待验收。

代码入口：后端`quant/native_python/`分别负责合同、运行器、计算、队列、HTTP、证据、AI归档及恢复；前端独立`api/quantNativePython.ts`、`useQuantNativePython`、`Quant/nativePython/`、类型/解码器及local样例。真实验收见[Python原始函数实测](./Python原始函数真实验收记录.md)。
