# Python逐文件依赖

核对日期：2026-10-27。应用1.5.65、量化schema66；本地实现，未部署。补交流程见[依赖源码补交](./依赖源码补交与重新分析说明.md)，报告合同见[源码变化AI复核](./源码变化AI复核说明.md)。本功能建立所提供正文之间的静态候选关系，不实际导入模块、读取安装包或执行源码。

## 当前流程

普通自动分析使用工作流23，仍为10步、最多7次模型调用、840秒。补交文件包后默认排队的分析使用23，在同一逐文件结构上增加[源码参数身份](./源码参数身份说明.md)。每份文件分别读取Python3.11语法和符号表，主文件与依赖文件有独立模块作用域，再按显式导入建立候选；不把拼接后的代码当作一个Python模块。

用户明确选定同材料已完成基准后，新的增量研究使用工作流24/片段方案3，仍为11步、最多8次模型调用、960秒；单次调用120秒，无自动重试。旧1–22工作流沿各自合同，其中1–18的片段方案1/2仍原样重建。新的普通单文件也使用虚拟文件名`__source__.py`，仅用于稳定定位，不表示磁盘实际路径。

例如主文件`from helper import calc`、`factor(x)=calc(x)`，依赖文件`N=20; M=N*2; calc(x)=x*M`。依赖中的N改变，可沿N→M→calc→主文件factor传播“潜在影响”；主文件自己的同名N不会因名称相同而连入该链。显示名为“文件名::符号”，ID同时绑定文件身份与词法节点；同名函数/变量不能跨文件混用。

支持精确提供的模块路径、`from ... import ... as ...`、模块别名及显式点路径、包内相对导入和静态再导出。`from 包 import 子模块`只建立候选并保留包初始化未知。模块文件与包入口同名、导入名被重复赋值、星号/缺失/动态导出、循环导入和属性对象不明均保留未知，不依据同名文件或本机环境猜测。

普通形参读取不指向函数值。闭包或嵌套默认值依赖外围形参时，另记“形参所属函数”关系，表示输入来源作用域，不表示调用了该函数。类、lambda、推导式/生成器、global/nonlocal写声明、循环、with、异常绑定等暂未求解时，保留该文件内的语法候选并标记partial/未知，不把其他文件拼进该作用域。

## 来源与模型边界

只使用SourceRevision已保存的文件正文。逐份核对SHA-256、主文件顺序、规范组装及全局行号，拒绝正文/文件边界不一致；路径只作字面模块身份，不打开本机路径、不调用Python导入机制。导入匹配是候选，不证明运行时安装路径、包初始化、钩子或终端版本等价。

全包最多150000字符、6000行、12000语法节点、256结构节点、256导入项；名称解析最多4096次工作、再导出深度16，属性链最多4层。工作量或文件身份不能确认时，返回limited/unparsed及限制，不输出残缺图冒充完整；语法引用最多2048项，超过时明确partial。完整原文继续保存并供AI逐段阅读。

参数、研究与候选提取等阶段的source_structure同时投影调用和数值读取，最多128条引用、64条导入，保留省略数量；不给模型另复制一份源码或不透明节点ID。原文仍带完整全局行号和文件范围；同名参数须保留各自文件出处，不能视为同一个实际运行配置。新23/24及历史21/22通过[源码参数身份](./源码参数身份说明.md)区分同名声明、内部符号和默认事实；自动原生运行参数映射仍未补齐。

增量报告使用source_change_review_version=2及事实v2，继续按24节点/18000字符选择变化线索，要求AI逐项复核。文件/符号以代码字面量展示，避免`__source__.py`等名称被Markdown解释成强调。旧工作流18的v1报告、旧提示和旧评分不重写。图谱不证明全局运行时语义或授权跳过全部未变化的全局阶段；评分和全局研究仍新审查。
