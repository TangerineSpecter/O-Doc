# MQ4 策略候选导出与归档

核对日期：2026-10-25。应用 1.5.35、量化同步 schema 43、迁移 `0023_strategy_artifact`。本说明描述本地已实现的候选生成／归档，不代表 MT4 原生编译、运行或平台等价性已通过。总入口见[量化文集](./量化文集一期说明.md)，参考执行规则见[策略执行与成交账本](./策略执行与成交账本说明.md)。

## 入口和对象

参数与组合实验中，启用显式策略规则且已发布结果的实验，可选择一个实际评价通过的尝试，再“导出当前尝试的 MQ4 EA 候选”。明确显示尝试序号、滚动折号、实际公式参数和完整执行假设。失败、未运行、旧指标模型和无法确认真实成交量映射的公式拒绝导出；不把指标直接当作 EA。可以导出非最终胜出但实际评价过的候选，不暗中替换成胜出方案。

GET `/api/quant/:collection/experiments/:id/strategy-export/?attemptId=...` 仅生成代码和来源清单，不保存代码版本、不调用模型或执行器。POST 同一地址按 actual attempt 幂等归档；API没有终端连接或交易授权功能。预览和归档都经过当前用户／私密文集所属校验。

归档创建独立 `StrategyArtifact`、`Implementation`、不可变 `CodeVersion` 及代码来源快照。产物保存实际表达式／参数、策略配置、行情哈希、原实验及结果哈希、实际父代、生成器版本和代码 SHA256；代码版本带 `strategy_artifact_id` 双向标记。多来源实验按当前尝试真正使用的父代追溯，归档到第一个实际父代的研究；不把无关首个输入当成来源，不继承父代评分或收益。公式库中的父代和报告不改写，初始编译／运行／结果检查均为 pending。

修改生成代码保存为普通新版本，保留原始产物及父版本引用，不能覆盖生成版本。图谱显示最多12个相关策略候选及“MQ4 EA候选”关系；按文集有界扫描，不能当成语义、等价或实证边。可从归档研究的“代码实现”查看源代码、配置和手工验证记录。

## 本机规则与 MT4 映射

代码为生成的单标的、单仓位市价参考 EA，使用当前测试标的及唯一 Magic；只接受单次策略测试器运行，拒绝普通实盘／模拟账户和原生优化器。应用不会自动启动该程序。

- 实际公式使用归档参数的命名空间，保留 literal 参数映射；上一已收盘柱产生信号，新柱首个 tick 决策。附加后的第一柱跳过，不追补中途历史入场。复制历史最多20000根，数组按时间正序，全窗口和缺失传播保留。
- 多空方向、数值入场／退出滞回、布尔 true 的明确方向、固定价格止损止盈、持有柱数、冷却、开仓次数和允许同开盘反向均来自实际策略配置。缺失信号退出；止损／止盈或持有期退出后，本柱不重新入场。失败记录在终端日志，平仓失败阻止新仓并逐tick重试，不能将失败当已成交。
- MT4 按账户净值比例和线性 tick 价值代理换算手数，向下按 volume step 取整，低于最小手数不交易，不向上补仓。必须核验合约和账户货币换算，无法获得 tick size/value/lot 约束时禁止新仓。该代理不是所有外汇／期货／CFD 合约的已验证通用换算。
- 原生 Bid/Ask、点差、原生手续费／Swap 与 tick 路径由测试器决定。本机 fee_bps、slippage_bps 和逐柱借券成本保留为 reference_only_config，不能拿偏离点数充当实现滑点，也不伪造相同费用。
- 止损止盈是逐tick软件检查，基于真实入场价，不放置服务器保护单。真实tick路径不等于本机 OHLC 同柱止损先行、跳空止盈保守按目标价的模型；终端、合约、行情、价格路径和资金约束都需另行验证。
- native inputs 中 `QExpectedSymbol` 和 `QExpectedPeriod` 必须与测试标的一致。常用明确周期映射为分钟，未知周期默认0并拒绝运行，须在测试器明确配置；不会猜测同名标的或周期等价。最大偏离默认0点，是独立执行输入。
- 导出默认／实际值通过本机声明检查；在 MT4 改输入后不再等于该次实验。窗口、文字枚举和策略范围有检查，复杂参数依赖条件仍需按来源清单核验。程序生成不证明源码、行情、成本或动态参数语义等价。

这些差异是待验证能力边界，不是已经通过的平台适配。原生 API 含义参考 [IsTesting](https://docs.mql4.com/check/istesting)、[CopyRates](https://docs.mql4.com/series/copyrates)、[OrderSend](https://docs.mql4.com/trading/ordersend)、[OrderClose](https://docs.mql4.com/trading/orderclose) 与 [SymbolInfoDouble 属性](https://docs.mql4.com/constants/environment_state/marketinfoconstants)。本地计算不能代替 MetaEditor 编译或 MT4 测试。

## 原生观察与反馈

测试结束的 OnTester 尝试写入 `tester/files/odoc-<artifact>-<server-time>-<tick-count>.json`，匹配既有 `standard-execution-json-v1`。记录实际运行输入、产物／实验引用、终端 build、标的／周期、账户币种、初始余额、全部已平仓订单的利润／佣金／Swap、期末余额／权益、未平仓数和错误数。额外费用、服务器时区、tick模型和现金流完整性不猜测；超过2000笔时不写截断证据。

JSON 是用户导入的原生观察，不经过平台认证，也不是信号或成交等价证明。将其作为“使用反馈”的标准执行证据导入，并保留原始测试器报告／日志；补充时区、成本口径和未平仓情况后再核算。实际输入名与原始参数名通过 manifest 对照，不以本机参数替代真实测试配置。亏损、错误、未平仓和缺失字段均保留，不自动晋级实证等级。

## 数据、同步与实现

按用户已确认的全业务范围，StrategyArtifact、代码／来源版本和追溯标记均进入 WebDAV／FTP／SFTP。恢复校验实际尝试、父代、参数、配置、代码／清单与双向引用；按固定 `quant-mt4-strategy-export-1` 重建，不编译、不运行、不联网、不创建本机执行权限。代码被修改并重新计算哈希也不能冒充原产物。旧完整快照缺少新标记时按空串恢复，不从当前设备借用新产物引用。

后端 `quant/strategy_exports/` 分开维护事实选择、生成器、固定信号编译合同、MQ4运行／审计模板、事务归档、恢复与图谱投影。前端 StrategyExport 使用独立 API／类型／解码与 local 路由。人工 local 样例明确不转换公式，下载的是不执行的样例，仅验证界面／归档／关联跳转；真实候选需后端生成。

当前机器未发现 MetaEditor、MT4 或 Wine，原生编译与执行未验收。另有可选 C++ API替身合同测试，直接检查生成控制流、缺失／时序、禁止普通账户、手数向下取整、止损／次数限制和 JSON 格式；它不是 MQL4 编译器或 MT4，不用于标记平台通过。整体重构目标和真实模型／市场／远端同步验收继续进行。
