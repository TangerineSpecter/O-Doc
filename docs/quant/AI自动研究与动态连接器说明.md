# AI 自动研究与动态连接器

核对日期：2026-10-27，应用1.5.76、量化同步schema75。本文描述当前代码；真实模型、用户量化系统及远端设备实测另见[验证TODO](./开发收口与验证TODO.md)。

## 适用范围

因子文集负责价值研究、解释、参数分析、评分和遗传迭代。没有行情或回测也能研究；现有本机实验和外部量化结果都是可选证据。无需在这里建设行情中心或原平台运行适配。

入口：因子候选库 → **AI 自动研究**；同页的**外部研究连接器**维护通用HTTP接口。研究候选也可以直接进入连接器，并带入候选定义、参数及父代作为请求上下文。

## 自动研究规则

1. 选择1–8个父代，填写方向及可选资产市场/周期；设定最多1–8代、每代1–6项、保留1–4项且不超过候选数。启动时冻结父代定义、哈希、模型及选用的外部证据。
2. 每代最多一次模型请求、单次120秒、不自动重试。模型提出参数变体、组合、交叉、变异或简化，给出完整定义、五维研究评分与依据、风险及保留/淘汰理由。组合和交叉须引用至少两个不同父代。
3. 程序检查父代、参数身份、表达式和定义；改变源码参数默认值后不能冒用原源码默认身份。按计算定义和参数去重，不因改名或改解释就当成新公式。无效、重复、未保留的输出仍记录，不能发布为可执行或已验证结果。
4. 五维沿用逻辑清晰度、实现质量、数据与时序可靠性、参数可解释性、复现与复用价值；每维0–5，总分为合计乘4，任一维未知则总分未知。研究分用于安排研究优先级，实证表现保持未评估，不生成收益/夏普等假数据。
5. AI建议保留且结构有效的候选按研究分和本代保留预算入库，建立`ai_study`公式版本与真实父代谱系。下一代使用本代保留候选，读取上一代摘要及已有定义指纹；没有可保留候选、AI判断停止或达到预算时结束。
6. 页面展示各代候选、参数建议、评分依据、取舍和谱系；冻结输入及AI原始输出可回看。定义校验失败的候选仍展示错误和原始定义，不会阻断同代其他候选及整份报告，也不提供回测连接器入口。无法解析的代次保留原始JSON供查看。整份报告由代次结果汇总，允许删改并单独保存；不会覆盖每代AI原稿。连续编辑当前修订不另外建立修订历史，原始代次持续保留。
7. 用户可以停止；失败或中断可显式继续剩余代数预算，失败代次也计入已消耗预算。恢复同步快照不会调用模型或自动续跑。已有完成代次保留，新研究可从已入库候选开始。

AI只做静态研究；建议参数是待验证假设，资产市场适用性是基于所给材料的研究判断。没有样本证据时不宣称盈利能力、最佳参数或市场有效性。

## 动态HTTP请求与返回映射

每个连接器独立定义HTTP方法、固定主机的地址、请求头、查询参数、JSON正文和1–30秒超时。支持GET/POST/PUT/PATCH/DELETE，用户按需明确发送，不随AI循环自动请求外部系统。

- 模板支持`{{parameters}}`、`{{factor.expression}}`、`{{candidate_id}}`等请求上下文路径。单独占位符保留对象、数组或数值类型；字符串内占位符用于拼接文本。地址路径可用上下文变量，主机不能动态切换。
- 本机密钥用`{{secret.api_key}}`引用，密钥JSON单独保存、不回显、不进入业务同步。认证请求头必须引用密钥变量，不把实际请求头/正文或请求上下文复制进归档。接口返回本身仍完整归档，使用者应让接口只返回所需研究资料。
- 来源路径支持`$.payload.stats.ReturnPct`、`$.rows[0].value`和JSON Pointer，例如`/data/Settings/N`；保持实际键名与大小写。目标路径由用户定义，如`metrics.total_return`、`parameters`及`custom.risk`，不用固定适配一种券商或报告格式。
- 类型支持原始JSON、字符串、数值、布尔和数组逐项映射；数组的字段配置相对当前项，也支持嵌套。数值可显式缩放，例如`12.5 × 0.01 = 0.125`。可选缺失字段保留null并提示；必需字段缺失或类型错误直接提示，不补0。
- 将接口实际采用的参数另行映射到返回结构；不能拿请求输入或源码默认值冒充实际执行值。自定义字段、实际费用、标的、周期和样本范围可按同样方法映射。
- 先粘贴返回样例解析预览，再保存连接配置并明确发送。发送只接受成功HTTP响应及UTF-8 JSON，单份响应最多2MiB，不自动跟随重定向。
- 发送时解析并校验所有目标地址，拒绝链路本地、组播、未指定和已知云元数据地址（包括IPv4映射IPv6及NAT64形式）；连接固定使用已验证的地址，HTTPS仍验证配置中的主机名。不使用环境代理。用户配置的本机和其他局域网接口仍可使用；DNS解析失败或超时会中止请求。响应支持未压缩或gzip的UTF-8 JSON，大小上限按解压后计算。
- 每份归档保留请求配置快照、原始响应、映射结果、警告及上下文哈希。外部结果标为未独立核实。启动AI研究时可选择归档作为补充证据，结果仅适用于其明确参数、样本和假设，不自动提升所有后代的实证等级。

当前接入是同步HTTP/JSON调用；XML/二进制解析、异步任务轮询、任意JavaScript后处理未接入。普通嵌套JSON与数组无需改代码即可新增映射，不复刻完整Postman产品。

## 数据与同步

按用户已确认范围，`AIStudy`、`AIStudyGeneration`、`ExternalConnector`、`ExternalResponse`和生成的现有因子/公式版本进入WebDAV/FTP/SFTP。研究计划、代次输入/输出、当前人工报告、接口模板与原始/映射结果都是业务数据。

`AIStudyJob`是本机执行状态，`ConnectorSecret`是本机密钥，均在同步模型排除表中；恢复清除执行任务、不恢复调用授权。向量索引沿用本机重建。恢复校验原引用、哈希、代次顺序、评分/保留结果、公式父代与响应映射，不重新请求外部接口。

新增迁移`0030_aistudy_aistudygeneration_aistudyjob_and_more.py`；本轮只在隔离测试数据库执行，未迁移真实业务库。使用新后端前需按正常更新流程应用迁移，参与同步设备一同升级。
