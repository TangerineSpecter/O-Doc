# 研究报告阅读与参数入口

核对日期：2026-10-27。适用应用 1.5.71、量化 schema 71。本文说明当前阅读界面与本轮本地验收，不代表整个[重构目标](../requirements/007-AI量化研究系统重构.md)已经完成。

## 当前规则

- 收集代码后自动研究仍是主流程。已有报告时，来源与重新分析设置默认折叠，报告在源码影响预览、阶段记录、候选和实验规划之前显示。尚无报告、任务执行中、失败或来源不一致时展开设置；旧报告与当前来源不一致的提示独立显示，不随设置折叠隐藏。
- 报告先显示 AI 原稿摘要，再提供“结论与评分”和“参数分析”两个阅读入口。结论页在评分前提示严重或高影响问题；总分不能抵消问题。五维评分可展开原始理由、依据与未知项，缺少分数不补零，不重新计算或修改历史评分。
- 参数页显示原稿中的参数分类、类型、源码默认、用途、影响、约束、建议与原文依据。默认值、实际运行配置及实验取值分别记录；建议保持待验证，不宣称最优。无结构化记录的旧报告显示缺失说明，原正文仍可阅读。
- 实验复盘显示“实验参数结论”，直接读取已保存的AI参数判断与尝试引用；反馈报告显示“配置与参数”，分别展示文件配置、报告声明及本机验证记录。它们不再因为没有源码声明数组而显示“参数分析（0）”。执行核算的参数对照仍使用既有完整证据入口，缺失不补默认值。
- 有首轮或反馈规划时，可从参数页跳到当前报告的 AI 实验方案，再选择行情并准备实验。界面不会因为阅读报告或跳转而执行源码、模型或计算。
- 实验复盘中的已有下一轮方案同样可从参数页进入，并在报告下方准备参数实验或连续研究；无方案时保留缺失说明。
- “编辑与删减”修改报告正文，保存时仍检查预期修订 ID，并保留离开保护。AI 原始摘要、结构化参数、问题清单和分数不会被人工正文覆盖；原稿与历史修订可展开查看。

## 代码与同步边界

`ReportPanel.tsx` 负责编排来源设置、当前报告及后续研究入口；`reports/ReportEditor.tsx`、`ReportScore.tsx` 分别负责正文与阅读切换、评分依据，`ReportParameterDetails.tsx`按报告类别展示已有参数字段，静态声明复用`ReportParameters.tsx`；`hooks/useQuantReportDraft.ts` 管理草稿、保存与离开保护。`experiments/InitialExperimentPlan.tsx`提供首轮、反馈及复盘后续方案的报告级入口。

本轮无新接口、持久字段、表或迁移，schema 仍为 71。报告与修订沿用用户已确认的 WebDAV/FTP/SFTP 同步；展开状态和阅读页签仅为本次页面状态，不同步。没有更改模型预算或本机执行授权。

## 本轮验证

- 使用完整应用的纯 local 模式，走通粘贴 Pine、自动样例报告、评分依据、参数页、人工删减并保存、刷新及原稿/历史查看。导入 120 根人工行情后，从 AI 方案启动实验，出现三个已保存尝试、失败记录与样例解读。模拟报告明确说明不解析输入源码，模拟实验明确说明不计算真实表现。
- Pine、MQL4/MQ4、Python 编辑器分别观察到 7、7、5 种 token 颜色；MQL4 仅验语法着色，没有运行 MT4。专用人工严重问题样例在仍为 60 分时，先显示严重问题横幅，未把总分当成通过。
- 已核对 1440、768、390px 的阅读布局；390px 的 body/root 宽度均为 390，无页面横向溢出、原生 select 或可拉伸 textarea。空数据提示条目不存在并提供研究列表，接口错误显示模拟失败；慢请求模式最终恢复样例。未单独断言慢请求中每一帧的加载骨架。
- 前端量化回归 156 项通过；最终类型检查、定向 lint、构建（39.84 秒）及差异空白检查通过。构建仍有现有大分包、Browserslist 数据和 JSON 导入属性告警。浏览器错误日志对应主动选择的模拟接口失败，没有把它计为模型或真实后端故障。本轮没有新 API，因此沿用现有类型化 mock 路由；本地样例不能代替真实服务验收。
