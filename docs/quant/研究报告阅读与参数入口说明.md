# 研究报告阅读与参数入口

核对日期：2026-10-31。适用当前本地代码；当前研究状态使用量化同步 schema 90，迁移为 `0035_research_document`，本次评审修复不新增数据库字段或迁移。本文说明当前阅读界面与本轮本地验收，不代表整个[重构目标](../requirements/007-AI量化研究系统重构.md)已经完成。

## 当前规则

- 报告正文、代码块、候选公式及引文的复制入口统一反馈成功或失败；剪贴板接口不可用时尝试浏览器复制兜底，两者失败则提示选中文本手动复制。目录和正文共用 Markdown 标题解析及重名编号；每份正文、预览和历史修订分别隔离锚点，代码块中的标题不进入目录。
- 每条资料只有一份当前研究。首次分析形成当前内容；重新分析先保存为待采用变更，通过正文解读、参数分析、因子算法、评价与审查、实验规划五部分比对，用户选择后才替换对应部分。未采用结果不发布新因子及实验方案。
- 从指定阶段继续只重算该阶段及后续阶段；发布结果仍进入待采用。只采用评分不会改写正文、参数或算法。相同算法按同资料、同来源、完整计算定义复用已有因子 ID；人工中文名称随稳定身份保留。
- 源码报告以逻辑解读为主；宽屏下 AI 原稿评分和提取的因子与信号显示在右侧并可独立滚动，窄屏时按解读、评分、候选的顺序排列，正文前有快速跳转。候选默认展示前五项，可展开全部并进入因子候选库。未编辑的原稿优先显示原理、公式和用途；有修订或未保存的草稿完整按用户内容显示。参数分析是独立入口，原稿检查记录可主动展开。历史原稿和修订均保留；五维分数不作为源码能否运行的结论。实验复盘与反馈报告继续使用各自的结论阅读方式。
- 研究目录和正文评分读取当前采用的评价部分；未评估仍显示待评分，不从最新未采用分析中取分。
- 评价与审查分区同时管理审查范围说明、历史记忆及其判断、源码变化事实和解读。仅这些字段改变也进入待采用；采用和恢复后，历史依据 JSON 与判断来自同一评价部分，不借用正文所属任务的旧记忆。
- 评分卡片保留总分和各维分数，点击维度或“查看评分说明”打开宽弹窗，沿用深色评分卡片与各维度展开样式；分别默认展开所选维度或全部维度，弹窗内仍可切换展开状态。
- 源码评分按计算逻辑、实现、时序、参数、复用五维评价。每维说明优点、问题与影响、扣分原因；源码引文默认收起，验证情况单列。未编译、未回测、平台解析或执行能力不足不能作为原源码缺陷扣分，作者尚未验证的预测效果也不扣计算逻辑分；具体边界、未来读取等实际问题仍按事实评价。0–5分分别表示核心失效、严重不足、显著问题、明确局限、轻微不足、未发现实质问题；缺少关键材料无法判断时为null。
- 评分说明继续存于既有reason/evidence字段，随报告同步，没有新增持久字段。模型使用显式中文段落标签，阅读器按标签分段；旧说明或格式不完整时原样显示，不猜测优缺点，也不改写历史分数。实验报告沿用其独立评价规则。

### 评分说明验证（2026-10-31）

后端相关25项、前端量化236项测试、类型检查与定向ESLint通过。纯local新样例核对了三段说明、单列验证情况、默认折叠和展开源码依据；旧说明完整保留。空数据、模拟接口失败可明确呈现，加载模式最终恢复样例，未逐帧验证加载骨架。开发热更新期间一次本地收集请求出现404，重新加载初始化mock后相同收集流程成功；未将该次失败计为通过。截图 `/private/tmp/odoc-score-explanation-local.png` 为人工样例，`/private/tmp/odoc-score-explanation-current.png` 为实际已保存评分的兼容展示。

按授权使用MiniMax-M3对四份样本从评价阶段真实续跑，发现新提示词仍不能稳定消除错误扣分：例如将`max(a,b)<k`与“两者都低于k”误判为不一致，或因正常预热、未指定资产周期扣分。因此本轮只完成阅读展示与生成指引调整，**评分内容可靠性尚未通过真实验收**；未采用这些测试评价。测试产生的待采用结果已撤回，核对四份当前研究所有部分的引用未变，现有分数分别为DERYA 64、IAKF 72、Liquidity Magnet 72、Adaptive SuperSmoother 76。没有为使测试通过而硬改分数，也没有重写已采用正文和因子。当前模型评分仍需对照源码阅读，不能据此宣称评分可靠性已经修复。
- 因子列表以类型、名称与简短计算说明区分候选，点击卡片打开计算逻辑和带语法高亮、复制按钮的 Python 代码。报告修订可在 `quant-factor-calculations:v1` 标记区内用 `### 因子名`、说明和 `python` 代码块保存人工整理的阅读内容；这仍是既有 Markdown 修订，随原有报告同步，不改变候选定义或实验表达式。标记区格式不完整时保留完整正文，避免丢失用户内容。没有人工说明时，使用报告中显式标记的 Python，或从支持的单值表达式生成展示片段；无法可靠转换的旧记录保留原始计算说明并提示缺失。普通新研究提示模型提供 Python 片段；增量工作流 28 沿用原有提示以兼容历史快照，模型实际生成仍须验证。
- 当前普通41/跨源码42工作流沿用39/40的“这个指标/策略/因子做什么 → 它是怎么计算的 → 关键公式与解读 → 输出怎么看 → 主要参数 → 怎么使用”导读，公式用Markdown/LaTeX并解释符号及作用，正文不罗列行号。旧原稿不改写；下游续跑保留已确认修订，不能因为旧工作流的排版重新发布而丢掉修订。报告阅读器使用KaTeX渲染公式。
- 研究详情通过固定 90dvh 高度的独立弹窗查看，分类栏固定，内容区域独立滚动，切换分类不改变弹窗位置和高度；按实验规划、源码与进度分类；从报告或参数页跳转到 AI 实验方案时直接打开对应分类。已有报告时，执行中的研究进度也显示在报告前。实验规划优先显示是否生成方案及可操作内容，生成说明默认只展示原文明确列出的研究结论、需要补齐的清单和下一步；不再提供“说明与边界”或七主题导航。来源、参数、平台及信号时点等技术依据按需展开，行号定位从阅读副本隐藏，完整原文保留全部引文与内部字段。界面不调用模型改写或推断结论。
- 参数页默认优先显示计算参数的名称、源码默认值、用途与变化影响，显示设置和内部常量/状态分组查看；范围、建议及原文依据可展开。Pine 已定位的 `input.source(close, ...)` 在阅读界面显示“收盘价（close）”，其他无法静态求值的默认表达式仍标明是表达式。分类与说明来自保存的 AI 原稿，并非对实际运行行为的独立验证。默认值、实际运行配置及实验取值分别记录；无结构化记录的旧报告显示缺失说明，原正文仍可阅读。
- 实验复盘显示“实验参数结论”，直接读取已保存的AI参数判断与尝试引用；反馈报告显示“配置与参数”，分别展示文件配置、报告声明及本机验证记录。它们不再因为没有源码声明数组而显示“参数分析（0）”。执行核算的参数对照仍使用既有完整证据入口，缺失不补默认值。
- 有首轮或反馈规划时，可从参数页跳到当前报告的 AI 实验方案，再选择行情并准备实验。界面不会因为阅读报告或跳转而执行源码、模型或计算。
- 实验复盘中的已有下一轮方案同样可从参数页进入，并在报告下方准备参数实验或连续研究；无方案时保留缺失说明。
- “编辑与删减”保存当前采用正文，同时核对文档修订号及正文修订号，防止多页面覆盖。更新记录保留最近 5 次状态，可按五部分恢复、删除单条或清空；恢复后可继续编辑。当前页面不再重复提供另一套原稿修订列表。

## 代码与同步边界

`reports/ReportUpdates.tsx` 与 `DocumentChanges.tsx` 提供比对、采用、按部分恢复和清理；`hooks/useQuantDocument.ts` 管理 API 状态和冲突。`quant/documents/` 分离状态修改、阅读投影、同步校验与清理，`/entries/<id>/document/` 提供 GET/POST。`ResearchDocument` 保存五部分来源指针、待采用结果、最多五条恢复记录和乐观锁；`ResearchReport.publication_mode/factor_bindings` 记录发布状态及复用的因子关联。以上字段按用户确认全部进入 WebDAV/FTP/SFTP 同步，弹窗开关不持久化。

`ReportPanel.tsx` 负责编排来源设置、当前报告及后续研究入口；`reports/ReportEditor.tsx`、`ReportScore.tsx` 分别负责正文与阅读切换、评分依据，`ReportParameterDetails.tsx`按报告类别展示已有参数字段，静态声明复用`ReportParameters.tsx`；`hooks/useQuantReportDraft.ts` 管理草稿、保存与离开保护。`experiments/InitialExperimentPlan.tsx`提供首轮、反馈及复盘后续方案的报告级入口。

报告与修订沿用用户已确认的 WebDAV/FTP/SFTP 同步；展开状态和阅读页签仅为本次页面状态，不同步。2026-10-30 的[分页与按需读取](./研究库分页与按需读取说明.md)新增读取接口和索引迁移，原稿、修订和对照报告在展开/选择时读取，正文缓存只留内存；没有新持久业务字段或同步格式变更，没有更改模型预算或本机执行授权。
