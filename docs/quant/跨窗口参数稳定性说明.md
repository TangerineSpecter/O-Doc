# 跨窗口参数稳定性

核对日期：2026-10-26。应用1.5.54、量化schema57，无新表或迁移。此处描述全部内层窗口的参数复核；窗口计算和选择规则见[多内层时序验证](./多内层时序验证说明.md)。完整重构仍有功能与真实环境缺口。

## 当前计算规则

walk_forward v2实验的每个计划外折、每个计划内层都单独检查同一来源的实际参数对照。单参数保留其他参数为实际基线；联合参数按字符串模式/布尔配置分别比较，不借用其他模式的参考。仅使用原始候选和参数变体，公式演化与组合不能归因于单个源码参数。

每个窗口沿用单/联合敏感度v1的固定规则：训练和验证都要求正收益、有入场、至少90%信号覆盖；相对实际基线的收益下降和回撤增加各不超过2个百分点。区段内收益/回撤极差各不超过2个百分点，缺失比例极差不超过5个百分点。单轴至少3个相邻已测点；联合至少两个变化轴和完整4点笛卡尔积。规则是描述性筛选，不是显著性标准。

全部窗口支持的离散区段或完整矩形取交集，保留所有最大共同区域。缺角、失败、未执行和缺测不能插值补齐；不能用最后一窗、最好一窗或平均值抵消反例。比较集合与稳定集合分开：

| 状态 | 含义 |
| --- | --- |
| sampled_region | 至少一组参数在全部计划窗口有共同支持的已测离散候选；其他组仍可不足 |
| no_supported_region | 有共同完整对照，但没有全部窗口共同通过筛选的区域 |
| insufficient_comparison | 共同完整对照不足，保持未知 |

整体未被评价的尝试不参与区段筛选，即使保留了早期完整指标；部分计算与失败理由仍可查看。未启动的外折/内层也占计划窗口，不能把已完成子集冒充全部完成。单点通过规则不等于形成3点区段或完整联合区域。

外层测试、选中赢家、留出收益和曲线不参与此计算。各窗分别空仓起止，收益不拼接；后折可使用前折已过去的历史，窗口重叠不构成独立重复样本。共同区域只支持提出新数据复核，不能据此宣称最优参数或金融有效。

## AI报告与评分

新实验解读使用review_version=12，继续冻结上下文6及规划能力v1。原parameter_sensitivity和parameter_joint_sensitivity仍描述最后内层；新增temporal_parameter_stability负责全部计划窗口，AI必须额外给出跨窗口解读，保留代码算出的status、planned_windows并引用完整证据。

模型输入保留每窗实际基线、参数值、可比较/单点资格、共同区域、失败和未知。逐点原始指标已在attempt的inner_evaluation中保存一次；新汇总按attempt_id和内层number引用，不再重复拷贝指标，number不是数组下标。160000字节上限仍保留，超限不静默丢弃失败或窗口。

参数稳定性非空评分须引用新汇总及一窗完整具体对照：单轴至少3点或联合完整至少4点，含实际参考。服务端再核对这些同组取值在全部计划窗口的共同证据：

- 共同完整对照不足：参数稳定性为null，不能把未知记0。
- 有共同完整对照，但没有共同支持区域：最多2/5分，可解释负面或不稳定结果。
- 3–5分：还须存在全部窗口共同支持的区域，仍须说明局限与新数据要求。

适用新门槛的报告记experiment-research-v2，保留五维等权和未知时暂缺总分的规则。旧解读1–11不注入新事实或提示，仍按原合同恢复；旧分数不与新版门槛直接混排。静态源码研究质量分不变。引用、状态和评分门槛校验不能证明模型每句推断正确，同模型分析也不构成独立证据。

## 页面、数据和同步

实验详情增加“全部内层窗口的参数复核”，展示实际基线、计划窗口总量、共同离散值和逐窗对照。每窗可看验证时间、原始参数、训练/验证收益与回撤、失败/缺测，并跳转对应尝试。零值保留为零，缺失显示未知。共同区域与原单/联合敏感度分开，避免混淆范围。

旧v2实验可按原检查点派生此只读面板，不改写原报告。历史单窗口AI评分有明确提示；点击重新解读生成新报告，原稿与人工修订保留。局部表格和窗口列表独立滚动并隐藏滚动条，沿用现有白卡片与公共交互。

原始参数、窗口、检查点、结果、AI报告/评分和引用沿用户已确认范围进入WebDAV/FTP/SFTP。新增面板是确定性只读投影，不另存易漂移的副本；review12的证据哈希与报告结果在恢复时从原始记录重建校验。schema57阻止旧端错误读取新解读；恢复不重新搜索、调用模型、执行源码或恢复本机队列。凭据、向量缓存及执行授权仍留本机。
