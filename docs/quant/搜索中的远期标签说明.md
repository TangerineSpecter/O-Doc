# 搜索中的远期收益标签

核对日期：2026-10-27；应用1.5.68、量化schema69。本地实现，未部署。本功能将[固定验证的远期标签](./远期标签与固定验证说明.md)接入参数/组合搜索、公式演化、显式策略和多内层时序验证。完整目标见[重构规格](../requirements/007-AI量化研究系统重构.md)，这一步不代表真实模型或整体验收完成。

## 选择目标和窗口

准备实验时可选“按远期标签选择因子”，明确未来1–2000根柱；未启用时仍沿用原成交收益选择规则。目标冻结为close[t+h]/close[t]−1，预测值来自同一收盘柱的受控因子输出，布尔按0/1处理。柱数按导入行计，不预设日历时长、连续数据或原平台实时可得性。

每个训练、验证和测试段分别限制标签终点t+h≤本段end。先剔除段末h个跨界起点，再记录预测缺失；至少5个可配对起点，实际有效配对不足或相关未定义的候选保留为rejected。段不够长时在创建/准备前拒绝，不通过越界标签补足样本或默默缩短期限。

搜索开发期只读取当前训练/验证前缀。每个外折从冻结原始父代重新搜索；每个内层按自己的预热起点计算，rolling不借用更早折的额外计算历史。标签可能在同段内重叠，但不跨段；内外层已有gap继续保留，不能把固定gap自动当任意事件标签泄漏检查器。

## 实际选择规则

训练Pareto目标为Rank IC、有效配对覆盖率、负复杂度；不把相关取绝对值，也不事后反转因子方向。随后按验证Rank IC降序、验证覆盖率降序、复杂度升序、公式指纹排序。Pearson IC单独保存供解释，不作为本版选择目标。已定义但全为负的相关仍是负面结果，不能称有效或最优。

多内层分别计算完整窗口；训练Rank IC/覆盖率等权均值和复杂度做Pareto，验证Rank IC/覆盖率等权均值选择。任何窗口标签不足或相关未定义，汇总保留null，候选不参与选择；已算的各窗口仍保留。原交易收益、回撤及换手均值另外保存，不替代标签适应度。显式策略资金耗尽等既有不可行条件仍会拒绝候选。

原始父代、参数变体、组合和演化仍消耗同一个32候选/4代/60秒上限，逐折分配而不乘大预算；训练Pareto和固定随机探索仍保留多样性。每个候选/窗口使用同一冻结目标，标签周期不是本批待优化参数。需要改变目标须创建新的待验证假设。

只在本折选定后计算测试标签和交易对照，顶层对应最后已启动外折，不按测试IC/收益挑最好折。改变某折测试/未来行情不改变此前开发记录和赢家。外层结果按折保存；没有把IC拼成连续组合收益或独立重复样本。

## 报告、后续研究与固定验证

详情分别显示标签目标、当前尝试全部内层的Rank IC/配对/剔除、完整内层均值、各外折选择后的测试标签，以及交易收益/成本对照。原单/联合参数敏感度与CSCV仍描述交易收益，不能称为标签IC稳定区域或标签选择显著性。

AI读取全部已记录候选、失败、部分窗口、完整汇总和逐折测试，冻结目标、数据重用与原交易事实一起进入解释。重复目标含义和说明在execution中单列，具体标签保留范围、全部计数、覆盖率、正负/未定义IC、配对哈希及选择用途；不附原始价格或完整标签数组。160000字符材料上限沿用，超限明确失败，不静默删除负面结果。

已有planning_capabilities v1的收益选择示例不用于覆盖标签目标；下一轮提案和连续研究继承完整config.label_target、预算和窗口。当前源码首次自动规划仍采用已有能力，不自动替用户选择预测期限；可在准备时明确目标，之后AI与连续流程沿用。已查看的数据进入下一轮后不能再宣称未见独立验证。

从标签实验登记固定新数据验证时，默认沿用来源目标，登记框明确展示；显式修改期限是新的预登记目标。未给出不同期限时API也继承，避免通过另一入口漏掉预测目标。固定验证仍无搜索，原收益标准与标签IC分开判断。原生EA导出只导出已评价配方和显式交易规则；标签选择不授予收益或原平台等价结论。

入口：`quant/label_studies/{targets,calculation,search,snapshot}.py`；既有experiments搜索/内层/滚动/快照与worker接入；review_evidence按阶段投影，review_contract说明新目标；fixed_validation继承目标，strategy_exports沿用实际配方。前端quantLabelSearch/quantLabels、readout/quantNested分开解析，LabelSearchSettings/LabelSearchResults与既有详情接入；纯local模块只构造标明人工的展示事实，不计算上传行情或真实选择。
