# 运行参数与固定源码的对照

核对日期：2026-10-27。应用1.5.60、量化schema62。新结构化执行反馈使用feedback v5 / source-parameters-2，覆盖MQL4简单input/extern、Pine可识别input及Python 3.11默认形参和大写初始赋值。旧feedback v3继续使用原MQL4对照v1，SET配置v2与Python原函数反馈v4不升级。成交核算和完整重构边界见[当前量化说明](./量化文集一期说明.md)。

## 使用与报告

从研究详情的“使用反馈 → 结构化执行证据”导入支持的JSON、CSV或MT4 Tester HTML，明确关联固定来源。报告原文中的parameters是外部声明的实际配置，不等于已经确认该代码按该配置运行。系统核算执行记录，并把可识别的源码声明与这些参数交给AI分析；模型缺失或失败时，原文与核算记录仍保留。

AI报告的运行参数区显示报告值、源码默认或初始赋值、类型/行号、匹配状态和缺项。可以展开源码声明与识别范围，所有名称区分大小写。缺少运行值时保持缺失，不把默认值填成实盘值。解析范围说明折叠保留，主要差异先展示。

以人工测试来源为例：`N=input.int(20,minval=1)`，报告声明`N=10`，显示“与默认值不同”；`RSIOverSold=50`，报告声明30，显示“与初始赋值不同”，并说明它不是公开输入。源码的`Mode=input.string("FAST")`在报告中缺失时，只列缺项，不补FAST。原始材料、研究质量分及已有实证结果不会因这种对照自动升级。

## 可识别范围

| 来源 | 当前读取 | 保留未知的内容 |
| --- | --- | --- |
| Pine | 直接顶层input、input.int/float/bool/string及对应可识别文字输入；位置或具名defval；具名minval/maxval/step/options；简单字面赋值 | 函数/常量引用的求值、源序列、枚举、输入参与其他表达式后的变量值、缺失依赖及编译/运行语义 |
| Python | 3.11 AST中的顶层同步/异步函数默认形参，包括仅位置和仅关键字参数；全大写模块初始赋值；简单内置类型注解提示 | 必填数据参数、普通混合大小写模块变量、g对象初始化、外部配置、装饰器效果、函数调用、动态赋值和运行时类型 |
| MQL4 | 延续已有input/extern简单声明、类型/字面默认值和数值边界核对 | include、宏、条件编译、枚举与复合表达式；不调用MT4 |
| 通达信等 | 保留来源及报告声明的参数 | 尚无对应确定性读取器；外部参数表缺失时不猜默认值或映射 |

公开输入、函数默认形参和模块初始字面赋值分别标记。初始赋值不证明运行时全程不变，也不能直接当作平台设置项；修改源码中的赋值应形成新版本。相同名称在多个函数/声明出现、或发现重写时保留歧义，不靠名称选一个作用域。

Pine的具名上下限和完整可识别选项可发现声明约束不符。step只记录为界面调节增量，不推断为强制网格、收益稳定区域或推荐范围。Python注解仅作静态提示，不证明运行时强制类型。字面标量只允许有界整数、有限浮点、布尔和字符串；不eval、不执行、也不解析函数调用或名字引用的值。

源码超过20万字符、Python语法节点超过20000或声明超过300时，返回limited及未解决状态，不用截断后的声明假装完整。未闭合/无法完整定位的语法标记unparsed；未支持语言标记unsupported；正常可识别来源仍为partial，因为它不是完整语言或平台解释器。原文、未知项和原始参数仍保留。

语法范围参照[TradingView Inputs](https://www.tradingview.com/pine-script-docs/concepts/inputs/)与[Python 3.11 AST](https://docs.python.org/3.11/library/ast.html)。这些资料不是本系统已通过原平台编译、执行或全语法等价的证据。

## AI事实引用与后续研究

源码参数对照v2包含固定源码ID/哈希、当前解析参数、缺项、解析状态，以及总览和逐项引用。引用指纹绑定该源码和此次解析的对照事实，改变实际配置会改变指纹。

新AI执行证据分析必须引用参数对照总览并解释实际值、默认值、初始赋值及缺失。有差异或未知时须有反驳或限制；不能只描述收益。金额核算存在差异时，仍须引用实际核算反例，不能用参数差异替代金额问题。确定性参数与数值事实由服务端复制，模型不能修改；重哈希后将整数1伪装成true也会拒绝。

反馈实验方案可以引用这些确定性参数事实及原反馈，保留配置差异作为待检验假设。已有本机实验的原输入、受控公式声明、外部实际配置和源码初始值仍分开。它不自动修改源码或运行配置，不把初始赋值冒充可调input，也不据单份反馈推荐最优参数；原平台代码变更需新的来源版本，受控公式实验不冒充原平台运行。
