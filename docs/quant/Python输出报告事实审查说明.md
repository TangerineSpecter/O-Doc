# Python输出报告事实审查

日期：2026-10-26。应用1.5.51、schema54、迁移0029。当前规则适用于原始Python固定输出反馈v4的AI解读，不改变其他源码、实验或外部报告的历史合同。整体重构仍在实施，未仅剩验收；本批未迁移真实业务库或部署。

## 生成与核对

新建原始Python验证并选择AI解读时，先生成原稿，再进行事实审查。发现问题最多生成一次完整修订，再复核；若复核仍拒绝、合同不合法、取消或超时，本次不生成ResearchReport。成功才单独发布报告，不覆盖原稿、历史报告或人工修改。

已有报告可在因子详情的“原始Python验证与AI解读”选择“核对并修订AI原稿”。请求绑定同一条目、同一反馈来源的已完成报告及哈希；读取旧报告不消耗新生成调用。核对针对保存的AI结构化原稿，不读取或覆盖人工修订Markdown；人工删改继续单独保留。旧版报告须升级事实确认字段后才可通过。核对不探测Docker、不运行原函数、不计算新行情；普通来源分析入口仍遵循原流程。

每请求最多3次新模型调用、360秒总预算、单次120秒、单次最多24000输出tokens；没有自动模型重试。已有报告通常为0次生成+1次审查+必要时1次最终复核。固定事实不满足或审查拒绝均保留失败，不循环修订。失败或取消后原稿/已完成步骤可查看，当前workflow2任务可显式从未完成阶段继续；已有已发布报告也可另建一次有预算的核对请求。

阶段名与状态独立展示：生成或读取原始解读、事实审查与一次修订、复核修订稿。使用当前配置的对话模型，**同模型复核不是独立专家审查或独立金融验证**。通过仅表示该次模型未列出遗留问题，不能保证自然语言全部正确，也不提升因子收益、平台等价或独立性证据等级。

## 从失败阶段继续

在原始Python验证记录的AI事实审查区选择“从失败阶段继续AI解读”，创建独立AIRun，native_resume_run_id绑定已停止的同反馈任务。只允许failed/cancelled/interrupted且没有完整reject决策；正在执行、已完成或明确拒绝的任务不能作为续作父任务。来源、模型选择、要求、冻结历史上下文、审查策略和已有报告引用沿用父任务；变更这些输入须另建完整解读。固定上下文超限时拒绝续作，不悄悄删减历史。原队列和租约不沿用，新的显式操作重新授权本机任务。历史workflow1不改写为workflow2。读取验证详情也会核对原AI任务租约，失效时显示已中断及可续作，不重新入队。

程序只复用连续完整的检查点：完整原稿可复用；审查accept/revise可复用；最终复核只有accept可复用。请求失败、合同错误、截断和只有输入而没有结果的步骤可重新请求。完整reject属于稿件被明确拒绝，须选择“重新生成完整AI解读”，从新原稿和一次审查开始，不能复用同一被拒文字反复申请通过。完整重生成使用当前默认模型及新选择的历史上下文，另受3次/360秒/一次修订限制，旧原稿和拒绝原件保留。如果续作在复制前中断，仍可从同一固定上下文的父链寻找完整检查点；较新正文变化后不复用旧正文的后续核对。没有完整原稿时重新生成AI原稿，仍使用保存的Python计算事实，不重跑Python或Docker。全部模型阶段已通过但发布失败时，可复用通过结果重新发布，新增模型调用为0。

已保存的一次修订继续计入上限。最终复核因请求或协议错误失败后，续作只能重新accept/reject，不能再修订；连续续作也不能重置该限制。每次显式续作各自有上述3次/360秒预算，最多64条祖先引用；不会自动反复重试。复用不代表旧文字已通过人工或独立审查。

续作步骤使用输入v10，绑定父任务、原步骤/结果身份及哈希，保存相同固定事实。复用结果使用outcome v3，逐字保留已解析成果，raw为空、用量0、耗时0，并保存reused_from；原始模型返回、真实用量和失败原因继续保留在祖先原件。新请求的模型阶段仍保存outcome v2，成功后报告gate只引用本次完整的阶段链。界面把“复用已保存阶段”和新增调用数分开显示，原报告与人工修订保持独立。

## 固定事实与模型文字

程序固定左右侧：left为受控表达式，right为原始Python函数；实际候选参数、显式函数映射、源代码默认值、样本、缺失和差异均来自保存的计算事实。数值一致条件为：

```text
abs(left-right) <= absolute_tolerance + relative_tolerance * max(abs(left),abs(right))
```

新请求使用feedback_workflow_version=2、native_review_version=3，精确确认比较角色、上述规则/实际容差/共同预热、NativePythonResult身份及alignment_ack；历史workflow1/native2维持原合同。不能在模型返回中伪造服务器审查通过标记。服务端附入固定计算表与判定，机器数据不由模型改写。

审查检查summary、comparison、hypotheses、next_steps、native_review、feedback_planning_note、memory_note及其余自由文字，涵盖左右侧、默认/实际参数、前视/定义范围、容差、数量级/比值、缺失以及历史统计概括。新请求的问题须选择程序提供的text_ref和匹配JSON Pointer，并给出合法事实引用与说明；服务端从冻结原稿复制完整区间（最多2400个Unicode字符），保存quote、quote_origin、起止位置。模型自行摘录或拼接的quote不作为依据。最多24条，跨字段、重复或不存在的区间拒绝。历史输入仍使用原逐字引文合同。只有旧协议升级可指向根序列化文档；其他问题须定位具体文字。修订可删除无依据列表项，或改变所标问题字段，并重新通过完整分析合同。最终复核不能再修订。

固定数值与历史明细由系统保留，模型文字侧重解释和可否证假设，避免重复抄写全部数字、新增未经核对的手算比值或笼统统计。窗口长度、显式warmup_bars和实际缺失行数分别表达；下一步须写明完整输出公式和原函数变体，不能将均值、偏离信号与含未来收益的乘积混为一谈。建议参数仍为待验证假设。

## 输入、记录与同步

| 阶段 | 模型读取 | 模型权限与输出 |
| --- | --- | --- |
| 原稿生成 | 固定来源、目标源码字段白名单、候选定义、原始输出比较、实际配置及有界历史 | 无工具；返回完整分析 |
| 读取旧报告 | 程序读取已保存报告数据/哈希 | 无模型调用 |
| 审查与修订 | 同一固定事实、原稿文字、合法引用键及必须确认的机器字段 | 无工具；accept/revise/reject及逐字问题，最多一次完整修订 |
| 最终复核 | 相同固定事实与修订稿 | 无工具；仅accept/reject |

程序从已保存的原始输出与受控表达式重算首次/末次有效位置、整个片段缺失数、比较段缺失差异及最多12条精确位置，不重跑原始源码。行号从固定片段0开始；显式warmup仅决定比较起点。原函数运行失败时位置未知，不记作零。报告和界面分别展示这些程序事实与AI解释。

模型输入移除机器反馈document中的重复JSON，只留文档哈希；提示明确这是去重投影，不能理解成资料未提供。源码不重复附文件副本，运行环境仅投影版本/限制，不将完整运行器哈希塞入解释上下文。历史实验/固定验证指标以列名和值表无损编码，保留每次尝试、失败原因、空值及未知字段；程序另计训练/验证收益正负零与未知数，不从总数猜“多数”。完整事实仍在服务器与业务快照保存，模型输入裁剪不替代验证输入。

新输入允许对完整analysis JSON字符串做一次严格无损解码，并记录normalizations；拒绝重复键、非有限数、截断或不完整JSON，不修补内容。历史输入v1至v6保持原对象校验。

AIRun保存feedback_workflow_version、audit_report_id和native_resume_run_id；复用WorkflowStep/WorkflowOutcome保存不可变输入、原稿、审查问题、完整修订、错误、用量和模型原始返回。普通请求输入合同v9，续作v10，实际模型调用保存完整提示；历史v1至v8按原合同重放。v5起包含位置事实，v8起选择原文区间，v9区分document去重与资料缺失、函数参数与本次literal绑定，且在定义不同前不另起金融参数方案。native Markdown v5将位置表按连续行渲染；复用的历史v4成果及其哈希保留。旧提示只对嵌入JSON的键序/格式做语义比较，原始字节与哈希保留；事实、其他数组顺序与提示指令不得改变。v8起的text_spans注册表按唯一ref规范化顺序比较，内容、字段路径、起止位置和原文须完全一致；原始提示字节及哈希仍保留。新注册表固定按字段键序生成，避免跨进程字典顺序导致恢复误拒。原始返回超过150000字符时只保留前段/全文长度与哈希，不能作为完成成果。阶段用量区分0次读取与实际调用，缺失tokens保持未知，不编造费用。

全部上述量化业务事实按已确认范围进入WebDAV/FTP/SFTP，schema54保护续作合同；旧快照缺少native_resume_run_id时明确为空，不借用本机较新指针。Job授权/租约/取消队列仍仅本机；量化事实捕获不包含提供商凭据。恢复逐阶段重建固定上下文、身份、引用/引文、原始返回解析、决策顺序、预算、最终标记及发布结果，并校验续作父链、连续检查点、原件指纹和用量0约束；重算哈希也不能改变复用内容或修订上限。不调用模型/Docker/源码，不恢复执行队列。哈希用于内部一致性，不是提供商签名或专家认证。

原始返回与完整固定输入按需读取，沿用所有者权限的阶段证据API；列表仅返回有界摘要。前端共同展示原稿来源、阶段决策、问题数、记录调用次数和详情，复用详情可直接打开原阶段的模型返回/用量依据，保留人工编辑报告的能力。local样例独立实现成功、一次修订、最终拒绝、取消、阶段失败/续作与详情；它不运行模型、Python、Docker或真实价格。

原始验证详情还展示同一固定反馈的前次AI解读与拒绝记录，最多最近10条并标明总量；不删除更早记录。历史区只读，可查看旧原稿、问题、原始返回和已归档报告。新完整解读不会让旧失败在详情中消失，业务快照仍保留全部记录；这些UI摘要不单独同步。
