# 搜索选择与过拟合诊断

核对日期：2026-10-25。应用1.5.46、量化schema49。当前在本机实验完成后，自动保存该请求的固定候选家族、尝试计数和开发期分块排名反转诊断，随AI复盘进入下一轮研究。它不改变实际赢家、留出结果、收益评分或验证层级。

## 当前计算范围

每次非滚动实验为一个家族；滚动实验按折分开。保留全部原始尝试ID、evaluated/rejected/cancelled/budget_stopped数量和可评价的不同公式/参数数量。被拒绝和未完整评价的尝试不伪造收益，重复的已评价配方只计算一次。当前计数仅覆盖本请求，不包括其他请求或外部试验，不声称覆盖完整研究者搜索历史。

计算从已冻结尝试重放训练与验证段的成本后逐期收益，并核对原汇总指标。每折只读取至其内层验证段末尾；不读取最终留出期，不再生成、修改或搜索候选。后折可使用当时已过去的前折数据，与[滚动规则](./量化文集一期说明.md)一致。

该方法参考[Bailey等的CSCV原始论文](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)，当前实现采用固定家族、每期成本后算术平均收益作为排名标准：开发收益分8个等长块，固定去掉最早不足整块的余数，要求每块至少5段。枚举全部70种四块/四块组合，在一半选出均值最高的候选，计算它在另一半的相对排名；低于中位视为反转。它与实际搜索中的训练Pareto和验证收益减回撤规则不同，是额外诊断。

均值并列容差固定为1e-12。样本内赢家并列不按名字或ID强行选一个；样本外排名恰在中位也保留歧义。展示已判定组合中的反转比例，以及把全部歧义分别计为非反转/反转的上下界。该范围是歧义界，不是统计置信区间；全部歧义时比例为null、状态证据不足，不显示零风险。

这是对已产生固定候选的条件诊断。它不重新训练，不是新的时序样本外、p值、多重检验显著性校正或盈利证明；低反转率不能抵消负收益、未记录的尝试或原生平台差异。完整跨请求搜索家族归集、正式多重检验控制及更高层嵌套评估仍需继续。

## 预算、发布和AI

诊断共享原本机实验的seconds总预算，最多使用剩余10秒。时间耗尽、取消、历史不足、候选不足或重放不可得时保留具体原因和计数，数值保持未知。取消后的本机授权仍以既有worker规则为准，不因读取或恢复生成诊断、实验或模型任务。

计算后的SelectionDiagnostic保存独立不可变身份，绑定来源请求、结果和行情哈希。实验详情直接读取，历史没有诊断的记录不在访问时回填。新的AI解读冻结其ID/hash，只接收有界摘要，不接收完整净收益序列、分块明细或全部70个组合。必须给selection_review并引用selection_diagnostic；遗漏或引用不符时不发布AI报告。正文可人工删改，原稿与计算事实保留。

同时解读固定新数据验证时，诊断指向来源搜索的开发期，不指向新的固定验证区间，也不修改预登记标准判定。诊断的32候选支持上限不是本次搜索预算；实际额度和剩余情况须依据execution.config及尝试计数核对。

## 持久化与同步

迁移0025新增SelectionDiagnostic，未改写旧实验结果或旧AI报告。新增记录按用户已确认的全部量化业务范围随WebDAV/FTP/SFTP同步，所有参与设备须支持schema49。恢复核对来源、哈希、时间顺序、家族计数及数值重放；不恢复任何执行授权。密钥和队列仍留本机。当前只在隔离测试库执行了迁移，开发业务库和正式环境尚未执行。

代码入口：quant/search_diagnostics分离纯分块数学、开发收益重放、发布、模型摘要和恢复验证；experiments/worker在授权发布前完成测量，jobs仅展示。前端独立SelectionDiagnostic组件、类型和严格数值读取；local使用明确标注的人工收益块，不执行导入行情。
