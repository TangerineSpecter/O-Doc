# 量化研究库分页与按需读取

核对日期：2026-10-30。适用于当前本地实现；不代表生产已部署。源码、Markdown、结构化报告、阶段证据与全部历史仍保存于现有数据库。本期优化读取与渲染，不迁移或去重存储，不修改模型研究或因子搜索算法。

## 当前加载规则

- 目录每批默认 50 条，`offset/limit`，最大 100。SQL 在分页前完成标题、补充笔记、标签搜索，类型与代码语言筛选；更新排序为 `updated_at DESC,id DESC`，名称排序为数据库 `title ASC,id ASC`。类型计数按当前搜索和语言条件统计整个文集。
- 每条摘要只包含 ID、标题、类型、创建/更新时间、质量分及最多 160 字预览。数据库先截取最多 640 字，再整理 Markdown 标记与空白；不把全文取入 Python 再截断。全文包含搜索仍有数据库扫描成本，未引入全文索引或语义搜索。
- 打开研究读取概览、报告/来源/任务摘要目录及一份当前报告。概览提供数量、默认报告、当前来源和活动任务 ID，不包含补充笔记、源码、报告、任务结果等正文。
- 报告、来源、实现、版本和任务的历史目录默认每批 20。报告当前正文不附加原稿和历史修订；原稿、修订目录和选中的单个修订分别按需请求。来源与代码版本只在用户查看、编辑或既有研究操作需要时读取。
- schema 5 报告的“完整执行证据与核算”展开后读取该报告固定来源，显示加载、缺失和错误重试状态；不依赖来源设置或反馈页签预先加载。历史报告没有内嵌研究记忆时，仅在研究详情的“全部 / 源码与进度”可见时补读对应任务正文，保留历史记忆回退。
- 已展开的修订使用稳定的报告 ID、修订 ID 和读取函数，父级分页或重渲染不重新启动读取；关闭后重新打开仍可复用有界缓存。单份代码实现正文加载后同步合并实现摘要，新增或分页外的实现也能出现在选择器中。
- 代码实现的当前版本与首批历史目录全部就绪后才发布加载状态，切换实现或离开页面仍取消未完成请求。回测列表按当前页的关联版本 ID 读取版本及所属实现摘要，独立于实现目录分页，不读取关联代码正文；刷新目录保留当前回测关联的实现摘要。
- 保存报告修订只返回该报告当前正文与修订标识；保留原有 409 并发修订检查。收集和依赖补交返回概览；创建/改名/采用实现返回实现摘要；取消任务返回状态摘要，均不附带全部历史。
- 周期轮询使用独立状态接口，返回活动任务状态、阶段进度、错误和内容变化标识；不返回 Markdown、源码、任务结果或任务要求。变化标识只基于计数、更新时间与默认报告身份等已有事实计算，不写库。报告/来源变化时刷新受影响的概览和摘要；正文版本相同则复用缓存。页面隐藏时暂停，间隔仍为原有节奏。
- 阶段进度通过 SQL 字段/JSON 路径投影，片段和问题数量在数据库统计，避免将完整输入/输出加载到 Python。SQLite JSON 路径提取仍需解析 JSON；PostgreSQL 也有解析、反 TOAST 等成本。完整阶段证据只在展开时读取。
- 只读概览、摘要、正文与阶段证据使用共享读取锁。状态查询在原有排他锁和恢复规则内处理过期任务；读取单个任务结果或目录不再恢复任务，不自动执行模型。

目录索引保留排序字段优先的现有顺序。2026-10-30 本地 SQLite 验证中，将 `is_valid` 前移会产生 `TEMP B-TREE` 排序，因此未采用该调整。

## HTTP 契约

以下路径以 `/api/quant/<collection>/entries/` 为根。JSON 仍使用 `{code,msg,data}`，HTTP 经现有 renderer 转换为驼峰；权限沿用私密文集所有者校验。不存在、跨文集或无权目标返回 404，不替换为另一份报告。

| 路径 | 返回内容 |
| --- | --- |
| `?offset=0&limit=50&q=&kind=&language=&sort=updated` | `{items,total,kindCounts,hasMore}`，摘要列表 |
| `<entry>/` | 概览、`counts/defaultReportId/currentSourceId/activeRunIds` |
| `<entry>/reading/notes/` | 单条补充笔记正文与基本字段 |
| `<entry>/reading/reports/` | 报告摘要分页：标题、类别、时间、评分、当前修订 ID/哈希 |
| `<entry>/reading/reports/<report>/` | 选中报告当前正文、展示数据及方案；无 `originalMarkdown/revisions` |
| `<entry>/reading/reports/<report>/original/` | 单份不可变原稿 |
| `<entry>/reading/reports/<report>/revisions/` | 修订元数据分页；无 Markdown |
| `<entry>/reading/reports/<report>/revisions/<revision>/` | 单个修订正文 |
| `<entry>/reading/sources/` | 来源摘要分页，支持 `provenance=external_feedback`；附当前来源与最新关联任务/报告 ID |
| `<entry>/reading/sources/<source>/` | 单份来源；`?metadata=1` 只返回摘要 |
| `<entry>/reading/implementations/` | 实现摘要分页 |
| `<entry>/reading/implementations/<implementation>/` | 实现设置，无历史代码；`?metadata=1` 只读摘要 |
| `<entry>/reading/implementations/<implementation>/versions/` | 代码版本元数据分页 |
| `<entry>/reading/versions/<version>/` | 单份代码；`?metadata=1` 只读元数据 |
| `<entry>/reading/runs/` | 任务摘要分页，无 `result` 或完整阶段证据 |
| `<entry>/reading/runs/<run>/` | 单个任务要求和阶段进度，无任务结果 |
| `<entry>/runs/<run>/` | 用户明确查看的单个任务完整结果；浏览器不以此周期轮询 |
| `<entry>/status/` | 活动任务摘要、默认报告 ID、`changeMarker` |
| `<entry>/reading/backtests/`、`reading/attachments/` | 各自分页；不附关联源码 |

旧 `GET <entry>/runs/` 同样返回摘要分页。原有命令、报告修订、阶段证据入口保留。当前浏览路径没有全量详情回退；完整领域序列化器仅供明确的业务结果及隔离旧版基准使用。

## 前端状态与错误恢复

`useQuantDirectory` 管理目录，搜索 300ms 防抖，切换条件取消旧请求并重置分页。追加按 ID 去重；显示已加载/匹配总数；追加失败保留原列表，重试原偏移。offset 分页面对其他客户端同时插入/删除可能产生移动位置，去重防止重复；刷新会重新从第一页取当前视图。

`useQuantWorkspace` 分开概览、元数据分页、正文与状态。页签读取和单个正文请求有各自取消生命周期，快速切换不会被写操作互斥锁吞掉。正文缓存只在内存中，按文集、研究、内容和修订/版本区分，最多 20 份或 5 MiB UTF-8 JSON 字节；LRU 淘汰、超大正文不入缓存。切换研究清空缓存；正在使用的正文与编辑草稿由组件持有，草稿不参与缓存淘汰。

显式选中的历史报告和编辑中的报告会固定 ID；任务完成不强制切换或覆盖草稿。未显式选择时跟随概览默认报告。保存后刷新当前正文和已打开的资源目录，加载过的附件、回测等不会一直显示旧数据。固定高度详情弹窗、分类栏、独立滚动、复制、编辑保存及离开保护继续保留。

`/quant/<collection>/entries/<entry>?report=<report>` 可直接打开未出现在已加载目录中的目标。若无报告参数，打开默认报告；显式无效报告显示错误，正文为空，不回退默认报告。

local mock 同步提供相同分页和正文契约，样例/空数据/慢请求/错误场景通过 `mockState=sample/empty/slow/error` 使用。`testReadingFixture.ts` 仅用于旧领域样例的完整事实断言，不注册 HTTP、不由应用导入；新增契约测试直接调用真实 mock 路由。

## 持久化与同步边界

不新增持久业务字段，不删除或覆盖冻结证据，不改写现有正文，不改变 WebDAV/FTP/SFTP 快照格式。当前量化同步版本沿用既有 `SCHEMA_VERSION`，本期不提升。`0034_quant_reading_indexes` 仅增加研究更新/名称排序、报告、修订、代码版本、活动任务和任务历史的 7 个复合索引；索引不进入业务快照。缓存、页签、搜索、分页偏移和变化标识均不持久化或同步。

本次仅在隔离 SQLite/PostgreSQL 数据库验证迁移；未对用户数据库运行迁移、未部署。未来正常发布时需按项目既有迁移流程应用索引。

## 手动容量诊断

```sh
uv run python manage.py quant_storage_audit --collection-id <文集ID>
```

只读命令按文集聚合笔记、代码版本、来源 JSON、报告 Markdown/数据、修订、任务结果/规划和阶段输入/输出的数量及逻辑 UTF-8 字节。不输出正文、凭据，不在日常页面运行；统计包含仍保留的软删除研究。另提供源码快照与关联代码版本、报告 JSON 与任务结果完全相同的观察数量，供以后评估去重。逻辑字节不等于压缩、索引、WAL、磁盘或同步备份大小；执行统计仍有扫描与 JSON 解析成本。

本期没有对真实业务文集执行容量诊断，也没有据此决定正文外置。下一期应结合实际字节量、访问频率、备份/同步耗时再判断。

### 2026-10-30 本地验收结果

新增读取与只读容量测试在 SQLite、PostgreSQL 各 11 项通过；前端量化 211 项测试、类型检查、量化范围 ESLint 和生产构建通过。构建仍有既有的大分块提示。纯 local 浏览器覆盖 1440、768、390px，包含代码保存、对照缓存、任务完成时草稿保持及离开保护，空/慢/错误场景均由 MSW 处理，无 501 或真实 API 放行。

完整后端量化回归运行 827 项，通过 825 项；图谱旧边类型断言和通达信假模型结果校验两项失败，在独立的干净 HEAD 导出副本中也能复现。本次调整了旧测试的详情读取入口及“新导出快照版本”的过时硬编码，没有改变业务快照版本。这次全量运行早于最后新增的两项读取测试，新增读取 11 项已在两种数据库单独全部验证。

最终 HTTP 编码基准中，1000 条目录从约 30.25 MB 降到 34.07 KB；100 份报告、各 5 个修订的首次阅读请求合计约 50.00 KB，旧全量详情约 24.24 MB。时间、SQL、峰值分配、首次与重复测量均保留在验收 JSON；重复服务器访问仍有数据库工作，浏览器命中正文缓存的重访没有正文 HTTP 请求。未对生产数据库执行迁移或容量扫描，未部署。
