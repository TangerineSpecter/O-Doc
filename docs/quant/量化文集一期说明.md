# 量化文集一期说明

核对日期：2026-10-22。本文描述量化研究库的代码实现及验证边界；正式部署迁移、真实模型和多设备远端同步须单独验收。

## 适用范围

量化文集（`Anthology.type=quant`）供本人收集因子、指标、策略及其研究证据。创建时强制私密，只允许所有者访问，不支持与其他文集互转。研究不进入普通文章表，不接行情、交易账户、脚本编译或执行环境。

## 当前规则与流程

1. 新建研究只要求标题，默认类型为因子。说明使用 Markdown，来源为 HTTP/HTTPS 链接，标签、代码和回测可后补。
2. 同一研究可保存多个 Python、Pine、MQL4 实现，每个实现保存名称、语言版本、依赖、参数和当前代码版本。每次保存或恢复历史创建新版本；代码及来源快照不可覆盖，验证说明可单独补充。不同设备新建版本使用稳定字符串 ID，不共用版本序号作为身份。
3. 回测在外部平台执行，在文集中手工记录标的、周期、时间区间、参数、费用假设、自填指标和结论。可关联本研究的具体代码版本，也可暂时为空并显示“代码版本未知”。空指标不补零、不推算收益，也不按不同测试条件自动排名。
4. 附件可以挂在研究、实现、版本或回测上，所有目标必须属于同一研究。同时关联回测与代码版本时，两者的明确版本必须一致；编辑回测不能改为与已有附件冲突的版本，需要先移除冲突的附件关联，系统不会静默改写附件证据。回测或附件未指定版本时仍可保存。普通文本脚本 `.py/.pine/.mq4/.mqh` 可读取成代码草稿，读取限制为 1 MiB；其他文件只保留原件。Notebook、CSV、第三方回测报告不自动解析。上传和下载不会执行代码；图片通过鉴权资源接口预览，其他附件下载。
5. AI 只提供解释和转换。用户选择已保存的来源版本、模型、转换目标和补充要求，系统冻结该版本后提交任务；不发送整个研究库或自动读取附件。任务可以查询、取消或显式重试，重复请求标识只对应同一个输入。每个文集最多同时保留 4 个有效任务；提交新任务前会回收该文集中所有研究的过期或缺失租约，并把旧任务标记为中断，不会重新派发。本机执行器仍持有任务时，跨文集排队超过初始 3 分钟不会误判中断；进程退出后由操作系统释放排队标记，原租约过期后即可回收。开始执行后仍使用 3 分钟续期租约和 120 秒模型调用时限。重复提交旧请求标识只返回原任务及恢复后的状态；重试中断任务必须由用户明确提交新请求标识。
6. 转换完成后先展示候选代码、差异、假设、依赖和限制，用户采用后新增实现，初始验证状态均为“待验证”。重复采用不重复创建。解释结果由用户主动加入说明草稿并保存，不能直接覆盖原文。
7. 编译、运行、结果核对由用户分别记录，系统不自动确认语义等价。失败、取消、超时或输出截断不产生正式代码版本。研究和文集采用逻辑删除，历史附件引用继续保护原文件；移除附件引用不删除文件。

## 数据与同步边界

用户已确认全部研究内容进入现有 WebDAV/FTP/SFTP 同步：`quant.Entry`、`Implementation`、`CodeVersion`、`Backtest`、`Attachment` 和 `AIRun` 是业务事实；源代码及结构化结果进入数据库快照，附件沿用 `Asset` 媒体清单与 Blob。手工验证记录和采用来源也随所属业务记录同步。

`quant.Job` 的执行租约、取消状态、阶段预览、临时上下文只留本机，不同步。排队存活标记是系统临时目录中的进程文件锁，不新增业务持久字段，也不进入同步；任务完成、队列 Future 取消或提交失败时释放标记。恢复会清除本机 Job 并将未完成 AIRun 标记为中断；需要用户显式重试，不会从快照重新授权模型调用。模型凭据沿用现有模型配置，不复制进量化请求或日志。

快照携带 `quant_schema_version=1`、记录清单和业务哈希；恢复前校验文集私密性、所属用户、实现与版本、回测、附件和 AI 来源引用。量化完整性错误不能由放宽 Agent 世界校验跳过。没有量化域的旧快照可以读取；同步仍遵循现有整库覆盖或三方合并语义。应用版本升级用于让旧客户端拒绝新快照，参与同步的设备应一同升级。

## 代码入口与 API

- 后端 `quant/`：models/serializers 表达数据与契约，services 处理版本、附件和候选采用，worker 管理有界模型请求，locking 协调写入与同步恢复，sync 管理快照校验及本机执行撤销。
- 页面 `/quant/:collId`、`/quant/:collId/entries/:entryId`；`QuantPage` 编排领域组件、Hook、API、类型和纯逻辑。编辑器使用 CodeMirror 6，提供行号、缩进、查找、撤销和代码保存，不承担编译检查。
- `/api/quant/<collId>/entries/` 下提供条目 CRUD、实现及版本、验证、回测、附件及脚本文本读取、AI 任务及取消/采用；全局 `/api/quant/models/` 返回可用对话模型和默认模型。遵循通用 `code/msg/data` 与驼峰接口约定。
- 请求先完成认证和文集归属预检，再取得文集锁及事务；锁内重新读取文集归属和研究有效性。未登录或无权访问的请求不会创建任意文集 ID 的锁文件，等待锁期间的删除或归属变化也不能绕过校验。
- 资源库通过显式 `quant_references` 识别研究引用，展示量化来源并阻止误删，包括已软删条目的历史证据。量化附件不能经旧 `/media/` 静态路径绕过鉴权。

## 验证与已知限制

纯 local 模式由 `frontend_react/src/mocks/quant/` 提供可修改样例，覆盖首页、研究详情、版本、回测、附件、模型和 AI 任务。样例/空数据/加载/错误必须分别验证；未匹配请求继续返回 501，不放行真实后台。local 数据仅为演示，不能作为真实回测成果。

后端测试必须使用隔离数据库、临时媒体和 fake 模型；不能读取或清理开发机真实媒体、触发同步调度器或连接真实远端。静态检查、隔离 API、local mock、真实模型及远端多设备同步是不同验收范围。具体本轮验证结果由交付说明记录。

2026-10-22 本轮验收：量化、资源和同步边界共 28 项隔离后端测试，纯逻辑与 local mock 共 9 项前端测试通过。浏览器验证了宽窄屏的新建、导航保存/放弃、代码版本、历史恢复、人工验证、回测、脚本附件、AI 解释追加/转换采用/取消重试和刷新恢复；样例、空、加载、错误的业务请求均由 Service Worker 处理，没有遗漏的 501 或真实后台请求。生产构建、类型检查与量化范围 ESLint 通过。未修改真实用户数据库；本机未配置对话模型，真实提供商转换效果与远端多设备同步未验收。
