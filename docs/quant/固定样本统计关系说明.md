# 固定样本统计关系

核对日期：2026-10-27。应用1.5.73、量化schema72。本文说明输出相关观察；[整体目标](../requirements/007-AI量化研究系统重构.md)中的互补、情景关系及真实环境验收仍须继续。

## 当前规则

从因子库“对照与逻辑分组”建立固定样本对照，明确两侧实际参数、输入映射、行情及共同预热。完整对照结束后可“计算并保存样本相关”，重复提交返回原记录；读取页面不计算。图谱独立展示统计边并跳回原对照。语义检索只读取semantic_similar边，不把统计系数当embedding相似度。

计算重建两侧受控表达式，核对包含时间戳的完整输出哈希与原比较一致；不运行原平台源码。最多20,000行、预热最多2,000行、15秒预算，与原对照共用两份并发上限。计算在业务写锁外进行，发布前重新核查文集、候选和原对照。超时、来源失效或输出漂移不保存关系，可显式重试；原报告、评分、对照和合并保持。

仅配对共同预热后同一行、同一时间戳的有效输出，不移位或分别删缺失后拼接。保存左右及共同缺失数、覆盖率、配对首末时间及绝对索引指纹。Pearson描述数值相关，Spearman对有效配对分别排序、并列取平均秩后求相关，依据见[NIST](https://www.itl.nist.gov/div898/software/dataplot/refman2/ch2/rankcorr.pdf)。布尔明确按0/1；单位不同不因此变成可直接组合的数据。

不足30个共同有效行为insufficient；常量或数值近常量使系数未定义时为undefined，未知不补零。30是本系统展示门槛，不是显著性门槛。沿用已有标签统计核的缩放/近常量检测，方法fixed-output-association-1、系数保留12位小数；不提供p值或独立样本量，不晋升验证等级。时序配对可能自相关或重叠；常量相关未定义亦见[SciPy](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.pearsonr.html)。

正、负、低相关及未定义均保留，不按收益筛选。相关为1仍不能证明等价：独立测试覆盖输出平移后对照失败但相关为1。互补仍须比较单独与组合在同成本、样本、参数范围下的增量表现，低相关不能代替该证据。

## 数据与代码

既有FactorRelation新增kind=sample_correlation，绑定原比较/行情身份与哈希、统计、配对规则及输出指纹。业务JSON沿用户确认范围进入WebDAV/FTP/SFTP，无新表或字段迁移。schema升72，旧客户端拒绝新包；旧语义关系合同保留。显式低schema不能携带统计关系，本机无远端元数据的导出预校验仍可重建。

恢复从不可变比较与行情重建系数、范围、端点及输出哈希；拒绝改系数后重算外层哈希、错绑对照/端点。仅运行有界受控表达式，不运行上传源码、平台、模型或恢复执行权限。没有读取原比较以外的行情；既有数据使用审计已计入原比较，不将这些数据重新当作新样本。

后端`quant/graph/correlation.py`负责计算/保存，`correlation_sync.py`恢复，`correlation_graph.py`图谱，`correlation_views.py`提供显式POST。接口`comparisons/<id>/correlation/`不接受覆盖参数，比较详情增加只读correlation与JSON字符串。前端CorrelationPanel、useQuantCorrelation、quantCorrelation分别维护展示、请求状态和合同校验；API、类型和local路由独立。
