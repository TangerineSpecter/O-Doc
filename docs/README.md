# 文档入口

按任务打开需要的文档，不必通读整个目录。仓库根目录的 `AGENTS.md` 是总入口；本页负责把任务导向专题索引或当前说明。

## 从任务进入

| 当前任务 | 先读 | 再按需阅读 |
| --- | --- | --- |
| 前端结构、职责拆分 | [项目结构文档](./项目结构文档.md) | [代码规范](./代码规范文档.md)、对应功能说明 |
| 页面视觉与交互 | [UI 设计规范](./UI设计规范文档.md) | 对应功能、图片或素材规范 |
| Agent 世界业务 | [Agent 文档导航](./agents/README.md) | 当前领域说明；涉及持久数据时读[数据同步逻辑](./数据同步逻辑说明.md) |
| 同步、恢复、迁移 | [数据同步逻辑](./数据同步逻辑说明.md) | 对应业务说明和迁移文件 |
| 新需求或需求交付 | [需求文档目录](./requirements/README.md) | [功能规划](./features/功能规划文档.md)用于中长期方向 |
| 种子、数据目录 | [数据目录说明](./data/README.md) | 对应数据集说明；战斗设计数据从[战斗设计目录](./data/combat/README.md)进入，运行内容见 `system_settings/agent_world/combat/data/` |
