# 小说文集与创作工作台

小说文集是独立的业务领域：`novel`。一个文集对应一本小说；章节不写入普通文章表，不进入文章搜索、MCP 文章检索或普通知识库。

## 使用流程

在首页选择小说文集，填写方向即可创建，书名可留空。系统生成暂定名，访问权限默认私密，创建或编辑时均可主动选择公开。公开只开放已发布章节，草稿和创作资料始终仅作者可见；没有发布章节时不进入公开列表。进入工作台后，可以与 AI 分次讨论、整理蓝图、比较文风样本、选择书名，或手工修改设定。AI 蓝图仍是候选，确认采用才写入人物、大纲和线索。

章节先填写细纲、出场人物、叙事视角和故事时间。正文可以手写，也可以按次生成、续写、选区改写、轻度润色、场景精修或剧情重写。使用候选结果只保存为草稿，选区操作只替换对应范围；生成后正文已变化时，候选不得覆盖新稿。

保存后执行检查，查看摘要、问题和状态变化。死亡、身份揭晓、线索回收、新增实体等关键变化需要确认。关键冲突需要处理或填写驳回理由；明确禁用词句必须移除或设置例外。采用后事实才进入故事记忆。发布必须主动确认，可选择公开或私密阅读，也可撤回。继续编辑不会改变已发布版本。

## 数据与状态

`Project` 保存方向、正式蓝图、模型覆盖、文风与筹备资料；`Message` 和 `Run` 保存讨论及候选结果。`Entity` 保存完整人物、地点、组织、物品等设定及开篇状态。`Outline` 保存全书、分卷和临近章节细纲。`Thread` 保存伏笔、钩子和剧情任务规划。

创作方向统一以 `Project.direction` 为准，首页小说文集的 `description` 接口字段和工作台的 `direction` 都读写这份资料，上限均为 30,000 字。`Anthology.description` 保留旧数据兼容，不再作为小说方向来源；普通文集简介仍为 100 字。公开文集只返回 `setup.public_synopsis`，不会暴露作者方向。

`Chapter` 的 `draft_id`、`adopted_id`、`published_id` 分别引用不可变 `Revision`。指针为稳定字符串，所有接口及同步校验核实章节归属。`Review` 保存检查结果、确认与驳回记录；`Fact` 记录带原文引文和偏移的状态、关系、知晓信息、事件及线索变化。已被正文历史或事实引用的人物禁止普通删除。

历史保留当前草稿及最近五份未引用版本。正在采用、发布、被证据或规则引用的版本额外保留。恢复历史版本生成新草稿，不变更采用和发布指针。

当前章的名称、分卷、顺序、细纲、出场人物、故事时间和视角纳入生成与审查的上下文校验。即使正文版本未变，修改这些资料后也不能直接使用旧候选或旧审查；重新生成或检查后才能继续。

筹备表单按字段保留未保存输入，模型切换和任务完成后的刷新不会覆盖它们；明确保存成功后清除已提交的本地修改，保存期间继续输入的内容仍保留。

同一正文版本重新审查时，采用会替换该版本此前提取的事实，旧审查记录保留。人物改名会保留原名为别名，蓝图关系也能按别名匹配原人物。物品转交同步更新新旧持有人的物品状态。重复添加已停用的同范围规则会合并并重新启用，不同适用范围的规则分别保存。

故事状态按有效采用版本重放，故事时间和目录顺序分开。当前场景排除明确晚于场景时间的事件；未知时间不补造。修改并重新采用旧章，会失效旧版本事实并标记后续采用章节待复核。后续正文不自动改写；依赖待复核前文的生成被阻止。

时间资料不完整时，回忆或预叙中的状态留在事件记录中，不覆盖当前人物状态。跨设备新增章节产生相同目录序号时，两份正文均保留并标为待复核；先调整章节顺序，再检查、采用和继续创作。

## AI 与检索

按小说覆盖主写和编辑模型；空值跟随系统主对话模型及轻量对话模型。每次任务有稳定请求键，本地租约、预览、取消及明确重试。恢复任务状态不自动重复执行中断请求。输出缺少正常结束标记、超过上限、空白或结构不完整时均视为失败，保留草稿与发布正文。

上下文包含本章结构化状态、正式规则、蓝图、近期已采用摘要和最多四个历史片段。向量索引使用独立 Chroma collection，查询后再次按小说、有效采用版本、章节进度和故事时间过滤。没有 embedding 或索引失败时，保留结构化与关键词检索，并在任务结果显示使用方式。索引是缓存，不能决定正文事实是否有效。

正文模型与向量调用进入现有真实用量台账；供应商未返回用量时保留未知。无 AgentWorld 居民，无自动连写整本，也无 AI 味百分比。文风调整依据具体问题、用户反例和采用的样本。

## API 和权限

作者接口 `/api/novel/<文集ID>/` 强制登录和归属验证。资料、章节、版本、任务、图谱记忆及导出均走作者接口。阅读接口 `/api/novel/<文集ID>/read/` 只返回有访问权限的发布目录与正文，不返回任何作者资料、未来大纲或检查结果。

新公开小说没有发布章节时不进入公开列表。普通文章访问路径明确排除小说文集。前端 `/novel/:collId` 根据归属进入工作台或阅读页；`/novel/:collId/read` 用于查看发布阅读效果。
