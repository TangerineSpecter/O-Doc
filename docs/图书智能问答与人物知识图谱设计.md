# 图书智能问答与人物知识图谱设计

## 目标

为图书文集提供可追溯的智能总结、问答与人物关系浏览能力，使用户能够询问“第几章讲了什么”“某个人为什么这样做”“两个人何时关系变化”等问题，而无需每次将整本书输入模型。

适用格式：TXT、EPUB、文字版 PDF。扫描版 PDF 需先完成 OCR；MOBI 建议先转换为 EPUB 或 HTML 后进入同一处理链路。

## 核心方案：分层索引 + RAG + 知识图谱

不采用“整本书全文直接输入模型”的方式。全文输入会超出上下文窗口、成本高、响应慢，也难以引用具体来源。

```text
图书文件
  └─ 内容解析
       ├─ 章节与段落切块 → 向量索引（RAG）
       ├─ 章节摘要 → 章节级索引
       ├─ 全书/卷摘要 → 全局索引
       └─ 实体与关系抽取 → 人物知识图谱
                                 └─ 每条关系均回链原文证据
```

### 分层 RAG

| 层级 | 保存内容 | 适合回答的问题 |
| --- | --- | --- |
| 段落块 | 原文、章节、页码或 EPUB CFI | 某件事发生了什么、原文依据是什么 |
| 章节 | 章节摘要、关键事件、人物状态 | 第 N 章讲了什么、某章的重要转折 |
| 全书/卷 | 主题、主线、人物弧光摘要 | 全书总结、核心主题、主要矛盾 |

每一个段落块必须保存 `bookId`、章节标题、章节序号、页码/CFI、原始文本与向量。回答必须带来源章节，并可跳转回阅读器的原始位置。

### 人物知识图谱

知识图谱用于保存稳定的关系结构和关系变化，不替代原文检索。

实体包括：人物、地点、组织、事件、物品。关系包括：亲属、师徒、恋人、同盟、敌对、上下级、加入、离开、拥有、发生于等。

每条关系边至少包含：

- 起点与终点实体；
- 关系类型与方向；
- 生效章节/事件范围；
- 当前状态（有效、已结束、发生变化）；
- 置信度；
- 原文证据块、章节及页码/CFI。

例如：`张三 --师徒--> 李四` 可记录“第 2 章建立”“第 12 章转为敌对”，两条状态均指向原文证据。

## 问答流程

### 章节总结

用户询问“第 5 章说了什么”时，优先读取章节摘要；模型可补充该章的关键段落，并输出章节引用。

### 事实与原因问答

用户询问“为什么某角色会这样做”时：

1. 先使用人物、事件和章节条件检索相关段落；
2. 若问题涉及因果，扩展检索前置动机、冲突和后续结果；
3. 将有限的高相关证据交给模型推理；
4. 以“直接原因 / 前置铺垫 / 不确定之处”组织回答，并标注章节来源。

### 人物关系问答与可视化

用户询问“张三与李四是什么关系”时，先查询图谱关系边，再用关联原文验证。用户查看人物关系图时，以人物为中心显示一至两跳关系；点击节点或连线可打开关系说明与对应章节证据。

对于“为何反目”这类关系变化问题，图谱先定位“关系变化”节点，再由 RAG 检索变化前后的章节，生成带证据的因果解释。

## 数据处理与任务设计

图书导入后使用后台异步任务处理，避免阻塞上传或阅读：

1. 解析格式并识别章节、标题与阅读定位；
2. 清理文本，按章节与语义段落切块，保留少量重叠上下文；
3. 生成段落向量、章节摘要和全书摘要；
4. 抽取实体、事件和候选关系；
5. 将关系与原文证据关联，写入图数据库或关系表；
6. 在图书详情显示处理状态、失败原因和可重试入口。

## 准确性与编辑原则

- RAG 是原文证据来源；图谱只是结构化索引，不能脱离证据独立断言。
- 自动抽取的实体与关系必须带置信度，低置信度不直接显示为事实。
- 用户应能编辑、合并、删除人物和关系，并能标记“别名”。
- 模型无法从证据中确认时，应明确说明信息不足，不能补写剧情或关系。
- 同名人物、代词指代、关系随剧情变化是重点校验场景。

## 分阶段实施

### 第一阶段：可引用的图书 RAG

支持 TXT、EPUB、文字版 PDF 的章节化解析、段落向量检索、章节总结与问答；回答可跳回章节/页码/CFI。

### 第二阶段：分层摘要与跨章问答

增加章节和全书摘要，支持更稳定的“本章总结”“人物变化”“全书主题”“跨章因果”类问题。

### 第三阶段：人物知识图谱

增加实体、事件与有证据的关系边；提供人物关系图、关系变化时间线、人工修正与图谱辅助问答。

## 验收标准

- 用户可对一本书提问，并得到包含章节/位置引用的回答。
- “第 N 章总结”优先使用章节摘要，且能查看对应原文。
- 对跨章节人物动机问题，回答能列出直接证据和前置铺垫。
- 人物关系图中的每条自动关系均能展示原文证据；无证据关系不得作为确定事实展示。
- 图书处理、向量索引和图谱抽取均可独立重试，不影响阅读功能。
