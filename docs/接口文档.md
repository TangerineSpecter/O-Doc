# 【小橘文档】接口文档

本文档描述了 `小橘文档` 项目的API接口规范，包括接口列表、请求参数、响应格式等信息。

## 📋 文档说明

- 接口基础URL：`http://localhost:11800/api/v1`
- 请求方式：支持GET、POST、PUT、DELETE等HTTP方法
- 响应格式：统一返回JSON格式数据
- 认证方式：JWT Token认证

#### 2.1 创建文章接口

**请求路径**：`/api/article/create`
**请求方式**：`POST`
**请求参数**：

```json
{
  "title": "文章标题",
  "content": "文章内容（Markdown格式）",
  "collId": "所属文集ID",
  "permission": "public",
  "categoryId": "所属分类ID",
  "sort": 0
}
```

**参数说明**：
| 参数名 | 类型 | 必填 | 描述 |
|-------|------|------|------|
| title | string | 是 | 文章标题 |
| content | string | 是 | 文章内容（Markdown格式） |
| collId | string | 是 | 所属文集ID |
| permission | string | 否 | 文章权限，可选值：public（公开）、private（私有），默认值：public |
| categoryId | string | 否 | 所属分类ID |
| sort | number | 否 | 文章排序值，值越小越靠前，默认值：0 |

**响应示例**：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "id": 1,
    "articleId": "art_1234567890",
    "title": "文章标题",
    "content": "文章内容（Markdown格式）",
    "collId": "col_1234567890",
    "author": "admin",
    "createdAt": "2024-01-01T00:00:00Z",
    "updatedAt": "2024-01-01T00:00:00Z",
    "isValid": true,
    "permission": "public",
    "readCount": 0,
    "categoryId": "cat_1234567890",
    "sort": 0
  }
}
```

- `file`: 要上传的文件（multipart/form-data格式）
- `linked`: 是否关联文章（可选，布尔值）
- `sourceArticle`: 关联的文章ID（可选，字符串）
- `source_type`: 资源来源类型（可选，字符串），取值范围：
  - `attachment`: 附件上传
  - `content`: 笔记编辑器内插入上传

- 当从笔记编辑器内插入上传图片等资源时，请设置`source_type=content`
- 当从附件管理界面上传资源时，请设置`source_type=attachment`

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "resource_id": "res_1234567890",
    "name": "需求说明书_v1.pdf",
    "type": "doc",
    "size": "2.5 MB",
    "date": "11-24",

    "sourceType": "attachment",

  }
```
