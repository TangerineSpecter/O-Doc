# 文章来源与视频笔记

2026-11-17，适用于 1.6.14 起的文章文集。

## 创建和阅读

文章文集的「新建内容 → 视频笔记」接受 B 站视频页、b23.tv 短链、抖音单条公开视频以及含这些链接的分享文本。B 站采用指定分 P，未指定时采用 P1。任务只对文集所有者可见，关闭弹窗或刷新后可在同一台服务的「本机最近任务」中找回。点击完成任务的「打开笔记」进入普通 Markdown 阅读和编辑页。

优先使用平台字幕，无可用字幕时提取音轨并在部署机器用 CPU 转写。遇到平台登录、验证或媒体不可读，可给原任务上传对应的本地视频。单条最长 3 小时，输入媒体上限 512 MiB，整机待处理上传文件总量上限 4 GiB。任务按设备串行执行；失败后可重试或重新上传。补传后应使用与分享链接相同的视频，以保持章节定位准确。

默认文本模型将实际字幕段落整理为速读结论和按主题展开的正文。章节锚点由真实段落起点生成，B 站使用分 P 和秒数回看，抖音显示时间码。FFmpeg 提取原画面，过滤暗屏、缺少细节和相似帧；默认识图模型可为相关主题选择图片，最多八张。取得字幕但画面不可用、识图失败或纯口播时可保存文字版。仅最终选中的截图进入文章资源。

## 部署

1. 更新镜像，启动应用并完成 `article.0028_video_notes` 迁移。镜像安装 FFmpeg、yt-dlp 和 faster-whisper，Compose 挂载 `deploy/runtime/video_notes`。本机开发需安装 requirements.txt 依赖并提供 ffmpeg、ffprobe。
2. 在系统模型设置中选择默认聊天模型和默认识图模型。模型接收转写文本与筛选后的候选画面；语音识别在 O-Doc 主机执行。
3. 管理员打开「系统设置 → AI 模型接入 → 视频转写模型」，点击「下载模型」。后台从 ModelScope 魔搭下载 `pengzhendong/faster-whisper-small` 多语言模型，约 464 MiB，显示下载进度、加载验证和就绪状态。关闭页面后下载继续；服务重启中断时页面提供重试，已完整校验的文件可复用。下载经固定版本、文件大小和 SHA-256 校验，并在独立进程实际加载成功后标记就绪。完成后返回视频任务重试。
   模型保存在 `runtime/video_notes/models/modelscope-small`，Compose 对应宿主机 `deploy/runtime/video_notes/models/modelscope-small`。模型和进度属于本机执行数据，沿用本机缓存范围。已有 Hugging Face 离线缓存仍可读取；新下载使用魔搭。命令行 `python manage.py prepare_video_asr` 保留并复用相同下载逻辑。自定义 `ODOC_VIDEO_ASR_MODEL` 可沿用已有离线缓存或本地模型目录；页面下载目前对应默认 `small`。
4. 经反向代理部署时，上传请求体限制需覆盖计划接受的视频大小及 multipart 开销。服务自身会校验视频大小、可用空间和实际媒体时长。

## 来源与同步

列表、详情和目录树均提供只读 `creationSource`。从「新建文档」创建记为 `manual`，网页和文件导入记为 `imported`，视频生成记为 `video_note`。历史原样 HTML 有明确的导入依据，其他未分类历史记录为 `unknown`。编辑、润色及历史恢复保留来源。目录和编辑器仍按 `contentFormat` 选择 Markdown 或 HTML 呈现。

自动下载的视频、音轨和候选截图写入运行后端的机器，归各次处理独立使用。成稿保存后，只将选中的截图复制到文章资源，随后清理整个任务目录。普通失败也会清理本次下载、解码文件和候选帧。若进程中断，下次接手任务时会先清理上次的处理目录。

默认临时目录为项目下的 `runtime/video_notes`，可通过 `ODOC_VIDEO_ROOT` 指定媒体同步目录之外的专用绝对路径；空值、相对路径、项目/用户/媒体/系统临时根目录及其上级路径均拒绝使用。任务目录必须是该根目录内的直接子目录，不接受符号链接。定期清理只处理数据库中仍有对应任务记录的目录；无法确认归属的 UUID 目录保留，不按目录名称推断归属或自动删除。

为支持重试，失败或待补传任务中的上传副本、已完成的转写稿和来源信息可保留 24 小时，之后由后台定期清理。用户自己选择上传的原文件仍在原处。任务记录可继续查询，转写模型缓存由整台设备复用。

WebDAV 同步文章、来源、正文时间码和成稿截图。入口在 `article/video_notes/`，同步边界见[数据同步逻辑](../数据同步逻辑说明.md)。
