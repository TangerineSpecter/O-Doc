# 原样 HTML 笔记

私有 HTML 的转换副本也按文章权限保护正文和素材；历史 Markdown 权限行为保持兼容。包内样式内联后保留 `media` 与 `@import` 的媒体、layer、supports 条件，不把打印样式应用到普通阅读页面。副本移除图片并保存后，该图片不再因旧关联被计为共享资源。

在文章文集的「导入网页 / 文件」中选择文件与「保留原样 HTML」。解析导入仍是默认模式，可编辑 HTML 提取后的 Markdown。原样模式支持自包含 HTML / HTM，或 HTML 与素材目录组成的 ZIP；多个 HTML 分别生成笔记。单上传文件上限 30 MB，ZIP 最多 500 项、解压后最多 100 MB，缺失相对素材时整包拒绝并列出路径。

「原样」保留静态 HTML、内联 CSS 和包内 CSS，不执行脚本或表单，不加载远程图片/字体/样式。首版支持 JPEG、PNG、GIF、WebP 及包内字体；SVG 等主动内容素材不支持。ZIP 的原包、各 HTML 原文件、安全预览及本地素材都记入资源库；用户范围内按哈希复用资源。

阅读页显示 HTML 原样笔记 / 只读，目录仅通过同色小图标和悬停提示区分类型。可修改标题、分类、标签、权限和所属文集；含子文章时不能跨文集移动。可下载 HTML 原文件或完整 ZIP 原包。「转换为可编辑笔记」创建独立 Markdown 副本、保留原笔记，继承分类/标签/权限与正文图片引用。原样笔记不支持划线评论，副本支持。

全文搜索、字数与现有手动 / 文集 / 自动 RAG 使用专门提取的 Markdown：保留页头摘要、段落、列表、表格与技术代码块，排除页面 CSS、脚本、标签和图片编码。图片说明与 alt 文字可进入正文，图片不做 OCR；无文字内容不计为 RAG 同步成功。

删除确认显示专属清理资源与共享保留资源数量，提示不可恢复。仅清理 HTML 导入新建且没有有效文章 / 图库 / Agent / 图书引用的资源，不清理已有资源库去重得到的资源。转换副本仍在使用的图片保留；文件清理失败记录待重试，运行 `python manage.py cleanup_html_resources`，后续 HTML 删除或同步应用也会重试。

部署前运行 `python manage.py migrate` 并重启服务，前端版本 0.9.8。同步设备须共同升级；详见《数据同步逻辑说明》。测试必须使用临时数据库及临时媒体目录。
