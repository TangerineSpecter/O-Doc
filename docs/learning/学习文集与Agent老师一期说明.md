# 学习文集与 Agent 老师一期

## 功能与入口

新建文集选择「学习文集」，仅本人私密使用，不能与其他类型互相转换或改为公开。首页增加类型筛选，卡片显示已完成练习和待完成数量，不计文章或 RAG 状态。

进入 `/learning/:collId` 选择英语学习大方向、填写可选补充、确认目标预览，并设置可选起始自评水平、每次时间、题量、未完成上限、老师名称、现有对话模型和教学风格。默认 10 分钟、5 题、上限 2 份；题量 3–10，上限 1–5。老师属于学习文集，完全独立于 Agent 世界，不创建居民或写入世界记忆、体力、账本。

首次为 5 题轻量初测，批改后老师提出三个阶段，用户可编辑并确认。初测不是正式水平认证；计划未确认时不能继续出新练习。每阶段完成 5 份不同的普通练习后自动排队评估；阶段切换由用户确认。目标或场景变化保留原计划并新增待确认版本，用户可调整重点；不改写历史题目或作答。

## 作答、讲解与老师交流

支持单选、填空、简答、翻译。题目、答案、评分标准、知识点和出题配置保存快照。提交前的详情不返回参考答案或评分标准，主动查看答案标记辅助；重新练习保留旧作答。

草稿 800ms 自动保存、离开输入框保存，提交和向老师提问前等待保存完成。未保存时关闭／刷新页面显示浏览器离开提示。草稿版本不一致返回 409，不静默覆盖，页面可重新加载核对。提交后答案不可修改，跳过题不计入平均分或知识点错误，同时显示完成比例。

单选按确定答案判分；填空只归一化大小写和首尾空白，不随意丢弃标点。简答／翻译使用意思与任务、语法与用词、自然度与场景三个分项，默认 40／30／30，题目可保存不同正整数权重，总和必须 100。模型判断、分项和总分须一致；批改无效、超时或失败显示失败并保留答案，绝不填零分。参考答案不是唯一正确句子。

每份正式作答可主动复核一次，原评分与复核版本均保存。失败重试不消耗额外复核机会；当前有效评分参与评估，不重复累计证据。填空复核由老师评估合理替代表达，单选仍按确定答案。

老师聊天可结合目标、知识点、最近聊天、当前题目及有效成绩，提供中文解释和建议。提交前只给提示，未提供答案快照；请求题目帮助立即标记辅助。没有指定题目的交流在存在草稿时保守标记当前草稿全部题目为辅助。聊天不能直接改分、确认计划或修改目标。可补充／纠正画像，保留原始事实，后续老师评估参考修正说明。

## 学习证据与复习

画像由正式作答和当前有效评分重算，按用户所属学习文集隔离；聊天记忆不能代替学习事实。同次作答的同一知识点聚合为一条证据。画像状态为待评估、学习中、初步掌握、需复习，并关联具体练习和作答。

独立作答达到 80 分，间隔依次 1、3、7、14、30 天；低于 80 或有提示／查看答案则次日复习，不推进间隔。三个不同练习、至少两个日期、至少一次到期复习通过，才算初步掌握。到期标记需复习但不记错，不显示遗忘概率，也不因缺席推断能力降低。这是产品初始启发式规则，代码集中于 `learning/progress.py`，不代表科学测得的掌握概率。

下一份最多 60% 题目复习到期知识点，剩余围绕阶段重点；复习尽量换例子、换场景。复习仅记录知识点到期，不预生成题目队列。14 天未完成练习后下一份为 3 题回顾，完成后恢复正常阶段练习，不补发缺席作业。

## 调度与失败恢复

未完成包括生成预留、待开始、作答中、批改中与批改失败。生成前短事务预留名额，跨进程文集锁防止手动、定时或双击超量；初测和回归复习不重复堆积。重练也遵守名额上限。主动结束释放名额、保留作答与历史，取消未完成请求；生成技术失败释放名额。

定时默认关闭，配置时间与 IANA 时区，每天最多一份。仅在当日计划时间后两分钟内触发，开启时已错过该时段不补发，关机或漏过不追补。本机后台请求串行处理，设置有界模型调用；跨进程租约防重复认领，五分钟失联请求标记失败，不能自动重放未知调用。

项目 `USE_TZ=False`，持久时间以项目上海时区解释，再转换到课程时区；页面时间输出显式偏移。仅一个设备开启自动出题。WebDAV 不提供实时分布式锁，离线设备手动出题可能合并后超量，保留全部事实并暂停新生成，不丢弃学生记录。

## 数据、接口与同步

`learning` app 拆分模型、生成校验、评分、学习证据、事务服务、展示、安全接口、工作线程及同步。持久对象：Course、Plan、KnowledgePoint、Exercise、Attempt、Grade、Evaluation、Correction、ChatMessage、Request、GoalProposal。所有对象使用稳定身份，知识点按课程与归一化名称去重。

用户已确认以上全部业务数据参与 WebDAV，包括题目答案、草稿、提交、评分版本、老师评估、画像修正和聊天。Runtime（本机自动开关／租约）、DeviceJob（本机模型请求授权）与 GoalJob（目标整理本机授权／租约）不同步，加入本机排除范围；无新凭证副本。同步注册修订与删除墓碑，快照加入 `learning_schema_version=3`、记录清单及业务事实哈希。

导出／恢复独占学习域锁，日常文集事务持共享域锁；模型网络调用不持锁。恢复先校验完整性、关联归属、答案与评分事实，失败不写库。旧快照完全没有学习域兼容；新版缺少业务记录拒绝恢复。重复恢复不累计证据。恢复后关闭自动执行、清理本机授权，未完成请求转人工重试，绝不自动再调用模型。所有设备升级并迁移后再交换学习快照。

`/api/learning/` 提供：`models/`；`<collId>/` 配置与首页；`goals/` 目标提案创建／状态查询；`generate/`；`exercises/<id>/` 查询／开始／结束；`attempts/<id>/` 保存／提交／查看答案／重试／复核；`plan/` 确认版本；`chat/`；`profile/` 评估与修正。异步状态包含在首页及练习详情。沿用 `code/msg/data` 和驼峰转换。

答案接口使用 `answerItems: [{questionId, answer}]`，ID 是字段值，不作为 JSON 字典键，以免通用驼峰转换改写含数字或下划线的题目身份。内部存储仍为题目 ID 到答案的字典。前端 API 层统一转换，不在 UI 散落转换逻辑。

学习数据不进入普通文章、公开搜索或 RAG；学习接口始终校验认证与文集归属，不能通过他人对象 ID 查询题目、成绩、聊天或画像。

## 起始自评与动态学习评估

自评可选，新学习文集默认“不确定，让老师初测”。现有自评保留为用户声明的起始记录；只在初测生成快照中作为 `starting_level` 参考，后续生成不再携带静态 `level`，不构成难度上限，也不自动改写用户声明。

动态评估从当前有效评分重算，每份练习采用最近一次有效作答，按最近提交顺序选取最多三份不同练习的证据。同一练习重练不增加独立迁移证据，但新的得分与辅助状态替换旧表现；跳过题不计证据，复核替换原评分。最近表现低于80分或使用帮助时建议巩固；近期至少两份不同练习独立达到80分时建议逐步提升挑战；仅一次合格时继续换题检测。新知识点先探测。到期和缺席不直接降低难度判断。动态挑战建议与长期掌握状态分别展示，不能把一次高分等同于掌握。

出题请求保存生成时的动态评估与证据快照，老师按知识点建议调整场景复杂度和独立表达要求；聊天与阶段评估也接入动态评估。画像页面显示判断及理由，不伪造CEFR或考试等级。具体题目难度仍由模型执行，需要真实模型教学质量验收。

没有新增持久领域字段：沿用已同步的自评与请求快照；动态评估是有效作答事实的派生结果，恢复后重算，不单独同步或累加。新增迁移仅将新文集默认自评改为“不确定”，不修改已有值。


## 选择目标、整理与确认

学习设置合并自由目标和场景，使用“学习内容 → 学习方向”：当前学习内容为英语，方向为工作沟通、旅行交流、基础提升、还不确定。默认不预选，方向可多选；不确定与具体选项互斥。点餐／问路等细项不再要求逐个勾选，由阶段计划安排。补充描述可留空。场景字段保留为服务端从目标派生的教学方向，界面不再要求用户重复填写。

只有预设选项时，服务端使用明确的能力目标组合成预览，不调用模型。有补充时，持久 GoalProposal 保存输入与模型快照，由本机学习工作线程整理：空泛英语需求具体化，无关／乱码／恶意指令拒绝；不现实时间或选择与补充冲突时给可行建议并说明取舍。基础格式校验在模型调用前完成；语义判断与整理质量由模型承担，必须继续做真实模型验收。

提案状态 pending／running／ready／rejected／failed／confirmed；关闭或刷新可查询继续，失败可手动重新整理。请求键幂等，同一文集最多一条未完成目标整理；整理不生成练习、不占练习名额，也不修改已有配置和计划。点击“确认目标并保存”才生效。服务端校验文集归属、提案状态和目标／方向匹配，禁止直接提交未确认描述或篡改提案。历史目标保持兼容，修改时间、模型等时无需重新整理；修改目标仍创建待确认计划版本并保留历史。

GoalProposal 输入、结果、确认与状态是同步事实；GoalJob 是明确排除同步的本机执行许可和租约，恢复清除许可、未完成提案标失败，不调用未知结果的模型请求。学习快照版本升级为3，旧版0／1／2可兼容，所有设备升级并迁移后交换新版快照。


## 学科目录与扩展边界

`learning/catalog.py` 按学科组织启用目录、学习大方向、默认能力目标及历史细分 ID 映射；`/api/learning/catalog/` 提供认证后的目录，前端动态读取，不硬编码英语选项。提案保存 `subject`，历史快照缺少时按英语解释；当前只能选英语。旧细分 ID 继续用于历史提案校验与恢复，界面回显映射到大方向，但原提案、目标和练习不会自动扩写。

未来编程可采用“编程 → 入门基础／实际项目／算法”等同层目录，接入对应出题、题型与评分规则后再注册启用；仅注册目录不能视为完成编程教学。一期的英语出题与质量批改保持英语领域实现，不开放编程空入口。课程学科保持稳定，更换学科应新建学习文集，避免混合学习证据。没有新增数据库字段或迁移；新增学科身份保存在已同步的提案 JSON 快照中，学习同步格式版本3明确要求所有设备升级。

计划确认校验补充：手动与定时生成统一检查最新计划版本，最新版本未确认时拒绝新增普通／回顾练习；不能回退到历史已确认计划。已有生成请求及练习保持原快照。
