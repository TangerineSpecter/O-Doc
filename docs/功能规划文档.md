# 小橘文档功能规划文档

本文档用于记录小橘文档后续可考虑建设的功能方向，便于按价值、复杂度和现有架构契合度选择迭代内容。

## 规划原则

- 优先增强知识沉淀、检索、复用与协作能力。
- 优先复用现有文集、文章、Memos、白板、图片文集、AI、MCP、RAG、云端同步与统计模块。
- 避免把产品做成过重的任务管理系统；碎片想法与轻量清单仍以 Memos 和 Markdown 清单为主。
- 面向个人知识库与小团队知识库场景，保持轻量、清爽、可自部署。

## 优先级建议

| 优先级 | 功能方向 | 用户价值 | 实现复杂度 | 备注 |
| --- | --- | --- | --- | --- |
| P0 | 文章版本历史与快照回滚 | 防止误删误改，尤其适合 AI 润色、长文编辑 | 中 | 可先只记录文章标题、正文、标签、分类、文集变更 |
| P0 | 回收站 | 降低删除成本，提升安全感 | 中 | 覆盖文章、文集、Memos、图片、白板时需分阶段做 |
| P1 | 文章模板库 | 提升创作效率，适合周报、方案、会议纪要等固定格式 | 低到中 | 可先做前端模板选择 + 创建文章时填充 Markdown |
| P1 | 双向链接与反向链接 | 强化知识网络，连接文章与 Memos | 中到高 | 可从 `[[标题]]` 语法和文章详情反链面板开始 |
| P1 | 公开分享链接 | 方便对外展示单篇文章或文集 | 中 | 需要权限、有效期、密码等安全策略 |
| P2 | AI 文档操作面板 | 把 AI 从聊天入口变成文档生产力工具 | 中 | 总结本文、生成大纲、提取 TODO、生成脑图、找相关内容 |
| P2 | 导入导出增强 | 降低迁移成本，增强数据主权 | 中到高 | Markdown/ZIP 优先，Notion/语雀/飞书可后置 |
| P2 | 全文搜索增强 | 提升大规模内容下的查找效率 | 中 | 支持文章正文、Memos、图片描述、附件名，命中高亮 |
| P3 | 评论与批注 | 适合团队知识协作 | 高 | 需要段落定位、通知、权限与已读状态 |
| P3 | PWA 与移动端快速记录 | 提升随手记录体验 | 中 | 可先做移动端 Memos 快速入口 |

## P0：文章版本历史与快照回滚

### 功能目标

- 每次保存文章时生成版本快照，用户可以查看历史版本。
- 支持对比当前版本与历史版本。
- 支持从某个历史版本恢复。

### 建议范围

- 第一期只覆盖文章，不覆盖图片、白板和 Memos。
- 快照字段包含标题、正文、文集、分类、标签、摘要、更新时间、操作者。
- 列表展示版本时间、操作者、字数变化。

### 可能涉及模块

- 后端：`article` 新增版本模型与接口。
- 前端：编辑器保存逻辑、文章详情或编辑器侧边栏新增版本入口。
- 同步：WebDAV 备份可自然包含数据库快照，无需单独处理。

## P0：回收站

### 功能目标

- 删除操作先进入回收站，而不是立即永久删除。
- 支持恢复与彻底删除。
- 支持按类型筛选：文章、文集、Memos、图片、白板、资源。

### 建议范围

- 第一期优先覆盖文章与 Memos。
- 第二期覆盖文集、图片与白板。
- 永久删除可增加二次确认。

### 设计注意

- 文集删除时需要明确是否连带隐藏或删除子文章。
- 图片和资源要考虑文件是否仍被其他内容引用。
- 回收站页面可以放在设置页或资源管理附近。

## P1：文章模板库

### 功能目标

- 新建文章时可从模板创建。
- 模板可自定义、编辑、删除、排序。
- 支持按场景分类，如技术方案、会议纪要、周报、读书笔记、复盘、产品文档。

### 建议范围

- 第一期内置系统模板，不做复杂变量。
- 第二期支持用户自定义模板。
- 第三期支持变量占位符，如日期、作者、文集名。

### 示例模板

- 技术方案：背景、目标、方案设计、接口变更、风险、测试计划。
- 会议纪要：会议目标、结论、行动项、负责人、截止时间。
- 读书笔记：核心观点、摘录、个人理解、可实践点。
- 周报：本周进展、问题风险、下周计划、需要协助。

## P1：双向链接与反向链接

### 功能目标

- 支持在文章或 Memos 中通过 `[[标题]]` 引用其他内容。
- 被引用内容可以看到反向链接。
- 文章详情页展示相关引用，帮助知识发现。

### 建议范围

- 第一期支持文章之间的双向链接。
- 第二期支持 Memos 与文章互链。
- 第三期结合 RAG/向量相似度提供“可能相关内容”。

### 设计注意

- 标题重名时需要处理歧义，可在选择浮层中选择具体文章。
- 删除或改名时保留链接文本，并提示链接失效。
- 不建议一开始做太复杂的图数据库，普通关系表即可起步。

## P1：公开分享链接

### 功能目标

- 为单篇文章或整个文集生成只读分享链接。
- 可设置分享有效期、访问密码、是否允许搜索引擎收录。
- 可随时关闭分享。

### 建议范围

- 第一期只支持单篇文章公开分享。
- 第二期支持文集分享。
- 第三期支持访问统计与分享页主题配置。

### 安全注意

- 私有内容默认不可公开，需要显式开启。
- 分享链接使用不可猜测 token。
- 密码和有效期校验在后端完成。

## P2：AI 文档操作面板

### 功能目标

- 在文章详情与编辑器中提供快捷 AI 操作。
- 减少用户把正文复制到 AI 聊天窗口的步骤。

### 候选动作

- 总结本文。
- 生成文章大纲。
- 提取行动项。
- 生成标签建议。
- 生成摘要。
- 生成脑图。
- 查找相关文档。
- 改写为更正式、简洁或口语化版本。

### 设计注意

- AI 操作应明确是否会改写原文。
- 自动写回文章前必须让用户确认。
- 长文处理需要进度提示和失败重试。

## P2：导入导出增强

### 功能目标

- 让用户更容易迁移已有知识资产。
- 增强自部署产品的数据可控感。

### 候选能力

- Markdown 文件夹导入。
- 文集 ZIP 导出。
- 单篇文章导出 Markdown。
- 整站数据导出。
- Notion、语雀、飞书文档导入。

### 建议顺序

1. 单篇文章 Markdown 导出。
2. 文集 Markdown/ZIP 导出。
3. Markdown 文件夹导入为文集。
4. 第三方平台导入。

## P2：全文搜索增强

### 功能目标

- 统一搜索文章、Memos、图片描述、附件名。
- 展示命中片段并高亮关键词。
- 支持按内容类型、标签、分类、时间过滤。

### 建议范围

- 第一期增强现有全局搜索弹窗。
- 第二期增加搜索结果页，适合大量内容。
- 第三期结合向量检索支持语义搜索。

## P3：评论与批注

### 功能目标

- 团队成员可以对文章段落发表评论。
- 支持解决、回复、通知。

### 复杂点

- Markdown 内容变更后，段落定位可能失效。
- 需要设计通知和权限。
- 和公开分享、团队协作能力关联较强，适合后置。

## P3：PWA 与移动端快速记录

### 功能目标

- 支持移动端添加到桌面。
- 支持更快记录 Memos。
- 支持弱网或离线草稿。

### 建议范围

- 第一期优化 Memos 移动端输入体验。
- 第二期加入 PWA manifest 和图标。
- 第三期支持本地草稿缓存与后台同步。

## 暂不建议重新做独立 TODO 模块

早期规划中的独立 TODO 功能已经合并到 Memos 和 Markdown 清单场景中。从当前产品定位看，独立任务管理会引入任务状态、优先级、截止日期、提醒、看板等一整套复杂度，容易偏离知识管理主线。

更轻量的替代方案：

- 在文章编辑器中继续保留 Markdown 待办清单语法 `- [ ]`。
- 在 AI 文档操作中支持“提取行动项”。
- 在 Memos 中支持通过标签或搜索筛选行动项。
- 如后续确实需要，可先做“行动项聚合视图”，不急着做完整任务系统。

## 近期推荐迭代组合

### 组合 A：安全感优先

- 文章版本历史。
- 回收站。
- 单篇文章 Markdown 导出。

适合先提升稳定性和数据安全感。

### 组合 B：知识网络优先

- 双向链接。
- 反向链接面板。
- 相关文档推荐。

适合强化个人知识库体验。

### 组合 C：创作效率优先

- 文章模板库。
- AI 文档操作面板。
- 标签与摘要推荐优化。

适合提升日常写作效率。
