# 吟游诗人与防具分类实施记录

2026-10-25：用户授权范围已完成本地实现与验证，待用户体验验收；没有执行生产部署或真实设备间WebDAV。当前规则见[迷宫探索与战斗说明](../Agent迷宫探索与战斗说明.md)。保留此检查表，验收后仍须用户明确同意才能删除。

## 已确认范围与落实

- 第五个一转吟游诗人10级；二转乐师／咒歌者30级；三转战歌指挥／镇魂歌者与琴圣／魔音术士50级。
- 乐师两条三转为辅助；咒歌者两条为输出。琴圣通过攻击命中随机给单名队友小增益，无其他存活队友时给自身，保持输出定位。
- 完整23项技能：一转音刃、鼓舞小调、乐感、乐器精通与皮甲精通；乐师奋进乐章、宁静乐章、演奏精通；咒歌者蚀心音波、破音、音律穿透；战歌指挥英雄战歌、指挥艺术、凯旋终章；镇魂歌者镇魂曲、安魂庇佑、封声乐句；琴圣回旋琴音、余音馈赠、华彩乐章；魔音术士共鸣音爆、不谐余震、毁灭终曲。精确等级、倍率和成本以运行CSV为准。
- 皮甲精通在10／20／30级升级：头、身体、手、脚四件皮甲齐穿，自己音律状态持续+1／2／3回合，不改直接伤害、冷却和层数。六项既有防具精通全部切为四部位对应甲类齐穿；武器和盾牌精通仍只检查对应单件。
- 头部五类各五档：10～30／30～50／50～70／70～90／90～99。旧`equip.head`稳定ID沿用布甲，改学徒／秘纹／月纹／星辉／苍穹法帽。另增20款皮帽、轻盔、战盔和面盔，按最终名称表，不保留高阶风巡／苍鹰皮冠或逐影轻冠。旧目录和旧装备冻结事实不回写。
- 用户明确确认节拍、共振、主旋律和余音全部进入现有战斗快照和WebDAV；无新数据库模型字段或迁移。
