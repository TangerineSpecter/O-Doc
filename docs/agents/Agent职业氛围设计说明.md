# 玩家职业氛围 · 第二版

## 目标与边界

采用已经确认的冰术师「像素意象 + 渐变辉光 + 缓慢运动」方向，改造其余 28 个职业。
人物、服装、装备武器保持独立；氛围表示职业气质，不表示技能正在释放或角色受到攻击。
主意象必须有运动，不能用固定大图标加几颗飘动光点来代替。光晕不模糊人物，脸与握点保持清楚。

所有效果共用脚底原点、4 单位像素纹理和最近邻采样。主体用阶梯轮廓，外围用低透明径向渐变。
亮度变化缓慢，不频闪；一转克制、二转增加意象、三转扩大光场与层次。
允许共享光学绘制工具，不允许把同一个技能换色作为不同职业的氛围。

## 共用实现与预览

- `Combat/art/professionAuras.ts`：稳定氛围 ID、名称、配色与阶数；职业 ID 的既有别名保持不变。
- `playerAppearance/auraDrawingPrimitives.ts`：径向辉光、细光弧、羽毛、叶片、符印、光点等光学与绘制工具。
- `warriorAuraDrawing.ts`、`arcaneAuraDrawing.ts`、`rangerAuraDrawing.ts`、`holyNatureAuraDrawing.ts`：各系独有造型与时序。
- `cryomancerSnowDrawing.ts`、`cryomancerAtmosphereDrawing.ts`：保留已确认的雪花和冰蓝冷雾。
- `professionAuraDrawing.ts` → `professionAuraMotifs.ts`：统一分发入口；生产 PixiJS、图鉴静态合成、动态总览共用。
- `ProfessionAuraRenderer.ts`：保持原逻辑尺寸，以双倍纹理密度绘制细轮廓，按场景时间播放与暂停。
- `playerStillArt.ts`：图鉴卡片缓存同源静态合成；动态总览可请求不含氛围的角色合成图，避免叠加旧背景。

总览入口：`frontend_react/profession-aura-preview.html`，按四系筛选、暂停、点击卡片进入独立分层预览。
总览 Canvas 使用真实共用绘制函数；离开视口的卡片停止重绘，卸载释放动画与观察器，不创建 29 个 WebGL 上下文。
单独查看：`player-layered-preview.html?job=job.warrior` 等已登记职业 ID，可换装、换武器或只看氛围。
正式图鉴列表保留静态缩略图，详情播放同源动态效果；静态列表不承诺播放动画。

本轮不新增持久数据或同步字段，不改变职业、装备、已学技能、伤害或状态。按用户要求不运行测试、类型检查、lint 或构建；用实际预览画面审视效果。
