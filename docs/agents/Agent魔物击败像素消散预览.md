- 背景现可切换六张地图的独立像素 PNG 与代码绘制的简洁舞台。地图切换不重置动画进度、更换怪物保留场景；没有替换正式出没地背景。地图资源与视觉确认状态见 `Agent像素战斗背景设计说明.md`。

## 素材复用方式

`Combat/animation/pixelDefeat/PixelDefeatEffect.ts` 在运行时裁去透明边缘，将同一原图采样为小纹理并拆成大小不同的像素矩形；碎片保留原图颜色和透明轮廓，共享一张纹理。不新增各魔物专用死亡 PNG，不修改现有形象文件。

`pixelDefeatMotion.ts` 负责确定性碎片布局和纯运动采样。脚底锚点保持 `(0, 0)`，调用方负责站位、大小和确认击败的时点。效果可用于 PNG，也可用于栅格化后的现有 SVG。

`previews/monsterDefeat/` 负责演示场景、页面、播放交互与示例素材选择。可复用消散模块独立于示例伤害和时间轴。
