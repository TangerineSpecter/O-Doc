# Agent 战斗探索一期实施与验收记录

日期：2026-10-10。生产内容包：combat-1.0.0，engine_schema=1；前端版本：1.1.8。

一期代码实现了准备、持续探索、观察、奖励/成长、返回结算、事件回顾和同步恢复。手动默认可用；自动探索是本机开关，默认关闭。生产数据库迁移和真实外部服务发布验收仍待执行，不能将下面的隔离验证解释为已经上线。

后端位于 `system_settings/agent_world/combat/`；纯规则不访问 ORM、时钟或模型。前端按组件、Hook、API、类型和展示逻辑拆分。世界居民属性面板提供冒险入口；每日动态提供探索聚合卡；设置的内置活动提供迷宫探索能力。活动能力启用和本机自动探索开关分别控制，后者不会同步到其他设备。

世界顶部查阅入口统一为「世界图鉴」，沿用原物品图鉴的 BookOpenText SVG。一级分类为物品/食谱/冒险，物品与食谱复用原卡片、详情、筛选及编辑操作；冒险分类为地牢与怪物、怪物图鉴、材料图鉴、装备图鉴、职业与技能，采用带数量的胶囊 Tab，不含「全部」，窄屏横向滑动。切换保留筛选、选中项和滚动位置；食谱隐藏时停止轮询。冒险面板保留档案/探索历史与操作，图鉴从该面板移到统一入口；烹饪事件跳转到世界图鉴的食谱分类。没有改变业务数据或同步协议。

准备和返回后的转职使用居民当前模型，分别记录 exploration_prepare/combat_promotion 用途。准备计划先持久化再进行真实采购；失败保留已成交库存及账本。战斗轮次不调用模型。达到多个转职门槛时依次选择直接分支，不跳级、不补算历史职业成长。

## 执行与经济边界

- 30/60/120 分钟预计探索体力为 22/34/58；入场 10、每个实际开始的 5 分钟块 2。到达终点不追加攻击或新块费用。准备时补给市场另扣 5，同一会话多笔采购不重复扣入场。失败不撤销成功消费。
- 每次药剂托管最多 20 瓶，单次采购最多 20 瓶；装备掉落等级从区域下限到怪物等级/区域上限抽样，再限制到模板范围。消耗逐轮记录，唯一终态返还剩余库存。装备属性、词条和回收价在实例生成时固定；绑定、穿戴或收藏装备不能出售。
- 有效时间每 300 秒产生一次物品机会、每 1800 秒产生一次装备机会，未消费分别最多保留 2/1。跨日、召回或重新出发不重置累计。普通怪装备概率 20%，Boss 优先使用已有装备机会；装备与材料共用物品机会。击杀不直接增加余额。
- 一次全新 30 分钟探索在终点才首次形成装备额度；终点不执行攻击，因此该次通常没有装备。额度保留，下一场的合格击杀可以使用，不能为展示掉落在终点额外补攻击。
- 普通/精英等级按角色等级加 -2～2 后限制到关联区间；低等级居民仍可能遇到区间下限更高的怪。每场至多一个 Boss；普通/精英击杀达到 12 后，下一遭遇概率从 1% 累加，上限 25%。
- 大于 30 秒的严重推进延迟暂停，不补离线历史轮次。进程正常退出及检测到旧推进进程消失时撤销许可。窗口关闭、网页隐藏或断线都不改变后端执行。
- 暂停/恢复不计有效时长。接续重新检查日程、居民占用、剩余体力和上海日额度；每次探索固定独立 origin，本机身份必须同时匹配账号、探索 ID 和 origin。外部设备没有该本机运行身份，只显示历史；同名请求键不能取得控制权。暂停居民或关闭自动开关只阻止新自动出发。
- 当前 `USE_TZ=False` 保持不变，持久化使用上海转换，接口返回带时区 ISO 时间。跨午夜的每轮有效时间分别计入两天；前端倒计时不参与结算。
- 永久保留热战报，观察按游标分页读取；归档压缩和删除尚未开放。长期多居民运行的同步体积和分页延迟属于后续发布容量验证。

炼金、组队、强化、耐久、玩家间装备交易、视觉换装仍不开放。材料的未来配方用途不产生当前业务数据。

## 接口与同步契约

统一前缀 `/api/settings/agent-world/combat/`，认证、camelCase 响应及错误沿用项目协议。

| 路径 | 用途 |
| --- | --- |
| GET catalog/ | 全部图鉴目录、版本及怪物基础属性预览 |
| GET/POST config/ | 同步每日时长上限、本机自动开关；请求回执分别保存 |
| GET agents/{id}/ | 冒险档案、装备、技能、补给及个人图鉴标记；读取不创建档案 |
| POST agents/{id}/ | operation=prepare/initialize/equip/preview_equip/favorite/trade/close_market/promote |
| GET agents/{id}/history/?page= | 探索历史分页 |
| GET explorations/{id}/?cursor= | 一致版本快照、时间、状态、成果及最多 100 条已确认事件 |
| POST explorations/{id}/ | operation=recall/resume；需本机运行身份 |
| GET explorations/{id}/encounters/?page= | 遭遇、击杀及奖励分页 |

所有命令要求 1～40 位幂等 key。客户端不提供经验、伤害、价格或掉落结果。装备预览只读；正式换装和交易由后端校验。市场工具增加 buy_combat_potion、sell_combat_material、sell_combat_equipment，可从 get_market_context 的 combat_supplies 查看补给和可售装备；沿用 5 分钟/20 调用会话限制及资金预算。

同步业务：CombatCatalog/CombatConfig/CombatProfile/EquipmentInstance/Exploration/CombatEncounter/CombatFact/CombatIntegrity、AgentTask.exploration_config，以及复用的库存、市场、体力、账本、日程和执行记录。CombatRuntime 中的授权、自动开关、准备/推进租约、进程 ID、临时转职许可及界面状态仅本机。

combat_schema_version=1/combat_actors 标记完整居民域。恢复前校验目录指纹和业务引用、事实链、初始/转职绑定装备、成长回放、库存/装备来源、成功消费、遭遇序号、唯一终态和固定摘要回顾关联，以及聚合指纹；冲突或缺来源拒绝。恢复后关闭许可、暂停在途、清理租约，并从实际数据库重新构建快照与修订。历史目录和实例不因内容包升级而重估。

## 固定种子平衡评估

[完整结果](./Agent战斗引擎平衡评估.json)由生产纯引擎生成，替代旧设计数值子模型。151 组，每组 1000 固定种子，共 151,000 场。

145 组日常场景为 29 职业 × 5 风格，按职业阶段使用 Lv.5/20/50/85，在推荐区域探索 30 分钟，关闭 Boss；配置同级六件蓝装、14 治疗 + 6 回蓝药剂。最低完成率 **95.2%**，满足 90% 目标。最大组平均击杀 20.597；各组平均净收益范围 -403.63～30.61，完整结果分别列出经验、升级数、击杀、耗药、采购成本、回收价值、装备数量与时长。此矩阵不是所有等级/装备组合的保证，尤其不代表 1 级裸新手或越级区域。

Boss 核心场景使用战士路径、推荐 Boss 区间中值等级、均衡风格和相同补给规则，单场胜率：

| 地牢 | 胜率 |
| --- | ---: |
| 苔石洞窟 | 62.7% |
| 废弃矿坑 | 57.7% |
| 迷雾林地 | 40.7% |
| 沉没遗迹 | 53.6% |
| 灰烬堡垒 | 60.6% |
| 星蚀裂隙 | 57.4% |

六个核心 Boss 场景均满足 40%～70%。这不是全部职业对全部 Boss 的组合验证。普通/精英攻击系数经评估调整至 .16/.24，Boss 保持风险系数，并在 monsters.csv 保存六个 Boss 的独立校准系数；生产清单哈希已经更新，设计 CSV 不覆盖生产。

采购指标按实际消耗药剂计算；返还的未用药剂不记为永久成本，初始蓝装成本不纳入。回收价值只是当场成果的 NPC 出售价值，探索不会直接发现金。额度边界、跨探索保存和低级怪耗尽后零掉落另外由规则/事务测试验证。
