# Agent 角色设定与决策路由

## 编辑与整理

姓名使用已有名称；年龄允许“原作未明确”，MBTI可不设定。五个文本模块各自描述身份、判断倾向、生活偏好、表达与相处、外貌。外貌不含固定画风，具体性格优先于类型标签。

“补充提示词”可为空；非空时所有场景固定加载。旧角色可直接继续使用，也可点击“整理角色设定”，预览字段、冲突说明及剩余补充文本，编辑后确认应用并保存。重复姓名移除，无法归类或有冲突的原文保留；应用可撤销。编辑或关闭期间返回的旧请求不会覆盖新表单。从零生成保留为次要入口，生成后同样预览确认。

## 场景与模型

角色字段投影之外，各任务的动态信息、记忆/技能和工具范围按[场景输入与工具治理方案](./Agent场景输入与工具治理方案.md)逐阶段整理。角色拆分及模型路由已接入，不代表全部业务上下文和MCP注册已完成治理。

角色按场景投影，不每次压缩或自动推断新偏好。生活、市场、社交、旅行的有限选择可优先JEV；预算、队列、检索词和正文继续普通模型。世界设置统一开关，并支持勾选排除场景。市场任务不再单独配置JEV。

普通决策依次尝试任务模型（世界自主决策使用世界模型）、Agent模型、系统默认对话模型；正文只尝试任务、Agent和系统模型。实际模型与失败记录以请求用量和执行阶段为准，任务开头的配置名称不是每次请求模型的保证。

JEV结果不包含自然语言人物理由。系统选择说明只用于追踪，真实反应另由表达模型生成。旅行选择先保存检查点；模型故障只继续当前步骤，已提交的交易与工具事实不会重放。取消、授权失效或时限耗尽会停止，不能靠降级复活任务。

## 升级与验证

升级1.2.12后执行0072和0073迁移；不自动批量整理已有角色。角色字段和世界策略同步，密钥仍保存在本机。旧市场开启的账号会启用所有首批JEV场景，效果不合适时可在世界设置排除。

验证包含旧角色兼容、字段独立使用、整理取消与撤销、社交正文不可更换已选行为、旅行检查点恢复、模型去重和降级、市场部分成交后继续执行及同步往返。真实Token节省需使用配置好供应商的同场景对照，本机未配置模型时不能据模拟测试宣称节省。
