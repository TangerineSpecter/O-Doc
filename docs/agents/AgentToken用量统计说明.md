# Agent Token 用量统计

入口为 **Agent 世界顶部「用量统计」**；任务执行详情增加 **本次 Token 用量**。

## 统计范围

统计自定义和内置任务、后续执行、日程规划、Agent 世界社交决策、飞书及站内 Agent 对话、记忆整理，以及发帖预览。发帖预览单列为其他调用。旅行、自主发帖的格式修复、工具循环和显式重试按每次真实模型请求记录。任务步骤中的嵌套调用继承执行归属。非 Agent 普通 AI 对话、创建角色配置、独立学习文集老师（没有 Agent 身份）及生图不纳入。

统计按北京时间的请求开始时间归属，跨午夜任务逐请求分到不同日期。输入／输出／总 token 以提供商返回的 `usage` 为依据；总量缺失而输入输出完整时相加。缓存、思考 token 仅作细分，不重复计入总量。接口无用量、超时、断流、中断均保留请求事实并提示不完整；失败任务中已经确认的消耗仍计入。SDK 隐式重试改为相同条件和次数的显式请求记录。流式用量只在同一请求内更新，重复事件不重复计数。

## 查看方式

- 今天、近 7 天、近 30 天、自定义日期或全部历史；按 Agent 和任务筛选。
- 总量卡片显示已知输入、输出、总 token、模型请求次数和不完整请求次数。
- 每日趋势；按 Agent、按任务及其他调用排名。任务显示有采集请求的执行次数和平均已知消耗；未知用量不能理解为零。
- 点击排名查看执行记录，展开查看整次执行的各 Agent 用量；进一步查看每次模型请求及可用细分。筛选后的执行行显示筛选范围消耗，展开的「本次 Token 用量」展示该执行全部已采集请求。
- 执行详情展示自身用量及各 Agent 汇总；存在后续执行时另显示整条执行链合计。每日总量只累计请求事实一次。
- 旧执行没有采集数据显示「未采集」；删除任务或居民后历史身份和用量仍保留。
- 「刷新明细」从第一页重新获取最新请求及状态；分页加载失败后「重试」保留当前位置。

## 接口与实现边界

认证只读接口位于 `/api/settings/agent-world/token-usage/`：`summary/` 返回总量、每日趋势和筛选选项；`breakdown/` 支持 Agent、任务、用途和执行维度分页；`requests/` 按时间与 ID 游标分页，每页 50 条。日期参数为 `start_date`／`end_date`，`all=1` 查询全部历史；支持 `agent_id`、`task_id`、`record_id`、`purpose` 以及 `other=1`。日期和分页错误返回 HTTP 400。响应沿用现有 `code/msg/data` 与驼峰转换。

持久化、用量归一化、归属上下文、查询和 HTTP 各自拆分；通用模型方法保持原返回内容契约。请求时间、Agent、任务、执行记录均建立索引。执行记录列表用两次聚合批量计算自身及各 Agent 用量，避免逐条查询。拥有独立账号归属的世界调用沿用账号范围；共享 Agent 配置的调用继续共享，IM 统计不返回内容或发送者。

WebDAV 同步与升级说明见[数据同步逻辑说明](../数据同步逻辑说明.md)。第一版只统计 token，不折算费用、不限制模型消耗。
