## 形象、动作与技能

- 20 只均提供 `idle / move / attack / hit / defeat`。按四足、岩像、持械、树人、菌类、水灵、施法者、炎魔、龙形分类，通过连续逆向像素形变控制腿、臂、尾、菌盖、袍摆与翼膜，避免只把整张图片平移或剪开关节。
- 普通与精英使用 128×128、64 色索引像素；首领保留 256×256、96 色细节，默认 1.2 倍体型，悬浮施法首领 1.08 倍以保留顶部空间。裂隙所有角色另乘 0.84 舞台比例，脚底位于 124/180，匹配悬浮平台上表面。
- 受击直接复用 `sprout-meadow/motion.js`；倒下直接复用 `sprout-meadow/pixel-shatter.js` 的 0.26 秒震裂、原色炸裂、弹跳及碎片终态。这里只适配原色、朝向、悬浮高度、体型和平台落点。
- 角色原图来自 `frontend_react/src/assets/combat/monster-<ID短名连字符形式>-v1.png`；背景为同目录 `battle-{abandoned-mine,mist-forest,sunken-ruins,ember-fortress,star-rift}-pixel-v2.png`。原 PNG 和正式动画注册表均未覆盖。
- 等级、名称和技能归属读取当前生产内容目录 `system_settings/agent_world/combat/data/{monsters,monster_actions,skills}.csv` 生成只读快照。首版特效按 `skill.monster.*` 稳定键映射。迷雾狼按用户反馈在预览内将重击改为候选 `mist_pounce`（雾隐扑袭），迷雾树王另以候选 `root_prison / royal_dew`（盘根囚笼 / 灵果甘霖）替换毒孢 / 再生，沉没遗迹四只另改为五个专属候选技能，灰烬堡垒前三只另改为三个火属性候选，深矿巨像两招另改为矿晶共振和洞顶崩塌，因此当前 25 个角色技能组合含二十二种表现；生产目录仍为各自原技能，候选尚未进入内容包和结算。
- 沉没遗迹四只重做：遗迹骷髅（暗）以原残刃挥出冥火骨刃；幽水灵（水）聚水旋尾、推出涡流弹并溅出水花；遗迹骑士（暗）以原贝纹盾迎击后挥出亡誓反斩；潮汐祭司（水）抬三叉杖、展开逆潮结界，或下令卷浪形成唤潮裁决。五招均是候选名称 / 动作 / 特效，原目录技能不变，触发、数值和附加规则待确认。两只水系的普通攻击也使用水滴、水花和涟漪。原图遮挡的腿部和衣袍在武器分层后局部补齐，共用受击 / 粉碎不变。
- 迷雾树王第三版：盘根囚笼取消直立木架、尖顶和横向藤栏，采用三条弯曲活根错位生长、卷合，根尖持续收细并带少量嫩芽。第二招按用户要求恢复治疗方向，改为候选「灵果甘霖」：树冠紫果凝露、甘露向胸前树心汇入、心纹舒展并出现恢复微光。区别于古树守卫的根系吸收与树干上行再生，不再使用迷雾隐身或命中干扰。回复量、控制时长等正式数值待确认，预览不改 HP 和战斗结算。

- 特效按既有语义区分物理打击、破甲、闪避、减伤护体、灵盾、再生、毒孢、炎灼、灵击和星蚀咒。虚线靶标为演示目标；演示不区分真实命中/未命中，也不驱动实际 HP、状态、持续回合或伤害。正式接入及真实事件验收需在用户确认后另行进行。

## 源码职责

- `build-previews.py`：生成五个 HTML、区域只读配置和索引精灵。运行 `.venv/bin/python docs/agents/demo/region-monsters/build-previews.py`，只写本预览目录及五个 HTML。
- 五个 `<region>.js`：当前区域的名称、等级、技能、形象参数与精灵数据。
- `toxic-mushroom.js`：原图毒液提取、凝滴 / 下坠 / 溅开时间采样及毒蘑菇专属毒孢动作和特效。
- `characters.js`：同源缩略图 / 大图、连续局部像素形变及材质检查视图。
- `ruins-motion.js` / `ruins-actors.js`：沉没遗迹候选动作采样、原图残刃 / 剑盾 / 权杖与手部分层，及水体局部形变。
- `ruins-dark-effects.js` / `ruins-water-effects.js`：暗刃与格挡反击，水团 / 流幕 / 卷浪及水系普攻；`ruins-pixels.js` 只提供这些效果共用的像素绘制函数。
- `mist-treant-skills.js`：树王候选双技能的专属姿态、根笼构形、树皮和荆刺、雾域分层及局部震屏；角色透明度按整图合成避免扫描条纹。
- `ancient-guard-regen.js`：古树守卫再生的扎根 / 舒展姿态、树皮生命光带、树心脉动、新叶及前后叶流。
- `mist-wolf-pounce.js`：迷雾狼候选雾隐扑袭的四足分层、跳跃轨迹、咬合与薄雾 / 爪痕特效。
- `mine-giant-skills.js`：深矿巨像双臂分层和两种候选姿态；`mine-giant-boss-effects.js`：晶能共振、岩层崩塌、矿岩细节、尘浪及震屏。
- `iron-guard-break.js`：铁甲矿卫专属破甲击的持械分层、动作采样、命中特效和震屏；只在对应角色和技能使用。
- `motion.js`：时间采样与动作姿态；`skills.js`：独立技能特效与语义说明。
- `scene.js`：背景、角色和技能的前后层级；`effects.js`：共用粉碎和普通攻击接触效果的尺寸 / 地面适配。
- `studio.js` / `studio.css`：页面、播放控制、可见性暂停、快捷键、音效和响应式布局。页面隐藏时停止 RAF；返回恢复；离开时清理 RAF 和音频实例。

页面无业务 API 请求，无账号、数据库或 localStorage 写入；没有新增持久字段，因此无需 WebDAV 同步。全部内容仍属于待确认的前端视觉资产。
