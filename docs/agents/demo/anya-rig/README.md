## 第三版调整

参考图仅保留粉发、绿眼、发饰等身份特征。重新生成侧向三分之四视角的短袖、短裤角色，去掉长袖、裙摆、背包和披风对关节的遮挡。先绘制完整姿态参考，再建立骨架。

前两版使用独立图片拼接肢体，出现袖口截面、关节断裂和姿态异常。第三版采用生成的头、躯干、鞋素材，加上由关节驱动的连续手臂、腿部轮廓。不是把原图硬切成几块旋转，也不是完整的 Spine 工程或网格蒙皮系统。

- **待机**：双脚支撑，轻微呼吸，低位持剑。
- **移动**：支撑脚后移，摆动脚屈膝前摆；脚跟接触、脚掌支撑、脚尖离地。骨盆在支撑阶段上升，避免持续蹲走。原地步行的地面刻线与支撑脚后移同速。
- **攻击**：屈肘预备、重心前移、向前突刺、收势。放弃本轮中间试验的举剑斜劈，因为大头比例下其过渡姿态不合适。握拳覆盖剑柄，两者共享握点。
- **施法**：持剑手低垂，另一手屈肘抬起、掌心向上，聚能后释放。
- **受击**：骨盆后移下沉、屈膝缓冲、躯干后仰，然后恢复站姿。

## 文件职责

| 文件 | 职责 |
| --- | --- |
| `reference.png` | 用户原始参考，原样保留 |

| `renderer.js` | 坐标变换、前后层级、素材挂接、骨架和特效 |
| `studio.js`、`studio.css` | 页面播放、时间轴、镜像、倍速、原图对照、关键姿态检查 |
| `check-rig.cjs` | 几何约束检查，不代表视觉质量验收 |

`v2-source/`、旧素材板和旧截图保留为迭代记录，当前页面不加载。短袖、手和腿采用程序绘制的连续轮廓，不能把这次验证描述成“只换任意生成素材就能直接复用”。

## 检查记录与边界

Chrome 中检查了待机、行走支撑/摆腿、突刺预备/伸臂/收势、施法和最大受击姿态，并保存 `walk-v3-check.png`、`attack-v3-check.png`、`cast-v3-check.png`、`hit-v3-check.png`。走路持续下蹲、攻击交叉腿以及举剑过渡绕头的问题在检查后重新调整。截图是抽样视觉检查证据，不表示所有帧都已人工逐帧审查。

```sh
node docs/agents/demo/anya-rig/check-rig.cjs
```

采样 1,005 个姿态、8,040 条骨段，检查骨长、腿部目标可达、脚底不穿地、支撑脚接触面及循环首尾连续。几何检查与浏览器视觉检查分开记录。

仍是单角色、单朝向的动作原型：脸部表情固定，头发未单独摆动，服装没有布料模拟；施法手型离散切换；切换动作立即回到该动作起点，尚无动作间融合。未实现自动拆图、任意形象导入、装备换装或正式战斗结算。

无后端接口和新增持久字段，不进入 WebDAV 同步。
