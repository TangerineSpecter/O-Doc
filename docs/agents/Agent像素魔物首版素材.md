## 视觉规范

硬边方块像素、深褐描边、左上高光，配色和材质语言沿用冒险者、装备。普通怪的外轮廓简洁；精英强调装甲、兵器或明显的身体结构；Boss 使用更有体量的剪影、王冠或其他主标志。不同怪物不只替换颜色。PNG 仅含角色，背景、舞台阴影和后续技能不烘焙进图片。显示使用最近邻采样。
