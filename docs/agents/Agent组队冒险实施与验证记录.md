## 数值模拟

脚本：`scripts/combat_design/evaluate_parties.py`，纯Python，不依赖Django、数据库、模型或网络。固定等级蓝装，分别模拟55/75/90级、1～4人及有无神官/盾卫，每组20个稳定种子、每趟30分钟。使用实际共享行动、怪物生成、经验和掉落规则；不模拟升级、体力不足、补购、美食或炼金，结果不能外推为所有真实居民的收益保证。

数据见[模拟结果](./assets/combat/party-simulation-2026-10-24.json)。结果体现合理配队的收益优势和纯输出队风险；没有因此调整用户确认的人数倍率与回合间隔。`fallen_fraction` 为曾倒地的成员占比（同一人只计一次），`unrescued_fraction` 为最终未救起而返回的成员占比，药耗包含这些成员；具体均值以JSON为准。
