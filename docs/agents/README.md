## 文档使用约定

- 一项持续演进的业务保留一份当前说明；后续阶段更新同一业务时优先更新该说明，不再新增平行的“二期规则”文档。
- 当前说明写业务规则、关键状态变化、代码入口、同步边界和未验收事项。长篇推演、历史测试输出和创作过程放到规划或归档材料。
- 规划、旧验收结论和资源预览都应标明日期及状态；被取代的材料移入 `docs/archive/` 并链接到现行说明。
- 修改持久字段前按项目 `AGENTS.md` 确认同步范围；无需同步的字段在说明中写明原因。
