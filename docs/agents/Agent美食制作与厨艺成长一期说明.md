# Agent 美食制作与厨艺成长一期

> 本文保留一期规则及当时验收记录。当前厨艺 Lv.99、成品星级、材料策略与同步版本 2 见[二期说明](./Agent美食星级与厨艺成长二期说明.md)。

## 使用与规则

Agent 世界新增「食谱图鉴」，任务设置新增「美食制作」内置行为，接入统一生活日程。任务默认关闭；保存参与居民及启用配置后，可明确选择居民手动执行，自动运行仍受本机世界开关控制。图鉴只查看、编辑和配图，实际制作由模型从服务端合法候选中决定，也可休息。

默认 20 道食谱全部可预览，名称、稳定身份和一份产量固定；不支持新增和删除。编辑模态支持材料、要求等级、回收价、经验及体力。材料限现有作物与普通鸡蛋、普通牛奶，不自动替代金色畜产品。数量、经验和体力为正整数，等级 1–10，体力不超过世界上限 100。基础调味料和水不占库存，小麦、水稻、大豆和向日葵的基础处理包含在制作中。

厨艺从 Lv.1、0 经验开始，到达等级 L 的累计经验为 `100 × (L−1)²`，上限 Lv.10（8100 经验），满级继续保留经验。默认每份经验为要求等级×10，体力为 `2 + floor((要求等级−1)/3)`；两项保存到配置，居民升级不降低同一食谱经验。

图鉴支持居民、菜名搜索和全部／可制作／材料不足／等级不足／体力不足筛选。等级锁定优先；详情展示材料与持有量、当前配置回收价、经验、体力和当前居民制作次数。加工差额使用当前农场配置价格估算，实际扣料价值保存在制作事实中。居民属性显示厨艺与经验进度，背包和物品图鉴增加「美食」，每日活动投影制作及升级。

## 制作与交易

一次活动即时制作合计最多 6 份。候选只读取本人背包、厨艺和体力，不使用其他居民或市场托管库存；当次活动的候选固定，新解锁菜在下一次活动出现。模型只能选择食谱、份数与理由，不能写入价格、经验或产量。

每份在同一世界业务锁与独立事务内检查任务、归属、执行租约、旅行状态、等级、材料与体力，先进先出跨库存记录扣料，原子提交成品、经验、制作事实和体力。相同操作键返回原结果；中途不足停止剩余份数，已成功份数保留。中断收束执行记录，不重放制作。

成品稳定 SKU 为 `dish.<recipeId>`，复用共用背包和现有价格批次。规则编辑不改变已确认执行快照或旧成品批次价格；商店出售按原批次回收。居民挂牌、购买和撤回沿用托管库存、成交账本和幂等流程。生活规划获得厨艺、可制作菜、材料缺口与加工收益，材料准备沿用农场／市场；商店未增加食材供应。

## 图片与接口

默认无配图，统一厨师帽占位；不生成图片。复用纪念品图片上传、图标库选择、保存关联与清除。关联按账号及成品稳定 SKU 保存，图鉴、背包和市场共享；售空仍保留关联，清除恢复占位。引用纳入资源计数、归属验证与删除保护，认证图片加载及资源同步沿用现有实现。

- `GET /api/settings/agent-world/cooking/recipes/`：传 `agentId` 或 `agent_id` 获取对应居民材料、厨艺、制作状态和材料选项。
- `PATCH /api/settings/agent-world/cooking/recipes/<recipe_id>/`：提交完整 `ingredients/required_level/sale_price/experience/energy_cost`，支持现有驼峰转换。
- `GET /api/settings/agent-world/cooking/agents/<agent_id>/`：厨艺累计经验与升级进度。
- `GET /api/settings/agent-world/cooking/agents/<agent_id>/history/?page=1`：每页 20 条制作事实。
- 图片沿用物品图鉴 SKU 关联接口，扩展支持 `dish.`；没有直接制作 HTTP 接口。

## 持久化与升级

新增 `CookingCatalog`、`CookingSkill`、`CookingOperation`、`CookingIntegrity`，任务增加 `cooking_config` 和 `task_kind=cooking`。目录账号级、成长使用稳定居民 ID，改名不重置，删居民保留历史。旧快照没有整个烹饪域时派生默认目录和 Lv.1，GET 不写库；首次保存规则、图片关联或成功制作才持久化相应数据。

全部业务数据已确认纳入 WebDAV：目录／图片引用、厨艺、不可变制作记录、完整性检查点，以及既有背包批次、成交与体力事实。新元数据 `cooking_schema_version=1`、`cooking_owners` 防止整个烹饪域被删后误当旧快照。导出和恢复使用同一世界锁与事务，恢复校验目录／库存／市场指纹、经验成长链及每份体力事实，残缺新版快照拒绝恢复且事务回滚；重复恢复不重复制作。

执行租约、线程、凭证、本机自动运行开关、界面筛选和请求生命周期不同步。恢复后沿用本机自动关闭规则。所有同步设备应升级代码并执行 `system_settings.0054_cookingcatalog_cookingintegrity_cookingoperation_and_more` 迁移后再交换新版快照。此次仅在隔离测试库迁移，未迁移用户正式数据库。
