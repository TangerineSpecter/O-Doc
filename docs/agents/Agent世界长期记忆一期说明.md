# Agent 世界长期记忆一期

更新时间：2026-10-10。状态：代码已接入；生产迁移、真实模型三天观察与远程双设备接续单独验收。

## 入口和范围

系统设置 → Agent → 长期记忆，复用已有列表与表单，新增来源筛选、自动有效/归档容量、受保护数量、整理状态、真实来源展开与固定功能。新增人工记忆默认角色共享，也可明确指定飞书用户或会话；已有范围不自动扩大。用户编辑自动记忆后转为受保护内容，人工归档不会被自动恢复。

读取农牧操作、料理实际产出、市场成交、投资实际成交、已完成旅行、可见文集中的本人作品/互动、本人社交行动与关系事件。按原始业务来源采集，不重复加载执行日志，也不把规划、他人的经历或未发生的结果当作自身事实。普通重复活动按活动/对象聚合。

## 整理与保留

迁移为已有参与居民记录启用时间；之后由后台为新加入生活的居民创建处理状态。不扫描启用前活动，不提供自动历史补录。

每天上海时间03:00后，现有记忆调度器处理上一日或最早一个积压日期。须本机世界运行开启、仍在参与列表、归属匹配且居民未暂停。每居民每日最多一次整理请求，使用居民默认模型，不做自动格式/网络重试；无值得保存的新事实不调用模型。失败不推进处理日期，次日再尝试。崩溃后同日不重复请求。

外部模型调用在事务外。提交时再次核对运行授权、居民角色/模型、租约、记忆版本及源事实指纹，任一变化则丢弃结果；记忆与进度同一事务保存。

模型最多提议五条事实或偏好，只能引用本轮提供的来源。普通重复活动不单独形成长期事实；偏好至少有三个不同日期的实际证据。为积累偏好，处理状态最多保留100个活动主题、每主题三个日期的代表事实，不保存无限增长的暗中历史。

整理输入中的历史记忆来源仅提供来源ID和日期，完整证据仍保存在数据库。输入超限时先减少召回的历史摘要，再减少本轮代表来源；无法容纳任何本轮来源时记为失败，不推进处理日期。

同主题更新已有身份；摘要最多300字符，保留最多八个代表来源与累计证据数量。重要性不因召回次数增长。不会改写角色提示词、生活配置、目标或关系分数。

| 规则 | 默认值 |
| --- | --- |
| 自动有效记忆 | 最多100条，标题和正文合计10,000字符 |
| 自动归档记忆 | 最多100条、10,000字符，最长90天 |
| 普通记忆无新证据 | 180天后归档；里程碑不单因时间归档，仍受容量限制 |
| 单次整理 | 完整输入估算8,000 token内；输出上限2,000 token |
| 单次召回 | 最多六条，完整记忆片段估算800 token内 |

容量排序依次为重要程度、最近证据时间、稳定ID。超限或过期自动摘要以永久删除墓碑清除，业务事实保留。人工、飞书晋升、旧旅行、人工编辑和固定记忆不自动删除，另计受保护容量。自动固定后只撤销固定即可重新参与管理；通过完整编辑表单保存则属于人工维护。

已有旅行长文不重写；已接入处理状态的居民新旅行不再直接生成长文记忆，完成行程进入每日事实采集。新旅行在既有同步快照内记录不可变的 `memory_completed_at`，后续配图更新不会移动记忆的发生日期。

## 召回与模型用量

统一召回覆盖生活规划、朋友圈/回复、文章评论、发帖、普通任务、旅行、农牧、料理、市场、投资及飞书对话。按行动意图、讨论或互动对象检索；同一生活执行使用请求内缓存，工具循环复用已装载上下文。保留当天事实和讨论，社交背景压缩为八条近期执行、五条历史社交摘录。

SQL是事实源，向量只返回候选ID；再次核对居民、范围、有效状态、正文修订及Embedding模型签名。向量故障降级关键词检索，不阻止业务；固定记忆优先。向量在既有后台逐批补齐，每轮最多五条；首次索引未齐期间关键词路径仍可用。更换Embedding模型使用新的余弦索引并清除旧本机派生集合。

飞书用户/会话专属内容不进入世界活动上下文。旧旅行和人工长文也受召回总预算限制。token估算沿用项目的中文字符与非中文长度方法，并非供应商实际计数。每日整理归入「记忆」用量，召回文本归入实际业务请求输入；Embedding复用配置，不调用额外文本模型。

## 接口、同步与上线

保留 `/api/settings/agents/<id>/memories/` 和明细接口，增加 `is_pinned`；来源等元数据只读。新增 `GET /api/settings/agents/<id>/memory-status/`，返回自动有效/归档条数和字符容量、受保护数量、启用时间、已处理日期与最近整理状态。

用户已确认纳入WebDAV：`AgentLongTermMemory.is_pinned`、记忆元数据与来源、`AgentMemoryState`的启用时间、处理日期、每日尝试记录、有限观察事实和结果。自动记忆与处理状态作为每居民一致聚合选择胜出来源；人工修改按既有逐记录规则合并。合并前验证双方快照，恢复前验证结果，不拼接不同处理进度的自动记忆。

两端整理状态完全相同时，保留逐记录合并胜出的记忆和修订，固定/取消固定及删除不被单端语料覆盖；整理状态不同时仍选择胜出状态对应的完整自动语料。

恢复校验来源表、居民与账号、日期、事实内容、三天偏好证据和容量结构。恢复关闭世界执行并清除记忆租约；恢复本身不会调用整理或模型。旧快照没有此域时兼容导入，不补写历史记忆。

**不同步**：`AgentMemoryLease`、向量、索引模型版本和请求内缓存，均为本机授权/派生状态。向量可从SQL重新构建。既有RAG/Chroma策略不变。

迁移为 `0061_agentmemorylease_agentmemorystate_and_more`。正式上线前备份，所有同步端升级并迁移，再交换含 `resident_memory_schema_version=1` 和 `resident_memory_aggregates` 的快照。此次开发未对正式数据库执行迁移或调用真实模型。
