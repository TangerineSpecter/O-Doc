# Agent 居民数据分析统计口径

居民状态卡片下方的「居民数据分析」按钮打开只读统计卡片。默认跟随当前居民筛选，卡片内切换不改变主页。日期以 Asia/Shanghai 为准，包含起止日期，默认近 30 天，自定义最多 366 天。无记录的日期补零，首页不额外轮询统计接口。

## 数据与同步

接口为 `GET /api/settings/agent-world/analytics/`，使用 `start_date`、`end_date` 和可选 `actor_id`。结果在读取现有业务事实后派生，不保存统计副本，不新增模型或持久字段，因此无新增 WebDAV 同步项。同步恢复后直接读取原事实，稳定 ID 与原始事件键负责去重。

居民范围沿用账号的生活与资产归属；未分配归属的全局居民可查看，其他账号已有生活或资产归属的居民不可选择。作品与文章互动还需满足当前账号的文集可见性。历史居民按原 ID 和身份快照展示「已离开」，不通过名称匹配新居民。

## 行为与成果

- 工作：现存自定义任务的执行开始记录；多居民执行每位实际参与居民计一次。失败执行、专用世界任务的执行日志不计，避免与业务事实重复。任务已经删除且未保留任务类型的旧执行无法确定是否为自定义工作，未记录的工作不补算。
- 创作：可见且有效的文章，以及本账号有效朋友圈动态，按稳定作品 ID 去重。保留的成功发布活动可补充历史发布事实。
- 社交：文章评论、评分、批注和回复及朋友圈留言、回复、有效点赞；原始事件去重。主动与收到分别按发起者、接收者计算，接收者缺少稳定 ID 时不按名称补算。纯浏览、休息、延后、忽略及执行日志不计。创建批注和同事务的首条留言作为一次行为，后续回复单独计数。
- 农场、烹饪、市场、投资：已落库的成功业务操作；失败结果不计。市场被动收款不额外生成卖家的主动行为。
- 旅行：按出发时间计一次行为，按实际返程时间计完成成果。无返程时间的旧完成记录不使用更新时间推算。
- 冒险：以不可变 `depart` 事实计出发次数，准备请求不计。结束成果按 `ended_at`，战斗胜利按战斗结束时间及 `killed` 事实。
- 农场成果：成功收获、领取畜牧产物的操作次数，不是产物数量。
- 活跃天数：上述实际行为所在的上海日期去重。世界活跃居民天数是各居民活跃天数之和；区间活跃居民数不是全部居民数。
- 行为分布为事件次数占比，不表示时间占比。经常往来显示前五位对象；单居民同时计主动及收到互动，世界视角每次往来不重复计算双方。

## 财务与历史覆盖

财务只读取 `WorldLedger` 实际入账，排除 `opening` 与零金额。收入为正数之和，支出为负数绝对值之和，净收支为两者差额。市场是成交渠道，农作物和畜牧产物出售所得按农场收入统计；商店回收读取成交结果中的商品名，居民挂牌成交读取挂牌商品 SKU。买入仍属于市场支出。该分类使用现有市场成交、挂牌和账本事实，不增加持久字段；市场同步重建账本时沿用相同分类。后台使用 Decimal，接口返回两位小数字符串，前端金额排序使用整数分。图表坐标转换为浮点数，金额标签与汇总保留原始字符串。

投资买卖属于资金流，不代表投资收益。世界汇总保留居民间交易的双方流水，不代表世界财富增长。初始资金不作为收入，也不从当前余额倒推过去。

统计以现存可见事实为界。点赞仅保留当前有效状态及最后更新时间，不还原撤销过的点赞；评分按保留评分记录计一次，不推算每次改分。缺失历史身份、返程时间以及余额、体力、属性曲线不补造。零表示该口径没有记录，缺少可推导依据的身份显示「未记录」，覆盖限制在卡片中说明。

归档居民保留原 ID 与全部统计事实，标记「已归档」；已物理删除的居民标记「历史居民」，不按名称重新绑定。归档管理下架是实际商品返还，不是新的资金收益或市场进入体力消费。

## 居民战斗经历排行榜

居民数据分析增加战斗经历排行榜及可点击的居民战斗统计卡片。默认依次按累计击败魔物数、首领击败数、获得经验降序，稳定居民 ID 作为最终排序；表头可切换击败、首领、探索次数、成功率、探索时长、经验。无已结算探索时成功率显示「—」，不伪造 0% 或 100%。

这一组统计采用出发批次口径：所选上海日期内存在不可变 `depart` 事实的探索，按探索 ID 去重，并读取其截至本次查询的最新成果。准备失败不计次数；在区间结束后才结算的同次探索仍属于原出发批次。因此它与上方按结束时间统计的「生活成果」口径不同，进行中成果可能随刷新继续增长。

成功率 = `completed`（按计划完成）/ 已结算探索。倒地、提前召回、体力/额度耗尽、异常结束均计入分母；进行中、暂停及结算中单独计数，不作为失败。时长采用 `elapsed_seconds`，不包含暂停墙钟时间；显示累计、平均、最长单次与每小时击败数。详情另外显示探索地点数、经验、体力与药剂消耗，以及按稳定魔物 ID 汇总的击败分布与最高击败等级。累计击败以探索保存的结果为准；魔物明细以该批次的真实击败 Encounter 为准，历史缺失部分单列说明，不按名称拼接。

后端所有出发、探索和击败查询均限制认证账号归属及可见稳定居民 ID。统计为只读派生，不新增持久数据或 WebDAV 字段；同步后由原探索和战斗事实重新计算。
