## 使用与触发

设置 → Agent → 任务中配置「A 股投资」：选择参与居民、固定间隔（默认60分钟）或周期随机、投资偏好，可选择既有 Tavily 搜索服务。启用任务和世界自动执行后自动触发，也支持手动执行。上海时间周一至周五任何时段可执行，节假日工作日使用最近已有交易日，周末跳过且不补跑。公平选择一位空闲、有模型且体力足够的居民，沿用任务记录和居民执行租约。世界页面顶部「股票投资」查看账户、分页持仓、成交与决策。

每次机会向模型提供现金及第一页持仓。可以观望、管理已有股票，或者搜索市场后查找行业和公司，再按需分析单股。最多分析3只不同股票、调用20次工具、执行5分钟；每次成交前重新检查任务绑定、执行授权及时间。第一笔成功成交扣5点体力，后续本次成交不再扣，查询、失败、持有不扣。体力事实主键与市场、农场一样限制在 64 字符内：短机会 ID 保持 `investment-energy:` 前缀，生活安排等 64 位哈希机会改为内容哈希，避免 PostgreSQL 写入超长。中断结束机会，保留已成交事实；不重跑模型或重做交易。

## BaoStock 范围

BaoStock 提供沪深股票基本目录、行业及成分、交易日历、未复权与前复权历史日线。过滤指数、B股、退市状态；不依赖模型记忆股票代码。不覆盖北交所股票，也没有完整热点概念板块目录，工具明确只提供行业分类，公司主题可按名称检索。没有固定股票池，不预下载全市场行情。

SDK 使用全局 TCP 连接，不适合多个业务线程直接共享。本实现每次请求启用独立子进程，12秒 socket 超时，普通查询30秒进程超时、分页目录60秒进程超时，均受本次机会剩余时限约束；网络查询在业务事务外进行，不修改系统代理设置。部署需能访问 `public-api.baostock.com:10030`；HTTP代理开关不能证明该TCP路径可用。

股票检索优先使用最近参考交易日的query_all_stock目录，失败再尝试基本目录；目录按上海自然日缓存，行业按需缓存；日线最多取约200根已完成数据。MACD(12,26,9)使用首样本起始EMA，柱值为2×(DIF−DEA)；RSI(14)使用Wilder平均，平价序列50；MA5/20/60及近5交易日涨跌幅。至少60根有效日线，分析截至冻结参考日且使用前复权；真实模拟成交单独读取未复权收盘价。缓存包含股票、截止日期、复权口径、指标参数和计算版本。缺少目标日期的日线不进入长期缓存；兼容清除旧版本已缓存的不完整日线，避免盘中旧数据阻挡晚上取得新收盘价。

## 新闻额度

只在寻找新方向时调用；持仓管理、加仓、卖出不主动搜索。查询固定为 `A股 最近一周 市场复盘 热点板块 政策 公司重大事件`，支持时最近7天，基础搜索、最多5条来源/日期/摘要/链接。同一账号上海自然日只能认领一次，所有居民共享；失败、手动执行、并发和缓存丢失均不能重搜。持久认领事实与本机新闻正文缓存分离；未配置服务或查询失败不阻止持仓管理。

## 成交、成本与估值

- 最少1股、数量正整数、费用0、不借贷或做空；不限制持仓只数和投资比例，实际现金约束在服务器执行。
- 每次机会冻结「最近已发布完整日线的交易日」。盘中排除尚未收盘的当天；收盘后通过上证指数未复权日线确认实际发布日期，当天数据可用则使用当天，尚未发布则使用上一已发布交易日。[BaoStock 官网平台介绍](https://www.baostock.com/mainContent?file=home.md)说明日线17:30入库、复权因子18:00入库，实际以接口返回日期为准。未发布结果仅缓存60秒，发布完整的日期缓存6小时；行情服务失败时拒绝执行，不将查询失败当作当天未发布。停牌、参考日缺有效日线或无法确认报价拒绝成交，不退回更早价格。
- 当天新买股数的解锁日期为下一真实交易日，跨周末与假期；已有可卖批次不因加仓重新锁定。同一次机会同一代码仅一个方向。
- 买入累加总成本；卖出按剩余总成本/剩余数量分摊加权平均成本，保留12位小数；全卖清空残余成本。Decimal处理金额，展示四舍五入。
- 成交键由机会ID和服务器工具序号生成。成交事实、权益批次、现金账本、余额、体力和完整性指纹共用短事务和世界资产文件锁；同键重试参数一致返回原结果，不重复扣款。
- 股票市值不算可用现金，卖出回款才到账。已实现盈亏单独累计，持仓浮盈只比较收盘估值与剩余成本。
- 持仓市值始终为最近已知未复权收盘价乘股数，浮盈为市值减剩余成本。盘中买入后出现新的收盘报价，可在同日产生浮盈或浮亏；收盘数据发布后按该报价新建仓，初始浮盈为0。T+1按实际执行日期计算。
- 维护循环按最近已发布交易日每轮最多更新一只持仓股票，启动、盘中及非交易日也可补上遗漏的收盘估值；失败最多4次，间隔1/5/15分钟，保留旧估值及日期。展示在估值缓存与成交参考收盘价之间选择日期较新的已知价格。浏览器列表只读本机数据；主动打开单股详情才按需获取指标，后端行情查询总期限120秒，前端详情超时150秒；查询超时保留持仓事实并提示指标不可用。
- 一期仅模拟价差收益，不处理分红、送转、配股，界面明确展示边界。

## 模块与接口

后端领域位于 `system_settings/agent_world/investment_*.py`：模型、行情/SDK进程、新闻、成交、工具、运行、估值、查询/API与同步分别独立。投资工具仅嵌入现有模型循环，不增加对外MCP。API沿用登录保护、账号隔离、响应协议与驼峰转换：`/api/settings/agent-world/investment/{accounts,overview,positions,trades,decisions,detail}/`，除账户目录外提供 `actor_id`，分页20条，详情提供 `code`。不开放用户买卖API。

前端 API、类型、Hook、组件分别位于 `api/investment.ts`、`types/api/investment.ts`、`hooks/useInvestment.ts`、`components/Investment/`；使用WorldDialog和通用Select，切居民中断旧请求，关闭/隐藏停止15秒轮询，详情错误不抹去持仓。

## 投资居民持仓标识

投资账户列表返回派生字段 `position_count`（前端 `positionCount`），表示当前持仓股票种数，不是股数。下拉列表显示「持仓 N 只」或「空仓」，有持仓的居民优先展示；旧版后端缺少该字段时显示「持仓待更新」。该字段从已同步的 `InvestmentAccount.positions` 实时计算，不持久化、不单独加入 WebDAV 同步数据，账户同步后自动重新计算。
