# 日记功能

核对日期：2026-11-03。本文描述本地代码中的日记功能；本地 PostgreSQL 已执行下述迁移，生产部署和真实双设备 WebDAV 验收尚未执行。

## 使用与入口

登录后从页面右侧的日记按钮进入 `/diary`，桌面与手机均可使用。桌面按钮位于 Agent 世界按钮下方。页面采用现代高质感杂志立体光影风格（Modern Editorial & High Dimensionality），以柔和空间环境光、纯白与象牙微渐变艺术卡片、立体建筑日历印模和双层微弥散阴影为主，彻底消除单调平铺的扁平感，无任何复古做旧宣纸或生硬伪洋文装饰。顶部生活刊头展示今日节气日期、典藏篇目/累计书写/记录天数三大微立体数据牌、触觉感今日心情速记与高质感黑曜石“写日记”快捷入口。支持“画报（现代错落流式画报排版）／长卷（按年月分章的时间流视图）／书房（左栏目录索引 + 右栏整页沉浸阅读）”三种浏览方式，支持标题、正文和标签关键词搜索，顶部提供“全部／按心情／按天气／按标签”四种半透明毛玻璃胶囊筛选维度。选择筛选维度后展开对应的 SVG 心情、天气或已有标签筛选项并显示数量，支持未标记记录。切换浏览方式会清空上一方式的筛选值，可继续叠加关键词和日历日期筛选。纯白现代立体月历卡圆点表示当天有日记（按心情着色），提供当月概览与累计字数统计，以及“往日重温”随机回顾微卡；再次点击日期取消筛选，翻月只改变日历。

“写日记”与“日记详情”使用纯白现代杂志工作台与沉浸阅读器：
- **沉浸式阅读**：顶部展开画报级整幅封面大片（Hero Cover），全模块排版统一采用极富人文书卷美感的文楷（LXGW WenKai / 楷体），提供日光／燕麦／夜读三种微质感阅读底色、黄金/宽幅版心切换、字号三档调节、段首空两格缩进开关与信纸横线开关；正文基于语义段落排印引擎呈现并完整保留段首缩进，支持多图跨页画廊检视，并支持通过顶部按钮、底部微立体导航卡或键盘左右方向键连贯翻阅上下篇。
- **沉浸式写作与编辑**：桌面中央为悬浮在柔光环境里的高级纯白书写画布，彻底消除浏览器原生聚焦框（无任何高亮选框），标题与正文统一采用文楷，正文采用高度自适应无缝流动画布（无内部滚动条，随打字自然向下延展），提供“一键排版”功能（自动梳理段首空两格、规范中西文空格与中文全角标点、压缩多余空行；URL 与行内代码保持原文）。服务端保存正文时保留首段空格，仍拒绝全空白正文。下方为生活印记与相册管理（心情、天气、含常用推荐的胶囊标签及支持设为主封面的多图相册）；手机改为单列滚动。支持 `Ctrl/⌘ + S` 快捷保存，保存时会合并尚在输入框中的有效标签，超出数量或长度限制时保留输入并提示。标题最多 150 字符，纯文本正文最多 50000 字符，保留换行。同一天可以记录多篇，按日记日期、创建时间倒序显示。关闭有修改的弹窗时先确认放弃，保存或上传失败保留已填内容。

## 心情、天气与标签

- 心情可选开心、平静、兴奋、疲惫、低落、生气，以项目内的 SVG 表情展示。平静使用横线眼睛和平嘴，疲惫使用 `x_x` 表情。
- 天气可选晴天、多云、阴天、下雨、下雪、有风，以 SVG 天气图标展示。天气由用户手动记录，不请求定位或天气服务。
- 心情与天气均可留空，再点已选项可以取消。
- 标签支持回车或逗号添加、移除，去重后最多 10 个，每个最多 30 字符。列表支持按标签筛选。
- 卡片、时间轴及详情展示上述标记，日记没有独立分类字段。

## 图片与资源库关联

每篇日记最多添加 15 张配图，支持文件选择器多选，或将多张文件拖入上传区域。可逐张移除，也可将任意一张设为封面（移到首位）。列表卡片显示封面和图片数量，时间轴最多预览 4 张，详情展示全部图片；普通段落不足时可在同一位置连续展示多组，没有普通段落时将随文图片放在正文开头。批量上传逐张处理，单张失败不会丢弃成功图片，会列出失败文件并保留正文。支持 JPG、PNG、GIF、WebP，最大 10 MiB、4000 万像素；服务端校验真实图片内容与后缀，拒绝 SVG、伪造图片及超限文件。

“从图片文集选择”可以选择本人创建的图片文集，按照片组浏览。整组选取会加入组内可用、尚未关联的照片；也可逐张勾选，跨文集／分页保留本次选择。组内多张按实际选中的资源数计入 15 张上限，同一文件重复出现只计一次。整组超过剩余额度时不截断添加，提示用户逐张选择。外链、非本人上传的资源、已失效或本机文件缺失的照片标明原因并禁用。

文集选图只引用已有资源 ID，不复制文件，也不保存一个会随组变动而自动展开的组 ID。保存后配图保持选取时的成员和顺序；原组增删不会自动改变日记，移除原文集照片时日记仍引用的文件由公共删除保护保留。所有配图仍按已有有序 ID 数组参与 WebDAV，不新增持久字段或数据库迁移。

上传复用 `/api/resource/upload`，来源类型为 `diary`。成功后立即存入资源库，保存日记时将有序资源 ID 写入 `image_asset_ids`，`cover_asset` 同步指向第一张作为封面；相同用户上传相同文件会复用已有资源。取消写作或移除图片不会自动删除已上传文件，未被其他内容引用的图片可以到资源库清理。

资源库列表卡片和资源详情显示“日记 · 标题”，点击跳到 `/diary?entry=<diaryId>` 并打开日记详情。一个资源有多篇有效日记引用时，资源库的单个来源入口指向日期排序最新的一篇。关联状态筛选纳入日记引用。有效日记引用中的图片受到公共资源删除保护；日记软删除或移除配图后释放引用，其他业务仍有引用时继续保护。

日记配图通过携带登录认证的资源接口获取，由公共图片组件管理 Blob URL。仅被私人日记引用的图片仅上传者可通过资源接口读取，旧 `/media/` 直链不公开。图片如同时被可访问的文章引用，按文章原有授权开放；日记上传的哈希去重、添加引用和软删除都不会撤销原文章的授权。复用图片文集照片时保留源文集原有访问权限，不因加入私人日记而使原公开照片变为私有；原文集已不再引用、也没有可访问文章授权、仅被私人日记引用的资源按日记私有规则保护。量化研究资源的独立私有规则保持优先。列表和详情均使用认证图片组件。

历史日记已有的外部配图地址继续只读展示，普通编辑保留；用户移除或上传替换后清空旧地址。不再提供外部配图地址输入。

## 数据与同步

用户已确认日记及新增数据纳入 WebDAV。`memos.DiaryEntry` 使用稳定随机 ID，与闪念、Agent 世界记录分开保存。正文接口仅允许登录用户访问自己的记录；删除将 `is_valid` 设为 false。

标题、正文、日期、心情、天气、标签、有序多图资源关联、封面关联、历史配图地址、归属、有效标记及时间字段随 `memos` app 进入导出、修订跟踪、三方合并和恢复。配图资源记录随 `assets` 同步；上传后的图片文件由现有媒体发现与 Blob 机制同步。旧外部图片只保留地址，不自动下载。

迁移为 `memos/0006_diaryentry`、`assets/0009_alter_asset_source_type`、`memos/0007_diaryentry_cover_asset_diaryentry_mood_and_more` 、`memos/0008_alter_diaryentry_entry_date` 和 `memos/0009_diaryentry_image_asset_ids`。旧记录心情／天气为空，标签为空列表。旧单图记录通过读取投影补齐 `imageAssetIds`，无需复制资源文件；旧同步包中缺少多图字段时仍可从封面关联读取。显式提交空多图列表会同时清空封面关联。各设备需使用包含这些字段和资源来源类型的同版代码。

日记没有接入 Agent 决策、RAG、全局搜索或回收站；软删除后不提供界面恢复入口。

## 代码与接口

- 页面、入口及展示：`views/DiaryPage.tsx`、`components/Diary/`。
- 类型、请求和状态：`types/api/diary.ts`、`api/diary.ts`、`api/diaryImage.ts`、`api/diaryLibrary.ts`、`hooks/useDiary.ts`、`hooks/useDiaryPhotoLibrary.ts`。
- 数据与 API：`memos/diary_models.py`、`diary_serializers.py`、`diary_views.py`、`diary_urls.py`、`diary_library.py`。
- 上传与资源引用：`assets/diary_images.py`、`assets/views.py`、`utils/resource_assets.py`、`views/ResourcesPage.tsx`。
- `GET /api/diary/photo-library` 返回本人图片文集和按组分页的照片投影，支持 `collId`、`keyword`、`page`，不下载外链或写入资源。
- `GET /api/diary/` 获取本人有效日记；`POST` 新建；`GET/PUT/DELETE /api/diary/<diaryId>` 查看／完整更新／软删除。
- `imageAssetIds` 提交最多 15 个不重复、归属本人且有效的图片资源 ID，并保存其顺序；`coverAssetId` 与 `coverUrl` 为首张图片的投影。服务端锁定所有选中资源并验证权限，在事务内写入，校验失败不改变原有配图。其余字段使用前端 camelCase，API 延续 `code/msg/data`，校验失败 HTTP 400、越权或无效记录 HTTP 404。
- local 样例与上传文件仅保存在浏览器内存，刷新恢复。日记和资源库关联共用 `mocks/diary.ts`、`diaryResources.ts`，资源列表继续按分页和筛选合并其他领域样例。样例／空数据／加载／接口错误都由 mock 处理，不访问真实后端。
